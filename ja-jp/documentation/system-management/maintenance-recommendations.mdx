---
title: "運用アドバイス"
---

お客様の組織においては、「アカウントと権限の定期的な巡回点検、モデルとリソースの一元管理、ログと利用状況の継続的なモニタリング、リリース前後の変更内容の確認」といった運用体制を構築することを推奨します。利用範囲が広いシーンでは、問題対応のクローズループ、権限監査、利用フィードバックの収集といった仕組みも併せて実施し、プラットフォームの長期的な安定稼働と規範に沿った運用を保障してください。

| モジュール | 主な用途 |
| --- | --- |
| モデル設定 | システム管理モジュール配下のモデル設定機能です。コアバリューは、プラットフォームに接続する大規模モデルを一元管理することであり、モデルタイプ（対話／画像生成／テキストベクトル／リランキング）、名称、Base URL、API Key（AES 暗号化保存）を設定できます。モデル作成後はコンテキスト長や推論モデルかどうかを設定でき、部門／担当者／ロール／権限ポリシーごとに使用権限を割り当てられます。「自分が作成したもの」と「自分に権限が付与されたもの」という2つの独立したビューを提供し、モデルリソースのライフサイクル全体の管理を実現します。適用シーンは、システム管理者が企業独自の大規模モデルを接続する場合、モデルパラメータを設定する場合、モデルの使用権限を割り当てる場合、プラットフォームのモデルリソースを一元管理する場合です。 |
| 辞書管理 | 機能名称：システム管理モジュール配下の辞書管理機能です。コアバリューは、企業専用の辞書体系を一元管理することであり、機密語辞書（リスク・コンプライアンスに基づくブロック）、同義語辞書（表現の標準化）、専門用語辞書（業界用語の注入）という3種類の辞書管理を提供し、辞書および語句の追加・削除・編集・照会、一括インポートと一括エクスポートに対応することで、Agent モデルの理解精度とコンプライアンス保障能力を高めます。適用シーンは、システム管理者が Agent の言語理解ルールを設定する場合、コンテンツのリスク管理ポリシーを設定する場合、業界の専門知識を注入する場合です。 |
| 権限ポリシー管理 | 権限ポリシー管理では、Agent、ナレッジベース、カスタムツール、MCP、モデル、データベースに対して権限ポリシーを策定でき、他者や組織がアップロードした Agent、ナレッジベース、ツールをユーザーが参照・使用できるかどうかを制御できます。 |
| システム設定 | システム設定には、汎用設定、Agent タイプ、Agent のおすすめの質問、コードブロックの外部実行環境の設定が含まれます。 |
| セキュリティログ | 機能名称：システム管理モジュール配下のセキュリティログ機能です。コアバリューは、詳細な監査追跡パネルを提供し、プラットフォーム上のすべてのユーザー操作を全方位で完全に記録し、条件検索とデータエクスポートに対応することで、セキュリティ等級保護のコンプライアンス要件を満たすことです。適用シーンは、システム管理者がセキュリティ監査、操作の追跡調査、コンプライアンス検査、問題調査を行う場合です。 |
| データダッシュボード | Agent の設定において、プライバシーキーワードのブロック（ユーザーの入力を禁止するキーワード）を設定でき、あらかじめ用意された機密語辞書と関連付けることで、対話の入り口段階から企業情報のセキュリティとコンプライアンス要件を保障します。 |
