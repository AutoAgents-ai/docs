title: "システム設定"

### 機能概要

システム設定には、汎用設定、Agent タイプ、Agent のおすすめの質問、コードブロックの外部実行環境の設定が含まれます。

<Frame>
  <img src="/images/documentation/ch7_7.6.7.1_0401.png" alt="システム設定" />
</Frame>

### 利用シーン

この機能は、システムパラメータの設定が必要なシーンで使用します。

### 機能へのアクセス

プラットフォーム左側のメニューバーにある【システム管理＞システム設定】メニューをクリックすると、システム設定ページに移動します。

  <img src="/images/documentation/ch7_7.6.7.3_0402.png" alt="システム設定" />
</Frame>

### 操作手順

### 汎用

<Frame>
  <img src="/images/documentation/ch7_7.6.7.6_0404.png" alt="システム設定" />
</Frame>

汎用設定画面では、システムロゴ、ログイン画面の背景、その他のシステムパラメータを設定できます。
パラメータ説明：
環境ごとのデプロイの差異
Agent タイプ

<Frame>
  <img src="/images/documentation/ch7_7.6.7.6_0405.png" alt="システム設定" />
</Frame>

Agent タイプ設定画面では Agent タイプを設定できます。追加をクリックし、表示された画面でタグ名を入力して確定をクリックするだけで追加できます。

<Frame>
  <img src="/images/documentation/ch7_7.6.7.6_0406.png" alt="システム設定" />
</Frame>

Agent のおすすめの質問

<Frame>
  <img src="/images/documentation/ch7_7.6.7.6_0407.png" alt="システム設定" />
</Frame>

この画面では、おすすめの質問機能を有効にするかどうか、おすすめの質問のベクトルモデル、おすすめの質問の要約モデル、おすすめの質問の関連度、おすすめの質問のプライバシー保護キーワードなどの情報を設定できます。
コードブロックの外部実行環境

<Frame>
  <img src="/images/documentation/ch7_7.6.7.6_0408.png" alt="システム設定" />
</Frame>

この機能では、外部実行環境の名称、URL、プログラミング言語などの情報を設定できます。環境の追加をクリックし、関連情報を入力するだけで追加できます。
