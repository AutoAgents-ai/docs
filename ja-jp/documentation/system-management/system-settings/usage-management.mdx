title: "利用状況管理"
---

### 機能概要

利用状況管理機能では、システムモデルの Token 上限、システムモデルの残り利用可能 Token 数、システムモデルの有効期限、テナントに設定されたモデルの使用済み Token 数などの情報を確認できます。

  <img src="/images/documentation/ch7_7.6.5.1_0396.png" alt="利用状況管理" />
</Frame>

### 利用シーン

ユーザーがモデルの利用状況を把握したいシーンです。

### 機能へのアクセス

プラットフォーム左側のメニューバーにある【システム管理＞利用状況管理】メニューをクリックすると、利用状況管理ページに移動し、利用状況管理の情報を確認できます。
