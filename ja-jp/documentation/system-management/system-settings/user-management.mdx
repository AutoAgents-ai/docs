### 機能概要

従業員アカウントの追加・管理に対応しており、ニックネーム、パスワード、電話番号、メールアドレス、ユーザーロール、所属組織を入力できます。アカウントの有効化／無効化操作にも対応しており、アカウントの検索や一括エクスポートも可能です。

### 機能へのアクセス

Agents プラットフォームにログインし、ホーム画面左側の「システム管理」ボタンをクリックし、続いて「ユーザー管理」モジュールをクリックします。

### 画面説明

ユーザー管理
アカウント：ユーザーがプラットフォームにログインする際の一意の識別子であり、プラットフォームがユーザーを識別するための中核的な項目です。
ニックネーム：プラットフォーム内でのユーザーの表示名です。自由に設定できるため、ユーザーの識別がしやすくなります。
組織：ユーザーが所属する組織／部門で、組織単位での権限制御やデータ集計に使用します。
メールアドレス：ユーザーが紐付けているメールアドレスで、アカウントの復旧や通知の配信などの場面で使用できます。
電話番号：ユーザーが紐付けている電話番号で、アカウントのセキュリティ認証や通知の到達などの場面で使用します。
アカウントの追加：プラットフォーム管理者はこの機能を通じて新しいユーザーアカウントを追加し、ユーザーの基本情報や権限を設定できます。
エクスポート：現在のユーザー一覧データをファイルとしてエクスポートできます。一括での保存やオフライン分析に便利です。
編集：管理者はユーザーのニックネーム、メールアドレス、電話番号、所属組織などのアカウント情報を修正できます。
有効化／無効化：管理者はアカウントの利用状態を制御できます。無効化状態ではユーザーはプラットフォームにログインできず、有効化すると通常のアクセス権限が復元されます。
組織構造ツリー：ユーザーが所属する組織構造を階層的に表示するために使用し、部門／組織単位でのユーザーの絞り込みや管理に便利です。
