### 機能概要

機能名称：データ権限管理モジュール配下の Agent 権限管理機能です。コアバリューは、「誰がどの Agent を使用／編集できるか」を精密に制御することであり、部門、担当者、ロール、または事前定義された権限ポリシーの4つの観点から権限割り当てを行うことで、Agent リソースに対するきめ細かなアクセス制御を実現します。適用シーンは、システム管理者が社内 Agent へのアクセス・操作権限を割り当てる場合や、ユーザーごとの Agent 利用範囲を区分する場合です。

Agent 権限管理機能により、管理者は企業の組織構造、担当者の職責、または事前定義されたルールに基づいて、各 Agent のアクセス権限を柔軟に設定できます。これにより、権限を持つユーザーのみが該当 Agent を参照、使用、編集できるようになり、企業の Agent リソースの安全かつ整然とした利用が保障されます。

### 機能へのアクセス

Agents プラットフォームにログインし、左側ナビゲーションバーの【データ権限管理】一次メニューをクリックし、展開されたメニューから【Agent 権限管理】二次メニューをクリックすると、Agent 権限管理機能ページに移動します。

Agent 権限管理機能ページは、検索エリアと Agent 一覧エリアの2つの部分に分かれています。各エリアの説明は以下のとおりです。

### 検索エリア

検索ボックス：Agent の名称、説明、または作成者情報を入力すると、条件に合致する Agent を素早く絞り込めます。曖昧検索に対応しています。

<Frame>
  <img src="/images/documentation/ch7_7.5.2.4_0309.png" alt="Agent 権限管理" />
</Frame>

### Agent 一覧

プラットフォーム内のすべての Agent の基本情報と権限管理への入口を表示します。各レコードには以下の項目が含まれます。
ID：Agent の一意の識別番号
名称：Agent の名称
作成者：該当 Agent を作成したユーザーアカウント
説明：Agent の機能と用途の説明
権限管理：「権限管理」ボタンが用意されており、クリックすると該当 Agent の使用権限割り当てポップアップが開きます
一覧の下部には Agent の総件数とページネーションコントロールが表示され、ページ番号またはページ送りボタンで複数ページの Agent データを閲覧できます。

<Frame>
  <img src="/images/documentation/ch7_7.5.2.5_0310.png" alt="Agent 権限管理" />
</Frame>

### 使用権限の割り当て

任意の Agent の右側にある「権限管理」ボタンをクリックすると、使用権限割り当てポップアップが開きます。このポップアップには、4つの権限割り当て観点のタブとグローバル権限オプションが含まれます。

<Frame>
  <img src="/images/documentation/ch7_7.5.2.6_0311.png" alt="Agent 権限管理" />
</Frame>

### 部門タブ

組織構造ツリー：企業の完全な部門組織構造を表示し、各階層の部門の展開／折りたたみに対応しています
検索ボックス：部門名を入力すると、対象の部門を素早く特定できます
チェックボックス：権限を付与したい部門にチェックを入れると、その部門に属するすべてのユーザーが該当 Agent へのアクセス権限を得られます
すべて表示オプション：チェックを入れると、該当 Agent はプラットフォーム上のすべてのユーザーに表示され、基本的なアクセス権限が開放されます

<Frame>
  <img src="/images/documentation/ch7_7.5.2.7_0312.png" alt="Agent 権限管理" />
</Frame>

### 担当者タブ

担当者一覧：プラットフォーム内のすべてのユーザーアカウントを表示し、検索機能に対応しています
選択済み担当者エリア：チェックされた権限付与対象の担当者を表示し、削除に対応しています
権限設定エリア：選択した担当者に対してきめ細かな権限を設定でき、以下にチェックできます。
読み取り：該当 Agent を参照・使用できます
編集：該当 Agent の設定や内容を編集できます
利用履歴：該当 Agent の利用履歴データを参照できます

<Frame>
  <img src="/images/documentation/ch7_7.5.2.8_0313.png" alt="Agent 権限管理" />
</Frame>

### ロールタブ

ロール一覧：プラットフォーム内で事前定義されたすべてのユーザーロールを表示し、検索機能に対応しています
選択済みロールエリア：チェックされた権限付与対象のロールを表示し、削除に対応しています
権限設定エリア：選択したロールに対して権限を設定でき、「読み取り」および「編集」権限にチェックできます

<Frame>
  <img src="/images/documentation/ch7_7.5.2.9_0314.png" alt="Agent 権限管理" />
</Frame>

### 権限ポリシータブ

権限ポリシー一覧：プラットフォーム内で事前定義されたすべての権限ポリシー（権限ポリシーとは、一連の権限ルールをまとめたもので、複数のリソースに統一的に適用できます）を表示し、検索機能に対応しています
選択済みポリシーエリア：チェックされた権限付与対象のポリシーを表示し、削除に対応しています
権限ポリシーにチェックを入れると、そのポリシーで定義されたすべての権限が該当 Agent に自動的に適用されます

<Frame>
  <img src="/images/documentation/ch7_7.5.2.10_0315.png" alt="Agent 権限管理" />
</Frame>

### ポップアップ下部のボタン

キャンセル：ポップアップを閉じ、権限の変更内容を保存しません
確認：すべての権限設定を保存して有効化します

<Frame>
  <img src="/images/documentation/ch7_7.5.2.11_0316.png" alt="Agent 権限管理" />
</Frame>

### 操作手順

### 1. Agent 権限管理ページへのアクセス

上記の機能へのアクセス手順に従い、Agents プラットフォームにログインして Agent 権限管理機能ページに移動します

<Frame>
  <img src="/images/documentation/ch7_7.5.2.13_0317.png" alt="Agent 権限管理" />
</Frame>

対象の Agent を素早く見つけるには、検索ボックスに Agent の名称、説明、または作成者情報を入力して絞り込みます

<Frame>
  <img src="/images/documentation/ch7_7.5.2.13_0318.png" alt="Agent 権限管理" />
</Frame>

### 2. Agent の使用権限の割り当て

Agent 一覧から権限を設定したい Agent を見つけ、その右側の【権限管理】ボタンをクリックして使用権限割り当てポップアップを開きます

<Frame>
  <img src="/images/documentation/ch7_7.5.2.14_0319.png" alt="Agent 権限管理" />
</Frame>

実際のニーズに応じて、以下のいずれか、または複数の権限付与方法を選択します。

<Frame>
  <img src="/images/documentation/ch7_7.5.2.14_0320.png" alt="Agent 権限管理" />
</Frame>

方法1：部門による権限付与
【部門】タブに切り替えます
組織構造ツリーで権限を付与したい部門にチェックを入れます（複数部門を同時に選択可能）
すべてのユーザーに権限を開放する場合は、左下の【すべて表示】オプションにチェックを入れます
【確認】ボタンをクリックして、部門への権限付与を完了します

<Frame>
  <img src="/images/documentation/ch7_7.5.2.14_0321.png" alt="Agent 権限管理" />
</Frame>

方法2：担当者による権限付与
【担当者】タブに切り替えます
担当者一覧で権限を付与したいユーザーにチェックを入れます（複数ユーザーを同時に選択可能）
右側の権限設定エリアで、選択したユーザーに対応する権限（読み取り／編集／利用履歴）にチェックを入れます
【確認】ボタンをクリックして、担当者への権限付与を完了します

<Frame>
  <img src="/images/documentation/ch7_7.5.2.14_0322.png" alt="Agent 権限管理" />
</Frame>

<Frame>
  <img src="/images/documentation/ch7_7.5.2.14_0323.png" alt="Agent 権限管理" />
</Frame>

方法3：ロールによる権限付与
【ロール】タブに切り替えます
ロール一覧で権限を付与したいロールにチェックを入れます（複数ロールを同時に選択可能）
右側の権限設定エリアで、選択したロールに対応する権限（読み取り／編集）にチェックを入れます
【確認】ボタンをクリックして、ロールへの権限付与を完了します

<Frame>
  <img src="/images/documentation/ch7_7.5.2.14_0324.png" alt="Agent 権限管理" />
</Frame>

方法4：権限ポリシーによる権限付与
【権限ポリシー】タブに切り替えます
権限ポリシー一覧で適用したい事前定義済みの権限ポリシーにチェックを入れます（複数ポリシーを同時に選択可能）
【確認】ボタンをクリックして、ポリシーによる権限付与を完了します
権限設定が完了すると、対応する部門／担当者／ロールは該当 Agent へのアクセス・操作権限を即座に得られます

<Frame>
  <img src="/images/documentation/ch7_7.5.2.14_0325.png" alt="Agent 権限管理" />
</Frame>
