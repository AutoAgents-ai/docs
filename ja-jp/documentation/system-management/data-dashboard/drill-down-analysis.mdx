---
title: "詳細ドリルダウン分析"
---

Agent：ユーザーが作成した AI アプリケーション／ボットの名称で、カスタム名または既定の名称を使用できます。
作成者：該当 Agent を作成したユーザーアカウントで、帰属管理や追跡に使用します。
作成日：該当 Agent が作成されたタイムスタンプで、作成の時系列を遡るために使用します。
総会話数：該当 Agent がユーザーによって呼び出され、発生した対話のやり取りの総回数で、Agent の利用アクティブ度を示します。
消費 Token 数：該当 Agent のすべての会話において、ユーザー入力とモデル出力のテキストで消費された Token（テキスト処理単位）の総量で、呼び出しコストに直接関係します。

アカウント：会話を開始したユーザーアカウントの識別子で、ユーザー行動の追跡に使用します。
ユーザーの質問：ユーザーが Agent に送信した元の質問／指示内容で、対話の入力側の情報を記録します。
高評価数：該当 Agent の回答に対するユーザーからのポジティブなフィードバック件数で、回答に対するユーザーの満足度を示します。
低評価数：該当 Agent の回答に対するユーザーからのネガティブなフィードバック件数で、回答品質の問題を特定するために使用します。
ニックネーム：会話を開始したユーザーのニックネームで、業務側でユーザーの身元を識別しやすくします。
所属部門：ユーザーが所属する組織／部門で、部門別に利用状況を集計するために使用します。
Agent の回答：ユーザーの質問に対して Agent が生成した回答内容で、対話の出力側の情報を記録します。
