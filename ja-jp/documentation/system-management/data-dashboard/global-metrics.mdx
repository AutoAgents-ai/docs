---
title: "全体運用指標"
---

PV（ページビュー数）：プラットフォームにログインしたユーザーがページを読み込みまたは更新するたびに、PV 数が1回加算されます。ユーザーが繰り返し更新すると、PV は継続的に積み上がります。
UV（ユニークユーザー数）：集計期間内にプラットフォームへアクセスした重複しないユーザーの数を指し、同一ユーザーが複数回アクセスしても1回のみカウントされます。
DAU（日次アクティブユーザー数）：集計期間内において、単日にログインしてプラットフォームを利用したアクティブユーザーの数を指し、プラットフォームの日次ユーザーアクティブ度を示します。
MAU（月次アクティブユーザー数）：集計期間内において、月次でログインしてプラットフォームを利用したアクティブユーザーの数を指し、プラットフォームの月次ユーザーアクティブ度を示します。
Agent 総数：プラットフォーム上で作成／設定済みの AI Agent（またはボットアプリケーション）の総数を指し、プラットフォーム上に展開されている AI サービスの規模を表します。
総 Token 消費量：集計期間内において、ユーザーと AI Agent とのやり取りで発生した入力＋出力の Token（テキスト処理単位）の消費総量を指し、通常はモデル呼び出しコストと強く関連します。
日次平均会話数：集計期間内において、ユーザーがプラットフォームの AI Agent と行った対話のやり取りの日次平均回数を指し、ユーザーが AI サービスを利用する頻度を示します。
部門インタラクション量：異なる部門／組織のユーザーとプラットフォームの AI Agent とのインタラクション回数／比率を指し、各業務部門の利用状況の分布を分析するために使用します。
ユーザーアクティブ傾向：MAU／DAU の切り替えが可能です。
ページトラフィック傾向：PV／UV の切り替えが可能です。
