---
title: "データダッシュボード"
---

Agent の設定において、プライバシーキーワードのブロック（ユーザーの入力を禁止するキーワード）を設定でき、あらかじめ用意された機密語辞書と関連付けることで、対話の入り口段階から企業情報のセキュリティとコンプライアンス要件を保障します。
Agent の観点から作成者、作成日、呼び出し件数を確認でき、さらにユーザーの観点から具体的なアカウントの質問内容まで掘り下げることで、全体から個別までの多層的なドリルダウン分析を実現します。

### 機能へのアクセス

Agents プラットフォームにログインし、ホーム画面左側の「データダッシュボード」ボタンをクリックします。
