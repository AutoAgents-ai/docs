title: "公開とデプロイ"
---

### 機能概要

Skill のデバッグが完了すると、保存（ローカルに保持）または公開（SkillHub へプッシュ）を選択できます。公開された Skill は、プラットフォーム内の Agent やアプリケーションなど、さまざまな対象から直接参照できるようになり、AI 専用能力のシーンをまたいだ再利用と標準化された配布を実現します。

### 機能入口

Agents プラットフォームにログインし、ホーム画面左側の Skill 管理メニューをクリックし、Skill 詳細タブページを選択して、保存または公開ボタンをクリックしてデプロイまたは配布を行います。
