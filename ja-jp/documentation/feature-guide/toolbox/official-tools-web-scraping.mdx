### 文法の説明

スクリプトの文法は命令と命令パラメータで構成されます。各命令は1行を占有する必要があります。
文法：\<命令\> \[=\>命令パラメータ\]
命令：必須項目で、1行に記述できる命令は1つのみです。命令の戻り値がセレクタ型の場合は続けてチェーン操作が可能で、セレクタ型でない場合は処理を終了して最終結果を返します。最後の命令は必ず終端型（セレクタ型でない）の命令になります。
=\>：任意項目で、パラメータを指定するための記号です
命令パラメータ：任意項目で、パラメータが不要な命令には入力する必要はありません
例1：
すべてのリンクを取得し、/articles/を含むリンクのみに絞り込みます
例2：
class 属性が article-body である任意の html タグ \<article\> のノード配下にある、任意の html タグ \<h1\> のタイトル内容を取得します
例3：
class 属性が article-body である任意の html タグ \<div\> のノード配下にあるすべての記事内容を取得します
