---
title: "マイAgent"
---

Agents プラットフォーム左側メニューの「マイAgent」には、「作成したAgent」と「権限を付与されたAgent」の2つのリストが含まれます。Agent のステータスは「公開済み」と「未公開」の2種類に分かれており、公開済みの Agent は Agent マーケットで見つけて直接利用できます。未公開の Agent は、作成者および権限を付与されたユーザーのみが表示・編集できます。

<Frame>
  <img src="/images/documentation/ch6_6.2.2_0127.png" alt="マイAgent" />
</Frame>

「マイAgent」で Agent をクリックすると Agent 設定ページに移動し、そのサンプル Agent の設定情報を確認したり、構築方法を学んだりすることができます。
上部メニューを切り替えることで、基本情報の「設定」と「プランニング」オーケストレーションを確認できます。
右上の「公開」をクリックすると、この Agent を Agent マーケットに公開して利用できるようになります。
