---
title: "Agentを体験する"
---

「Agentマーケット」で公開済みの Agent を選択してクリックすると、その Agent を利用してAgent対話ページに移動します。
下部の入力欄に質問を入力するか、ショートカット質問をクリックして Agent と対話できます。
左側メニューサイドバーから最近使用した Agent に切り替えられます。
左側メニュー内で過去の対話履歴を確認したり、新しい対話を作成したりできます。
