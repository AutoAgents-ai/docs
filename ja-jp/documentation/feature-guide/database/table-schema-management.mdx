### テーブル基本情報領域

テーブル名称と説明：現在選択中のテーブルの名称「XX章節」を表示し、デフォルトでは「説明なし」と表示されます。
データテーブルのカスタム説明入力欄：当該データテーブルの個別の説明を入力できます。
フィールド検索ボックス：フィールド名やコメントを入力して、現在のテーブルのフィールドをあいまい検索できます。
フィールド情報管理テーブル
テーブルには、データテーブルのフィールドを管理するための5列の中核情報が含まれます：
フィールド名称：データベース本来のフィールド名（chapter_content、chapter_numberなど）を表示し、編集はできません。
フィールドコメント：データベース本来のフィールドコメントを表示し、コメントがない場合は「-」と表示されます。
カスタムコメント：編集可能な項目で、「クリックして編集...」をクリックするとカスタムのフィールド説明を入力できます。
フィールドタイプ：フィールドのデータベースデータ型（text、int、varchar(255)など）を表示し、編集はできません。
有効化の有無：スイッチコントロールで、青色のオン状態は当該フィールドが使用可能であることを示します。
