---
title: "マイアプリ"
---

「マイアプリ」モジュールは、Agent の能力をビジュアルなアプリとしてカプセル化するための機能で、顧客がプラットフォームの価値を最も直接的に体感できる重要な機能です。既存の元情報によると、このモジュールには主にアプリ一覧管理、アプリ作成、自然言語によるページ生成、アプリ公開という4種類の操作が含まれます。
- 「マイアプリ」ページに移動し、既存のアプリを確認してキーワードで検索します。
- 「アプリを作成」をクリックし、アプリ名とアプリ紹介を入力します。
- 対象の Agent を選択してバインドし、アプリと Agent の能力との対応関係を確立します。
- 編集ワークベンチで自然言語によりページの要件を記述し、プレビューおよび再編集を行います。
- 効果に問題がないことを確認したらアプリを公開し、独立したアクセスアドレスを取得します。
