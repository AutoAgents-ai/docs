---
title: "アプリの作成と基本設定"
---

アプリの作成フローは白紙の状態から構築を開始でき、基本情報の設定と Agent のバインディングを通じて、アプリに「アイデンティティ」と「頭脳」を確立します。

### 操作手順

ステップ1：作成を開始します。一覧ページ先頭の【アプリを作成】（「+」カード）をクリックし、「ゼロから作成」を選択します。

<Frame>
  <img src="/images/documentation/ch6_6.4.3.1_0139.png" alt="アプリの作成と基本設定" />
</Frame>

ステップ2：基本設定を行います。ポップアップに「アプリ名」と「アプリ紹介」を入力し、【次へ】をクリックします。

<Frame>
  <img src="/images/documentation/ch6_6.4.3.1_0140.png" alt="アプリの作成と基本設定" />
</Frame>

ステップ3：Agentをバインドします。「Agentを追加」ウィンドウで、「作成したAgent」または「すべて」のリストから対象の Agent にチェックを入れます。アプリのすべての機能は、本質的にバインドされた Agent に基づいて実現されます。完了後【確定】をクリックすると編集ワークベンチに移動します。

</Frame>
