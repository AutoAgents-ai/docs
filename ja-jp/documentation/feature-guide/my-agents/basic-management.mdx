このモジュールでは、Agent カードに対するクイックメンテナンス機能を提供しており、並び順の最適化やアセットのクリーンアップが行えます。

  <img src="/images/documentation/ch6_6.3.3_0131.png" alt="Agentの基本管理" />
</Frame>

### 操作方法

トップ表示：カード左下の【トップに固定】ボタンをクリックします。トップに固定された Agent は作成時刻に関わらず、常にリストの先頭に表示されます。再度クリックすると解除されます。
再編成：カード本体（または名称）を直接クリックすると、その Agent の基本設定およびフローオーケストレーションページに移動します。
アセットの削除：
カード右下の【…】（その他）ボタンをクリックします。
ドロップダウンメニューから【削除】を選択します。
確認ポップアップで「OK」をクリックすると、その Agent がプラットフォームから完全に削除されます。
