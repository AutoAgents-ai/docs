---
title: "権限の割り当てと管理"
---

「作成したAgent」について、作成者は企業内の他のメンバーに対して的確に利用権限を付与することができ、エンタープライズレベルのツールを安全かつコントロール可能な形で配布できます。

### 操作手順

ステップ1：「作成したAgent」リストで対象の Agent カードを見つけ、右下の【…】ボタンをクリックして拡張操作メニューを開きます。
ステップ2：メニューから【利用権限の割り当て】を選択すると、「利用権限の割り当て」設定ウィンドウが表示されます。

<Frame>
  <img src="/images/documentation/ch6_6.3.4.1_0132.png" alt="権限の割り当てと管理" />
</Frame>

ステップ3：ポップアップ上部で【部門】、【担当者】、【ロール】、【権限ポリシー】のタブを必要に応じて切り替え、権限を付与する対象を正確に指定します。
ステップ4：左側の組織構成ツリーまたは検索バーで対象項目にチェックを入れると、右側に選択済みの対象リストが表示されます。

<Frame>
  <img src="/images/documentation/ch6_6.3.4.1_0133.png" alt="権限の割り当てと管理" />
</Frame>

ステップ5：右下の【確定】ボタンをクリックして権限付与を完了します。権限を付与されたユーザーは、その後自身のアカウントの「権限を付与されたAgent」リストでその Agent を確認できるようになります。
