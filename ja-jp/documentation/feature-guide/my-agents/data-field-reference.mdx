---
title: "データフィールド説明表"
---

「使用記録とデータダッシュボード」に表示される主要なデータフィールドとその説明は以下のとおりです。業務担当者が集計基準を理解する際の参考にしてください。

| フィールド | 説明 |
| --- | --- |
| Agent 名称 | ユーザーが作成した Agent の名称。カスタム名称またはデフォルト名称を使用可能 |
| 作成者 | その Agent を作成したユーザーアカウント。帰属管理とトレーサビリティに使用 |
| 作成時刻 | Agent が作成されたタイムスタンプ。作成の時系列を追跡するために使用 |
| 呼び出し回数 | その Agent が呼び出されて開始された対話インタラクションの総回数。利用の活発度を反映 |
| Token 消費量 | その Agent がすべてのセッションで消費した Token の総量。呼び出しコストと直接関連 |
| 利用部門/利用者 | その Agent を呼び出した部門または利用者。ディメンション別に利用状況を集計するために使用 |
