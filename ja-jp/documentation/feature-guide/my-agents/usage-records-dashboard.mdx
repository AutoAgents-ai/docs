可視化されたデータ運用分析と詳細なインタラクションログを提供し、作成者が Agent の利用頻度、ユーザー分布、対話の深さ、頻出質問を追跡できるようにすることで、Agent の継続的な改善にデータ的な裏付けを提供します。

### 操作手順

ステップ1：ダッシュボードに移動します。対象の Agent カード右下の【…】ボタンをクリックし、【使用記録】を選択すると、その Agent 専用のデータ分析ダッシュボードに移動します。
ステップ2：データの絞り込みを行います。ページ上部で「クエリ期間」（直近1週間、直近1ヶ月など）を設定するか、「部門連携」にチェックを入れてドロップダウンのツリー図から特定の部門を選択することで、特定の組織ディメンションでのドリルダウン分析ができます。詳細データについては、アカウント、セッションID、入力内容、出力内容のキーワードによる精密検索にも対応しています。
ステップ3：トレンド指標を確認します。上部のダッシュボード領域で、各主要運用指標の折れ線グラフのトレンドを確認できます。一部のグラフは複数ディメンションでのドリルダウンに対応しており、例えばユーザー満足度はドロップダウンから「いいね」または「よくないね」のディメンションで切り替えて確認でき、さらにアクセス元（Agentを発見する、共有リンクなど）でのフィルタリングにも対応しています。
ステップ4：詳細とログを確認します。ページ下部の「使用記録」と「頻出質問リスト」で、ユーザーの対話詳細やタスクステータスを1件ずつ確認できます。調査が必要なレコードについては、操作列の【実行ログのダウンロード】をクリックして、より詳細な実行情報を取得できます。
ステップ5：データをエクスポートします。ページ内のすべてのデータ詳細テーブルはデータエクスポートに対応しています。右上の【データエクスポート】ボタンをクリックすると、完全なデータレポートをローカルにダウンロードして詳細な分析を行うことができます。
