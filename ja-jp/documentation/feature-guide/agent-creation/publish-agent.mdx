### 公開方法

まず右上の「···」ボタンをクリックし、表示されたサブメニューから「公開」ボタンを選択して、Agent の公開ページに入ります。

### Http アプリケーション

HTTP アプリケーションリンクの作成と管理：
リンクの作成：
右上の「リンク作成」ボタンをクリックします。
必須項目：リンク名、有効期限
デフォルトの利用方式：「自己チャージによる利用」
オプション：リンクパスワードの有効化／無効化

<Frame>
  <img src="/images/documentation/ch6_6.1.1.2_0003.png" alt="Agent の公開" />
</Frame>

リンクの操作：
作成が完了すると次の操作が可能です：開く、コピー、ウェブページへの埋め込み
リンク右側の「···」ボタンをクリック：リンクの削除または編集

### API サービス

API サービスページの情報と操作：
利用可能な情報：
Uuid：Agent API を一意に識別する識別子で、異なる API インスタンスを識別・区別するために使用します。
AuthKey：API 呼び出し権限を検証するための鍵で、認可されたユーザーのみが API にアクセスできることを保証します。
AuthSecret：API 呼び出しをさらに保護するためのセキュリティ鍵で、通常は AuthKey と併用してセキュリティを強化します。
作成時刻：API の作成日時。
ユーザー操作：
API 情報に対して行える操作：コピー、更新、削除。
詳細な API 呼び出し方法：AgentsOpenApi-v1.5 を参照してください。
