### モジュール紹介

ワークフローに JavaScript または Python のコードを組み込んでデータ処理を行うことができます。関数名は userFunction として指定する必要があり、入出力は Key-Value 形式です。計算精度の要求が高く、構造化されたロジック処理が必要なシナリオに適しています。
