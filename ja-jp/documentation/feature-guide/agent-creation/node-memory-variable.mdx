---
title: "記憶変数の追加"
---

### 機能概要

ワークフロー内で一時変数を保存することで、インテリジェント対話モジュールのコンテキスト長の制限（最大 6 ターン）を補うことができます。対話内容を記憶変数に連結・追記することで、長いターン数にわたる対話のコンテキストの継続と、Agent 間でのデータ受け渡しを実現できます。

### 機能エントリ

モジュール内で記憶変数の追加モジュールを見つけることができます。

### 画面操作フローの説明

記憶変数の追加モジュールをクリックして設定画面に入り、「追加」ボタンをクリックして記憶変数を追加します。

<Frame>
  <img src="/images/documentation/ch6_6.1.33.3_0096.png" alt="記憶変数の追加" />
</Frame>

案内に従ってデータ型、フィールド key、フィールド説明を入力し、「追加」をクリックすると、記憶変数の追加モジュールを 1 つ作成できます。

<Frame>
  <img src="/images/documentation/ch6_6.1.33.3_0097.png" alt="記憶変数の追加" />
</Frame>

### フィールド key

フィールド key は、このフィールドがシステム内で持つ一意で重複しない識別子であり、このフィールドに「システム内部で使用する名前」を付けるようなものです。コード、データベース、インターフェースにおいてこのフィールドを正確に特定するために使用され、ユーザーが目にする「フィールド名」とは別のものです。
