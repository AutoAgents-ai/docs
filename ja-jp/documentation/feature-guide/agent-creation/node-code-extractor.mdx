### 機能概要

コード抽出モジュールは、プラットフォームが開発者向けに提供する実用的なツールであり、大規模言語モデルが生成した Markdown 形式のコンテンツから、指定されたタイプのコードスニペットを正確に抽出することを目的としています。SQL、Python、Java、C、JSON、JavaScript の 6 種類の主要なコードタイプに対応し、自然言語の記述に混在するコード部分を識別・分離して、純粋なコードテキストとして出力します。これにより、その後の直接利用、実行、さらなる処理が容易になります。
このモジュールの中核的な価値は以下のとおりです。
開発効率の向上：モデルの返答から自動的に実行可能なコードを抽出し、手動でのコピー＆ペーストやフォーマット整理といった煩雑な作業を回避します。
コードの純粋性の確保：自然言語とコードを効果的に分離し、抽出されたコードスニペットを直接実行や統合に利用できるようにします。
フローのシームレスな連携：抽出されたコードは変数として、後続のコードブロックモジュールに直接渡して実行させたり、ドキュメント出力モジュールに渡して保存させたりでき、ワークフローの自動化を実現します。

### 機能エントリー

コード抽出モジュールは独立した機能ノードとして、プラットフォームのビジュアルワークフロー編成キャンバスに統合されています。この機能へのエントリー手順は以下のとおりです。
モジュールのドラッグ：ワークフローキャンバス左側のコンポーネントライブラリで「コード抽出」モジュールを見つけ、キャンバス内の適切な位置にドラッグします。
モジュールの命名：キャンバスにドラッグしたモジュールの名前を変更し、フローの理解や以後の管理を容易にします。
有効化条件の設定：業務ロジックに応じて「連動有効化」または「いずれか有効化」を設定し、モジュールがどのような条件で実行を開始するかを決定します。

### 画面説明

コード抽出ツールの設定画面はシンプルで分かりやすく、主に入力パラメータの設定と出力結果の表示エリアで構成されています。
コアパラメータの設定
設定画面には主に以下のパラメータが含まれます。
連動有効化：ブール型。このノードは複数のブール型入力を接続できます。上流のすべての条件が True の場合に現在のコンポーネントの実行を有効化できます。つまり「すべての条件が満たされたときにこのモジュールを実行する」という意味です。
いずれか有効化：ブール型。このノードは複数のブール型入力を接続できます。上流のいずれかの条件が True であれば現在のコンポーネントの実行ロジックを有効化できます。つまり「いずれかの条件が満たされればこのモジュールを実行する」という意味です。
Markdown 入力：文字列型。上流から出力される Markdown 形式のテキストを接続し、コード抽出の元となる内容とします。
コードタイプ：ドロップダウン選択ボックス。SQL、Python、Java、C、JSON、JavaScript の 6 種類のコードタイプから 1 つを選択し、今回の抽出対象とします。
出力：読み取り専用の表示エリア。抽出を実行すると、システムはここに抽出された純粋なコードテキストを表示します。

### 操作フロー

以下では、一段の Markdown テキストから Python コードを抽出する例を用いて、具体的な操作手順を説明します。
ステップ1：抽出ノードの追加
マイクロアプリ編成のキャンバス内で、ツールボックスから「コード抽出」ノードを適切な位置にドラッグします。
ステップ2：抽出パラメータの設定
キャンバス内のノードをクリックし、右側にポップアップする設定パネルで以下を設定します。
有効化条件の設定：業務ロジックに応じて「連動有効化」または「いずれか有効化」を選択します。
Markdown 入力の接続：上流ノード（例：対話モジュール）から出力される Markdown コンテンツを「Markdown 入力」ポートに接続します。
コードタイプの選択：「コードタイプ」ドロップダウンメニューで「Python」を選択します。
ステップ3：実行と結果の確認
設定パネル下部の「実行」または「テスト」ボタンをクリックします。
システムが抽出ロジックを実行し、「出力」エリアに抽出された純粋な Python コードテキストが直接表示されます。
このコード出力は変数として、後続のコードブロックモジュールで参照・実行させたり、ドキュメント出力モジュールでファイルとして保存させたりできます。
ステップ4：下流モジュールへの接続
コードの実行：「出力」ポートを「コードブロック」モジュールの「コード内容」入力に接続すると、抽出されたコードを直接実行できます。
コードの保存：「出力」ポートを「ドキュメント出力」モジュールに接続すると、コードを Word ドキュメントとして保存できます。
ベストプラクティスと注意事項
入力フォーマット：上流の入力内容が標準的な Markdown 形式であることを確認してください。コードブロックは正しく言語（例：python）を指定して囲む必要があり、これが正確な抽出の前提となります。
コードタイプの一致：選択したコードタイプは、Markdown 内に実際に含まれるコードタイプと一致している必要があります。一致しない場合、抽出に失敗したり、空の結果が返される可能性があります。
エラー処理：ワークフロー内でコード抽出ノードの後に分岐判定ノードを接続し、コードの抽出が成功したかどうかに応じて異なる後続フローを設計することを推奨します。
バージョンサポート：このモジュールはプラットフォームの基本版機能に属し、すべてのユーザーが利用できます。
