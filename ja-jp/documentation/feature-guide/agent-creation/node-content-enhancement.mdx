概要
簡単に言うと、このモジュールは「優秀なアシスタント」のようなものです。システムが質問に回答する際、まずナレッジベースを参照し、その中の専門的な内容を使って回答を「磨き上げ、加工（強化）」し、最終的な回答をより正確で専門的なものにします。

### モジュールの形（入力と出力）

このモジュールはワークフローのコンポーネントであり、生産ラインの加工ステーションのように、「入荷口」（入力ノード）と「出荷口」（出力ノード）があります。
入荷口（入力ノード）：モジュールはいつ作業を始めるのか？
この部分には「起動スイッチ」と「受け取るデータ」が含まれます。
起動スイッチ（実行ロジック）：起動方法は 2 種類あります。
連動有効化：前段のすべてのステップが完了する（全員がグリーンライトになる）のを待ってから作業を開始します。
いずれか有効化：前段のステップのいずれか一つが完了すれば（一人でもグリーンライトになれば）すぐに作業を開始します。
受け取るデータ（コンテンツ入力ロジック）：「チャンク情報」と呼ばれるデータパッケージ（システムが読み取れる、フォーマット付きのデータテキスト、通常は JSON 情報と呼ばれるもの）を受け取ります。これが加工する「原材料」です。
出荷口（出力ノード）：モジュールは作業完了後、何を引き渡すのか？
加工完了後、結果と状態を次の段階に渡します。
引き渡すデータ（コンテンツ出力ロジック）：加工が完了すると、強化されたチャンク情報（同様に JSON 形式のデータパッケージ）を出力し、次のステップに渡します。
作業状態（実行ロジック）：モジュールの実行が終わると報告があり、以下のいくつかの信号に分かれます。
実行成功 または 実行異常：この 2 つの結果は「二択」です（正常に完了したか、途中でエラーが発生したかのいずれかです）。
モジュール実行終了：このモジュールの作業が完了しさえすれば（成功でもエラーでも）、このスイッチはオンになり、後段の処理に「こちらは完了しました。続けて進めることができます」と伝えます。

### モジュール内部の設定方法（コンポーネントの内容）

このコンポーネントを開くと、データの加工にどのような「頭脳」と「方法」を使うかを具体的に設定できます。
パネルには「アルゴリズムを選択」というオプションがあり、ここには 3 種類の異なる「加工の秘技」から一つを選べます。
① 要約強化：アシスタントにより精度の高いコンテンツの要約を書かせます。これを選択した場合、以下の 2 つの項目を設定する必要があります。
強化設定：ドロップダウンメニューで「モデルを選択」します（この作業を行う優秀な AI の頭脳を選びます）。
Prompt：ここに入力欄があり、Prompt（アシスタントに与える具体的な指示、例えば「分かりやすい言葉で要点をまとめてください」など）を記入できます。

② ファイル名強化：ファイル名に基づいてコンテンツを補完・強化します（ファイル名自体に重要な情報が含まれている場合に適しています）。
③ ディレクトリ強化：ファイルが格納されているディレクトリの階層に基づいてコンテンツを強化します。
強化設定：このオプションを選択した場合も同様に「モデルを選択」する必要があり、ディレクトリ情報を処理するための AI の頭脳を指定します。
