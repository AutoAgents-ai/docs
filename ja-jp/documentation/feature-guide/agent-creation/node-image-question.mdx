### モジュール紹介

ユーザーが画像をアップロードした後、視覚モデルの画像認識能力を活用して分析と質問応答を行うことをサポートします。PNG、JPG、JPEG 形式に対応し、1 枚あたり最大 30MB までで、工業検査、票券認識などの視覚理解シナリオに適しています。
