### 概要

簡単に言えば、この機能は「誰がどのデータを閲覧でき、誰がどの機能を使えるか」を決めるためのものです。チームでの共同作業において、このような「通行証」を適切に発行することで、重要なデータの漏洩を防ぎつつ、各メンバーが自分の役割に専念できるようにし、より安心して業務を行えるようになります。
権限ページはどこにありますか？
このページは主に 2 つのページに分かれています。「自分が作成したもの」と「自分に権限が付与されたもの」です。これらはそれぞれ\\「自分が他の人に発行した通行証」と「他の人が自分に発行してくれた通行証」\\と理解すると分かりやすいでしょう。

### 「自分が作成したもの」ページ

このページはあなた専用の「コントロールパネル」です。あなた自身が設定したすべての権限ルールがここに表示されます。ここで新しいルールを作成したり、ルールを変更したり、権限を他の人に発行したりできます。
一覧を確認する： ページ中央の大きなテーブルには、あなたが作成したすべてのルールが表示されます。上部には以下の項目が明確に表示されます。
ポリシー名： このルールの名称（例：「営業部門の閲覧権限」）。
データ種別： 管理対象となるデータの種類。
ポリシーの説明： このルールの具体的な説明で、後から見返した際に用途を思い出しやすくするためのものです。
作成時刻： このルールが作成された日時（年月日と時分秒まで正確に記録）。
ルールの検索と新規作成： ルールが多すぎて見つからない場合は、上部の「検索ボックス」で名前を検索してください。新しいルールを追加したい場合は、青色の「新規追加」ボタンをクリックするだけで開始できます。
よく使う操作： 一覧の右端には「操作」という列があり、以下の 3 つのよく使う機能が用意されています。
編集（変更する）： 名前を間違えて入力してしまった場合や、対象となる人を変更したい場合は、こちらをクリックして修正します。「ポリシー設定」では、WeChat のグループを作成するときのように、どの部門、どの人、どのロールが利用できるかをチェックボックスで選択できます。会社の全員が利用できるようにしたい場合は、最下部の\\「全員に公開」\\にチェックを入れるだけで、ワンクリックで設定が完了します！

利用権限を割り当てる（他の人に発行する）： ルールを作成しただけでは有効になりません。このステップで具体的な対象者に発行することで初めて有効になります。同様に、特定の部門、人、またはロールを選択することもできますし、簡単に済ませたい場合は最下部の\\「全員に公開」\\を選択して、全員に権限を発行することもできます。

削除（不要になった場合）： このルールが今後完全に不要になった場合は、こちらをクリックして削除します。（ヒント：削除前にシステムが確認を求めますので、誤って削除しないようご注意ください！）

### 「自分に権限が付与されたもの」ページ

ここには、他の人（例えば上司や同僚）があなたに割り当てた権限が表示されます。このページは「読み取り専用」であることにご注意ください。展示ケースのように閲覧のみが可能で、中の内容を変更したり削除したりすることはできません。
ルールの検索と一覧の確認： 他の人から付与された権限が多すぎる場合も、上部の検索ボックスで検索できます。下部のテーブルにも、ポリシー名、データ種別、ポリシーの説明、あなたへの付与日時が明確に表示されます。
詳細の確認： 一覧の右端の「操作」列には「表示」ボタンのみがあります。クリックすると、この権限の具体的な内容（例えば、この権限が他にどの部門や人に発行されているか、あるいは「全員に公開」になっているかなど）を確認できます。
