### はじめに

こんにちは、Agents プラットフォームへようこそ。このチュートリアルでは、皆さんと一緒に最初の専用 Agent を構築し、Agents プラットフォームに早く慣れていただき、AI がもたらす強力な力を体感していただきます。全体の流れは約 3 分で完了し、あなたのアイデアをリアルタイムで対話できる Agent に変えることができます。さっそく始めましょう！

### ステップ1：Agent を作成する

### 空白 / テンプレートから作成する

Agents プラットフォームに入ったら、ページ左側の「Agent を作成」をクリックして作成フローに進んでください。Agent の作成には以下の 2 つの方法があります。
空白から作成：クリックすると、ゼロから Agent を作成します。
テンプレートから作成：クリックすると「テンプレートを適用」の選択ページに進みます。選択できるテンプレートタイプは以下の 7 種類です：すべてのカテゴリ、汎用インターネット、金融保険、公共サービス、電力エネルギー、医療ヘルスケア、その他。実際のニーズに応じて選択し、「テンプレートを複製」をクリックすればそのテンプレートを使用できます。

テンプレートを使用する
Agent の設定
Agent はユーザーと目的のアイデアをつなぐ重要な橋渡し役であり、指示の受信、分析、実行、対話を担っています。そのため Agent の設定はプラットフォームの中核機能であり、Agent の利用効果に大きく影響します。
空白 / テンプレートから Agent を作成すると、Agent の設定ページに進みます。Agent はWYSIWYG（見たままが得られる）方式で設定でき、左側が設定情報欄、右側がプレビューウィンドウです。

<Frame>
  <img src="/images/documentation/ch6_6.1.44.3_0122.png" alt="最初の Agent を作成する" />
</Frame>

設定情報欄では Agent に関連するパラメータを設定し、Agent の用途と方向性を決定します。設定が必要な情報は以下のとおりです。
Agent 名：あなたの Agent に名前を付けます。
説明：あなたの Agent の用途を説明する簡単な文章を書きます。
Agent タイプ：適切な Agent タイプを選択します。すべてのカテゴリ、汎用インターネット、金融保険、公共サービス、電力エネルギー、医療ヘルスケア、その他から選べます。
対話背景：あなたの Agent に適した対話背景を選択します。システム内蔵の背景を選ぶことも、カスタムで選ぶこともできます。
オープニングメッセージ：Agent との対話が始まる前に表示するメッセージです。
おすすめ質問：今回は設定不要です。
対話モデル：デフォルトのままにします。
Prompt：Prompt を使ってこの Agent が実現する目標を定義します。ここでは自由な発想を発揮して、Agent に対応する能力を与えてください。
ナレッジベース：今回はナレッジベースを使用しないため、チェックする必要はありません。

例えば今回は、自分の Agent を「SWOT 分析」アシスタントのキャラクターとして対話させたいので、以上の情報を設定して Agent を構成しました。

### プランニングと接続

上部の「プランニング」をクリックして Agent のプランニングページに進みます。このページでは Agent の実行フローをプランニングします。使用したいモジュールをドラッグしてキャンバスに入れ、ノードを接続することで正常に動作させることができます。
この例では、すでに左側の「テキスト情報」ノードと右側の「情報入力」を接続しています。この接続の意味は、ユーザーが質問したテキストの内容が対話モジュールに出力され、続いて対話モジュールが情報処理を行い、対話に返信するというものです。図に示すとおりです。

以上で Agent の基本情報の設定が完了しました。この Agent はすでに指定した知識と AI 能力を備えています。右上の「保存」をクリックしてください。
ステップ2：対話テスト
これで最初の Agent の作成が完了しました。右側の対話プレビュー画面で内容を入力すれば、Agent との対話を始められます。ぜひあなた専用の Agent を試してみてください。
対話の中で、Agent の対話についてさらに良いアイデアが出てきたら、いつでも Prompt の設計を調整して、最終的に期待する効果に近づけることができます。

### 設定完了

これで Agent の構築が完了しました。プラットフォームは非常に柔軟な構築能力を備えており、大規模モデルの力を借りてアイデアを効率化のための Agent へと変えることができます。次は、プラットフォームのより詳細な機能紹介をご覧いただき、AI がもたらすさらなる可能性をより深く体感してください。
