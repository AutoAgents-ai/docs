---
title: "Agent の作成"
---

Agent の作成は、プラットフォーム上での業務構築の出発点です。既存の Workflow 2.0 の資材と組み合わせることで、本プラットフォームはワークフローのオーケストレーション、モデルの接続、ナレッジによる拡張、ツールの呼び出しといった方法により、Agent の能力を構築することをサポートします。
- Agent の業務目標、対象ユーザー、期待される出力を明確化します。
- 適切なモデルリソースを選択し、パラメータと権限の設定を行います。
- Workflow 2.0 を通じて、処理ノード、データフロー、制御フローをオーケストレーションします。
- 必要に応じてナレッジソース、ツール、その他の外部機能をバインドし、処理効果を強化します。
- デバッグ、検証、公開を完了した後、業務担当者向けに利用を開放します。
