Agent 対話終了

### モジュール紹介

このモジュールは、複数の Agent が連携するシナリオで使用するモジュールです。Agent のプランニング編成にこのモジュールを導入した場合のみ、「プランニング」キャンバス左側の「Agents」欄でこの Agent を見つけることができ、キャンバスにドラッグして複数 Agent 間の連携を実現できます。
メモリ変数は現在のシナリオで保存される一時変数であり、他の Agent の編成内でこの Agent が呼び出される際には、メモリ変数はこの Agent の出力パラメータを表し、Agent をまたいだ参照を実現します。
