### モジュール紹介

ユーザーがドキュメントをアップロードした後、直接質問を入力して即時の質問応答を行うことをサポートします。同時に最大 9 個のファイル（1 ファイルあたり最大 50MB）をアップロードでき、PDF、DOC、DOCX、TXT 形式に対応しており、柔軟なドキュメントインタラクションを実現します。
