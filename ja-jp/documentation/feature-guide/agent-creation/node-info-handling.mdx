### モジュール概要

正規表現を用いて文字列をルールベースで処理し、入力パラメータから出力パラメータへの形式変換を実現します。データクリーニング、フィールドの連結、フォーマットの標準化などのシーンに適しており、文字列型の入出力のみをサポートします。

### 入力パラメータのフィールド key

フィールド Key は、そのフィールドがシステム、インターフェース、またはデータ構造内で持つ一意の識別子であり、対応するフィールド値を特定・取得するための重要な根拠となります。

### 入力パラメータのフィールド説明

フィールド説明は、そのフィールドの機能、意味、値の範囲、使用シーン、制約条件について詳細に記述したものであり、フィールドの用途を理解するための重要な根拠となります。

### 出力パラメータのフィールド key

フィールド Key は、そのフィールドがシステム、インターフェース、またはデータ構造内で持つ一意の識別子であり、対応するフィールド値を特定・取得するための重要な根拠となります。

### 出力パラメータのフィールド説明

フィールド説明は、そのフィールドの機能、意味、値の範囲、使用シーン、制約条件について詳細に記述したものであり、フィールドの用途を理解するための重要な根拠となります。

### 変換ルール

入力パラメータをこの出力パラメータへどのように変換するかを定義します。変数を参照する場合は {{variableName}} を使用します。
