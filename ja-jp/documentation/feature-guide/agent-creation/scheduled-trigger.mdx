---
title: "定時トリガー"
---

### 機能概要

定時トリガーでは定時タスクを設定でき、事前に設定した時刻に自動的に Agent を起動してワークフローを実行させることができます。複数の時刻トリガーモードに対応しており、複数のエントリからタスクを作成できます。管理画面でタスク情報を確認でき、アイコンによって素早く識別することもできます。設定はアプリケーションレベルで有効となり、タブを閉じても無効になりません。

### 機能エントリ

Agent の基本設定ページにアクセスし、「定時トリガー」オプションを見つけます。
「トリガー作成」をクリックし、トリガー名を入力します。
トリガー時刻を設定します。毎日トリガー、毎週トリガーなどのモードを選択できます。
トリガー時に実行する入力内容、つまり Agent がトリガー時に実行すべき指示を設定します。
「確定」をクリックして作成を完了します。

  <img src="/images/documentation/ch6_6.1.2.2_0007.png" alt="定時トリガー" />

### 設定方法

Agent の基本設定ページでは、名前、トリガー時刻、トリガー時の入力内容を含む定時トリガーを設定できます。トリガー時刻は、特定の時刻の指定、毎日トリガー、毎週トリガーなど、複数のモードの選択に対応しています。
