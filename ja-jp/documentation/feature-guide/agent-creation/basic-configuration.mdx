### 機能概要

ホーム画面で「Agent を作成」をクリックすると、Agent の基本設定ページに移動します。このページでは Agent の基本情報を設定でき、これらの設定内容が Agent の表示スタイルや機能を決定します。また、このページでは Agent に関する各種データを確認して継続的に利用を最適化したり、Agent を公開してより多くのユーザーにサービスを提供したりすることもできます。

### 機能エントリー

Agents プラットフォームにログインし、ホーム画面上部の「Agent を作成」をクリックします。Agent タイプで「Agent ワークフロー」を選択し、作成方法として「空白から作成」または「テンプレートから作成」を選択できます。Agent を作成すると、右側の設定入力欄に関連情報を入力できます。

### 画面説明

Agent 基本設定ページ
Agent アバター：Agent のアバターを設定します。カスタム画像をアップロードでき、JPG、PNG 形式に対応しています。

<Frame>
  <img src="/images/documentation/ch6_6.1.3.3_0010.png" alt="基本設定" />
</Frame>

Agent アバター設定
Agent 名：Agent の名前を設定します。
説明：Agent の用途に関する簡単な説明を設定します。
Agent タイプ：Agent のタイプを設定します。公開ページではタイプに応じて Agent が分類表示されます。
対話背景：Agent の対話ページの背景画像を設定します。カスタム背景画像をアップロードでき、JPG、PNG 形式に対応しています。推奨サイズは 1920\*1080 です。
音声入力：Agent の対話ページに音声入力機能を表示するかどうかを設定します。オンにすると、ユーザーは入力欄右側のマイクボタンをクリックして音声入力を行えます。
オープニングメッセージ：Agent のオープニングメッセージを設定します。ユーザーが初めて Agent ページを開いたとき、対話ウィンドウにオープニングメッセージの内容が表示されます。
おすすめ質問：Agent のおすすめ質問を設定します。ユーザーが初めて Agent ページを開いたとき、対話ウィンドウにおすすめ質問の入力ボタンが表示されます。

<Frame>
  <img src="/images/documentation/ch6_6.1.3.3_0011.png" alt="基本設定" />
</Frame>

Agent 基本情報設定
対話モデル：Agent が使用する大規模モデルの種類を設定します。注意：この設定は、後続のワークフローで計画された対話設定によって上書きされます。
Prompt：Agent の Prompt 内容を設定します。注意：この設定は、後続のワークフローで計画された対話設定によって上書きされます。
おすすめ質問のプライバシー保護キーワード：Agent のプライバシー保護キーワードを設定します。Agent はおすすめ質問を生成する際、プライバシーに関わる質問の生成を主体的に回避します。
リッチテキスト表示の有効化：リッチテキスト表示をオンにすると、Agent が出力する内容は Markdown 形式でレンダリングされます。リッチテキスト表示をオフにすると、Agent の出力内容はプレーンテキスト形式で表示されます。
Word から PDF への変換の有効化：Word から PDF への変換をオンにすると、ユーザーが対話ボックスにアップロードした Word ファイルは自動的に PDF 形式に変換され、後続の Agent によるファイル関連処理（OCR、文書解析など）に使用されます。
ナレッジベース引用の表示：ナレッジベース引用をオンにすると、Agent の出力内容に検索されたナレッジベースと具体的なファイルが表示され、ユーザーはカードをクリックして確認できます。
画像引用の表示：画像引用の表示をオンにすると、Agent の出力内容に検索された画像が表示され、ユーザーはカードをクリックして確認できます。
引用マークの表示：引用マークの表示をオンにすると、Agent の出力内容の文末に引用マークが付与され、ユーザーはマークをクリックしてその箇所の引用元を確認できます。

ナレッジベース引用
拡張質問の有効化：拡張質問をオンにすると、Agent は回答完了後にいくつかのおすすめ質問を生成し、ユーザーはそれをクリックしてすばやく質問を入力できます。
おすすめ質問の表示：おすすめ質問の表示をオンにすると、Agent はナレッジベースの内容に基づいておすすめ質問を生成し、ユーザーが初めて Agent ページを開いたとき、対話ウィンドウにおすすめ質問の入力ボタンが表示されます。
ナレッジベース：Agent が使用するナレッジベースを設定します。注意：この設定は、後続のワークフローで計画されたナレッジベース検索設定によって上書きされます。

ナレッジベースの追加
禁止用語審査：Agent が使用する禁止用語ライブラリを設定します。ユーザーの入力内容が禁止用語に該当した場合、Agent は自動的に検知してブロックします。

定時トリガー：Agent の自動実行時刻を設定します。設定した時刻に達すると、Agent は設定されたトリガー入力に基づいてワークフローを実行します。

### 機能概要

任意の期間を指定して、PV、UV、DAU、Agent の総数、および Token の総消費量を確認できます。部門別インタラクション量ランキング、日次平均会話トレンド、ユーザーアクティブトレンド、ページトラフィックトレンドなどのグラフも提供されます。

### 機能エントリー

Agents プラットフォームにログインし、ホーム画面上部の「Agent を作成」をクリックします。Agent タイプで「Agent ワークフロー」を選択し、作成方法として「空白から作成」または「テンプレートから作成」を選択できます。
禁止用語審査
禁止用語審査の追加：対応する禁止用語ライブラリを追加すると、ユーザーの入力内容に禁止用語が含まれる場合、Agent が自動的に「入力内容に禁止用語が含まれています。修正のうえ再度お試しください」と表示します。
