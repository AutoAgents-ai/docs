### 機能概要

ワークフローの実行中に、指定された出力情報を対象のナレッジベースに保存します。保存されたコンテンツは自動的に解析・分割処理され、他のナレッジベース検索モジュールから参照可能になり、ナレッジの動的な蓄積を実現します。入力時には、データ内容とデータセット名の両方を入力する必要があります。これら 2 項目は必須であり、入力しない場合、このコンポーネントは機能しません。

画面操作フローの説明
ナレッジベースへの保存モジュールをクリックして設定ページに入り、「追加」をクリックして新しいデータを追加します。

<Frame>
  <img src="/images/documentation/ch6_6.1.24.1_0072.png" alt="ナレッジベースへの保存" />
</Frame>

「高度な設定」をクリックすると詳細な設定を行えます。このうち「チャンクサイズ」はテキスト分割時の最大文字数を設定するもので、値を小さくするとチャンク数は増えますが検索精度が高くなります。「オーバーラップ率」は隣接するチャンク間の重複比率を設定するもので、コンテキストの連続性を保つのに役立ちます。
