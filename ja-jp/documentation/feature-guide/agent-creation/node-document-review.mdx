### モジュール紹介

ドキュメントの読み取りとレビューのシナリオに使用します。ユーザーがドキュメントをアップロードすると、システムは事前に設定した一括レビュー質問（最大 100 個）に基づいて一つずつ質問し、AI が回答します。CSV テンプレートによる質問の一括インポートにも対応しており、契約書レビュー、コンプライアンスチェックなどのシナリオに適しています。左側でドキュメントを入力し、大規模モデルで処理した後、回答内容として出力されます。

詳細な画面説明
右上で自分で質問を追加することも、テンプレートを使って質問を追加することもできます。
モデルは自由に選択でき、国内の主流モデルの大半に対応しています。
Prompt：モデルへのガイドワードです。この Prompt を調整することでモデルの対話の方向性を導くことができ、この内容は冒頭に固定されます。
