### モジュール紹介

特定の内容をユーザーに返答したい場合は、確定回答モジュールを使用できます。トリガー条件の判定が成立すると、ユーザーは「回答内容」テキストボックスに設定された内容をそのまま受け取ります。回答内容ノードが外部情報源にリンクされている場合、そのリンク情報が「回答内容」入力欄に設定された情報を上書きします。

### システム組み込み変数

使用文法
{{var}} は変数を参照することを表します
{{cTime}} 現在時刻 yyyy-MM-dd HH:mm:ss
{{cMills}} 現在のタイムスタンプ
{{cWeekdayNum}} 曜日（数字）
{{cWeekdayEn}} 曜日（英語）
{{cWeekdayEn2}} 曜日（英語略称）
{{cWeekdayCn}} 曜日（中国語）
