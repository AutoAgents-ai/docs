### モジュール紹介

一般的なモデル＋Prompt の Agent と比較して、Agent ノードはナレッジベース、ツール（MCP）、スキル（skill）を統合しており、より充実した機能を備えています。
Agent ノードは、Agent が各種の専門的な skill にアクセスするための入り口であると同時に、プラットフォームが Multi-Agent コラボレーションを実現するための重要なステップでもあります。

### 適用シナリオ

MCP や skill の機能を利用する必要がある場合は、いずれも Agent ノードを通じて実現できます。
その中で、
MCP はモデルにウェブ検索やブラウザ操作といった複雑なツール能力を持たせることができ、
skill はモデルに専門的な SOP（標準ワークフロー）を習得させることができます。
