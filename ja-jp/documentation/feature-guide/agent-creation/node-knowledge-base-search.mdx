### モジュール概要

ユーザーの質問を入力し、関連するナレッジベースに対してベクトル検索とキーワードのハイブリッド検索を行います。類似度のしきい値、ベクトルの重み、リコール件数、リランキングモデルの設定に対応しており、関連するナレッジが検索できた場合／できなかった場合に、それぞれ異なる下流フローをトリガーできます。
