---
title: "新しいノードタイプの追加"
---

◦ Agent ノード：Agent が目標に基づいてタスクを自動的に分解し、実行ステップをプランニングし、MCP ツール / ナレッジベース / スキルなどのリソースを動的にスケジューリングし、実行状態をリアルタイムで監視して異常時のリトライや戦略調整を行うことをサポートします。複雑な問題の自律的なクローズドループ処理を実現します。

  <img src="/images/documentation/ch6_6.1.39_0112.png" alt="新しいノードタイプの追加" />
</Frame>

◦ ドキュメントレビューノード：業務フローに基づいてレビュータスクを自動的にトリガーし、多段階のレビューフローを設定し、レビュー担当者と権限を柔軟に割り当て、レビューの進行状況と処理意見をリアルタイムで同期させることをサポートします。差し戻し、タイムアウト、異常な提出などの状況に対しては、自動的にフロー切り替えルールとリマインド通知をトリガーし、ドキュメントの提出・審査・修正・アーカイブに至る全プロセスのクローズドループ管理を実現します。
