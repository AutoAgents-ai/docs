### 機能概要

Agent アプリケーションの急速な発展に伴い、ツールの開発と接続にはさまざまな課題が生じています。
統一されたツール開発規範が存在しないため、効率が低下する。
プラットフォーム側で各種ツールへの適合を繰り返す必要があり、時間とコストが増大する。
高品質なツールの統合と運用の負担が非常に大きい。
MCP（Model Context Protocol）は Anthropic が発表したオープンスタンダードプロトコルであり、大規模モデルとツール・データソースの間に安全・標準的・効率的な接続チャネルを構築することを目的としています。ツールの実装形式が統一されておらずモデル間で汎用的に使いにくいといった課題を解決し、業界の主流なソリューションとして徐々に採用が進んでいます。
MCP 管理モジュールは、MCP サービスの作成、管理、設定を行うための中核ツールです。このモジュールは MCP サービスのデプロイと管理を簡素化し、ユーザーは直感的な画面から迅速に操作できます。
MCP を利用することで、外部サービスを標準化されたツールとして接続し、プラットフォームがより複雑なタスクを処理できるようになります。

### MCPサービスの作成と設定

### MCPサービスの作成

MCP 管理ページの「MCPサービスを作成」ボタンをクリックすると作成ページに移動し、このページで MCP サービスの基本情報を作成できます

<Frame>
  <img src="/images/documentation/ch6_6.8.1.4_0229.png" alt="サービスの作成と設定" />
</Frame>

<Frame>
  <img src="/images/documentation/ch6_6.8.1.4_0230.png" alt="サービスの作成と設定" />
</Frame>

対応するサービス情報を入力します：
サービス名：この MCP サービスの名称を設定します。
説明：この MCP サービスの機能を説明します。
インストール方式：サービスのインストール方式を選択します。現在 SSE と Streamable HTTP をサポートしています。
MCP 設定：MCP サービスの設定を入力します。JSON 形式で記述する必要があります。例：
{
"mcpServers":{
"ocr_edu":{
"url":"https://aip.baidubce.com/mcp/ocr_general/sse?Authorization=Bearer+<YOUR_ACCESS_TOKEN>"
}
}
}
「確定」をクリックすると、システムがこの MCP サービスのデプロイを開始します。

<Frame>
  <img src="/images/documentation/ch6_6.8.1.4_0231.png" alt="サービスの作成と設定" />
</Frame>
