### 機能概要

接続済みのすべてのサービスを一元的に表示し、概要とツールの詳細を確認できるため、サービスの稼働状況を統一的に監視・管理できます。

### 機能入口

Agent プラットフォームにログインし、「MCP管理」ページをクリックします。

<Frame>
  <img src="/images/documentation/ch6_6.8.2.2_0235.png" alt="サービス管理と監視" />
</Frame>

任意の MCP ツールをクリックします。

### 画面説明

### サービス管理と監視画面

MCP 概要：MCP ツールのサービス名、説明、インストール方式、MCP サービス設定を確認できます。
MCP ツール：MCP ツールのすべてのメソッドと対応する入力パラメータを確認できます。
