title: "評価タスクの作成"
---

### 操作手順

ステップ1：右上の【ルールを作成】ボタンをクリックします。
ステップ2（評価対象の設定）：評価タスク名、説明を入力し、評価対象（Agent）を選択し、評価実行時の並行数を設定します。
ステップ3（評価データセットの設定）：評価データセット、データ範囲（任意）を選択し、ユーザー入力（データセット内のどのフィールドを Agent への入力とするか）、画像（任意）、添付ファイル（任意）を選択します。
ステップ4（ルールとマッピングの設定）：評価ルール（単一または複数）を追加し、ルール内のフィールドマッピングに対応するパラメータのデータソースを選択します。
ステップ5：右下の【作成】または【作成して実行】ボタンを選択します。
