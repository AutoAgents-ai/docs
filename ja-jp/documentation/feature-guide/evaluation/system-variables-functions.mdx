### システム組み込み変数

### 使用方法

{{var}}は変数の参照を表します
{{var:defautValue}}は変数を参照し、デフォルト値を設定することを表します
{{@var}}は変数を参照し、変数が存在しない場合はこの式自体をそのまま表示することを表します
{{cTime}}現在の日付と時刻 yyyy-MM-dd HH:mm:ss
{{cDate}}現在の日付 yyyy-MM-dd
{{cYear}}現在の年 yyyy

### {{cMonth}}現在の月

### {{cDay}}現在の日

{{cHHmmss}}現在の時刻 HH:mm:ss

### {{cMills}}現在のタイムスタンプ

{{cWeekdayNum}}曜日（数字）
{{cWeekdayEn}}曜日（英語）
{{cWeekdayEn2}}曜日（英語略称）
{{cWeekdayCn}}曜日（中国語）
{{\_input}}すべての入力パラメータ情報
{{\_state}}入力状態パラメータ情報
{{userChatInput}}入力テキストパラメータ情報
{{\_images\_}}入力画像パラメータ情報
{{\_files\_}}入力ファイルパラメータ情報
{{\$*db_type*}}Agentが接続しているデータベースの種類情報
{{\$*db_schema*}}Agentが接続しているデータベースのテーブル構造情報
{{\$kbIdList}}ユーザーが選択したナレッジベースのIDリストを取得
{{systemContext}}現在のシステム環境とログインユーザー情報を取得（v1.9.0.0+）
