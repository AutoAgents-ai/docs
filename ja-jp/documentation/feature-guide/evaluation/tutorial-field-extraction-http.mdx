title: "上級：フィールド抽出＋HTTPモジュール"
---

「フィールド抽出」モジュールは、入力された内容を解析して必要なフィールドを抽出できます。「HTTP呼び出し」ツールは、サードパーティシステムに接続し、入力パラメータと出力パラメータを設定することで、サードパーティシステムとの通信を実現し、Agent の活用シーンを大きく拡張します。
今回の事例では、主に「フィールド抽出」と「HTTP呼び出し」モジュールを利用して、シンプルな会議室予約 Agent を構築し、自然言語による会議室予約を Agent の力で実現します。

### 基本設定

「会議室予約くん」Agent として、会議室の状況照会と会議室の予約機能を実現したいと考えています。そのうち会議室の照会と予約の機能は、既存の会議室予約システムとの通信が必要であり、その基本情報の設定は以下の通りです。

### キャンバス設計

Agent の大まかな設計思想は次の通りです。「情報分類」モジュールでユーザーの意図（会議室の照会／会議室の予約／その他）を判定し、意図に応じて異なるデータ通信をトリガーし、以降のステップを実行します。

### 会議室照会機能の設計

以下は「会議室照会」機能の設計図です。コアとなるフローは、「情報分類」モジュールでユーザーの意図を判定し、「会議室の照会」に関するリクエストであれば、続く「HTTP呼び出し」をトリガーして、会議室システムへ現在の会議室予約状況を照会するというものです。

<Frame>
  <img src="/images/documentation/ch6_6.10.11.3_0279.png" alt="上級：フィールド抽出＋HTTPモジュール" />
</Frame>

接続線1：「ユーザー質問」モジュールを通じてユーザーの入力情報を取得し、「ユーザー質問」として出力します
「情報分類」モジュールは「情報入力」を通じてユーザーの質問を受け取り、その後以下の手順を実行します：
モジュールの prompt を「ユーザー質問」および会話コンテキストとともに Tiangong 大規模言語モデルに渡し、分類処理を行います
ユーザー情報の種類を判定し、分類処理の結果を返して、次のモジュールの機能をトリガーします
接続線2：ユーザーの意図が「会議室の照会」であれば、「HTTP呼び出し」モジュールがトリガーされます
「HTTP呼び出し」モジュールには「会議室照会」用のリクエスト URL が設定されており、一方で照会リクエストを受け取り（接続線3）、もう一方で照会結果を出力（接続線4）し、現在の会議室の状況情報を次のモジュールへ渡します
接続線4：「インテリジェント対話」モジュールは会議室の予約状況情報を受け取った後、以下の処理を行います
「インテリジェント対話」モジュールは上記3つの情報入力を受け取った後、以下の手順を実行します：
プロンプト、ユーザーの質問、および HTTP 呼び出しの照会結果を Tiangong 大規模言語モデルに渡します
大規模言語モデルが加工処理を行い、プロンプトに基づいてユーザーへ回答します

### 会議室予約機能の設計

一方「会議室予約」モジュールでは、「情報分類」モジュールでユーザーの意図を判定し、「会議室の予約」に関するリクエストであれば以降のフローがトリガーされます。具体的な接続線と機能の説明は以下の通りです。

<Frame>
  <img src="/images/documentation/ch6_6.10.11.4_0280.png" alt="上級：フィールド抽出＋HTTPモジュール" />
</Frame>

接続線5：ユーザーの意図が「会議室の予約」であれば、「フィールド抽出」モジュールがトリガーされます
「フィールド抽出」モジュールの主な機能は、ユーザーが入力した情報を構造化し、JSON 形式の内容として出力することです
例えば「天空之門を予約、13:00〜18:00、予約者：アシスタント」と入力すると、フィールド抽出後の内容は「{"会議室名":"天空之門","開始時間":"13:00","終了時間":"18:00","予約者氏名":"アシスタント"}」となります
接続線6：予約情報をより適切に会議室予約システムへ送信するために、今回は追加で「情報加工」モジュールを設けています。上記で渡された JSON を、インターフェースが必要とする形式へさらに加工し、接続線7 を通じて「HTTP呼び出し」モジュールへ出力し、会議室予約システムへ渡します。このステップは実際の必要に応じて選択的に追加できます
接続線8：予約リクエストの発行が成功すると、「インテリジェント対話」モジュールがトリガーされ、ユーザーに予約完了を通知するとともに、ユーザーの予約情報を同期します（接続線9 を通じてユーザーの予約情報を同期）
接続線10：会議室の予約にはユーザーから必要な情報の提供が必要です。ユーザーが提供する情報に不足がある場合を防ぐため、「不足情報の抽出」というプロンプトを設定し、必要な情報の提供をユーザーに促します

以上が、シンプルな会議室予約 Agent の構築についての紹介です。「フィールド抽出」モジュールと「HTTP呼び出し」モジュールを柔軟に活用することで、個人／業務のシーンに合わせたさらに多くの Agent を作成できます。
