ロールプレイボットは、よく利用される AI Agent の一種です。AI に特定のキャラクターを演じさせ、指定した知識やキャラクターらしい文体を与えることで、ロールプレイボットを構築できます。今回は「孫悟空」を演じる AI Agent を例に、キャンバス設計のロジックを紹介し、Agent のオーケストレーションロジックに素早く慣れていただきます。

### キャンバス設計

Agent を初めて作成する際、システムは自動的に「ユーザー質問」モジュールと「インテリジェント対話」モジュールを作成し、今回の AI ロールプレイボットの機能を実現します。その主なロジックは以下の通りです。
「ユーザー質問」モジュールを通じてユーザーの入力情報を取得し、「ユーザー質問」として出力します。
「インテリジェント対話」モジュールは「情報入力」を通じてユーザーの質問を受け取り、その後以下の手順を実行します：
プロンプト、入力情報、および会話コンテキスト（3件）を Tiangong 大規模言語モデルに渡します。
大規模言語モデルが加工処理を行い、ユーザーへ回答します。

### 最適化のご提案

ここでは、大規模言語モデルの回答の創造性というパラメータも調整しています。
機械学習と人工知能の文脈において、Temperature（回答の創造性）は、一般的にテキストやサンプルを生成する際のパラメータを指し、特に Softmax 関数のような確率分布を用いる場合に使われます。このパラメータは、モデルが生成する出力の多様性を制御します。
モデルは可能な各出力の確率を計算し、最も確率の高いものを最終的な出力として選択します。Temperature パラメータは、これらの確率分布の平坦さに影響を与える制御因子を導入します。Temperature が高いほど確率分布はより平坦になり、モデルはより多様性の高い出力を生成しやすくなります。一方、Temperature が低いほど確率分布はより鋭くなり、モデルは最も可能性の高い出力を選びやすくなります。
今回は「孫悟空」というキャラクターの回答内容がより生き生きとした創造性のあるものになるよう、数値を 0.8 に設定しました。ここで簡単な比較を行うことができます。左右はそれぞれ創造性を 0 と 0.8 に設定した場合のインテリジェントな回答を示しています。

### 回答の創造性を0.8に設定

創造性が 0.8 の場合、AI の回答内容がより多角的になり、「世界の理想的な統一を実現する」といったあまり見られない目的が現れることが明確に感じられます。一方、創造性が 0 の場合は、「師匠を守る／悪を退治する」といったより厳密で慎重な回答へと傾く傾向があります。
また、Agent を設計する過程では、プロンプトの設計を継続的に最適化し、関連パラメータを調整していくことで、最終的に満足度の高い自分専用の AI Agent を得ることができます。
