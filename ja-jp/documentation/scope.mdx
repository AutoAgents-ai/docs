### 対象者

本マニュアルは、Agents プラットフォームを利用する顧客組織内のプラットフォーム管理者、業務設定担当者、アプリケーション構築担当者、および一般利用者を対象としています。各ロールは、権限範囲に応じてリソース管理、機能構築、アプリケーション公開、日常利用などの作業を行います。

| 適用次元 | 説明 |
| --- | --- |
| 組織対象 | 本社部門、支社・拠点、プロジェクトチーム、専門タスクフォースなど |
| 業務シーン | ナレッジQ&A、プロセス連携、インテリジェントアシスタント、アプリケーションパッケージング、成果展示など |
| 利用目標 | 迅速な構築、継続的な最適化、統一的なガバナンス、協働効率の向上 |
| 想定読者 | 顧客側の管理担当者、構築担当者、実際の利用者 |

### 適用シーン

Agents プラットフォームは、ナレッジQ&A、業務連携、業務データ入力、データ照会、アプリケーション展示、運営支援、成果公開などのシーンに適しており、特に低い導入ハードルと短いサイクルでデジタル能力の構築と継続的な改善を進めたい業務部門に適しています。

### 適用範囲の境界

本マニュアルは主にプラットフォームの業務利用と設定方法について説明するものであり、インフラのデプロイ手順、ネットワークおよびセキュリティ制度、ミドルウェアの専門的な運用ドキュメントの代替とはなりません。デプロイ、リソース申請、ポート開放、データベースの高可用性、災害復旧などに関わる内容については、『インテリジェントエージェントプラットフォーム デプロイメントプラン – V2.0』も併せて参照してください。
