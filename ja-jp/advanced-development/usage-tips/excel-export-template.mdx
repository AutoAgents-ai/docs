---
title: "Excel エクスポートテンプレートの使用方法"
---

「Excel 生成」コンポーネントを使用すると、JSON データで XLSX テンプレートを埋めることができます。具体的な構文とサンプルテンプレートは以下のとおりです。

## 1. プレースホルダーの置換

形式：`{{expression}}`。Excel セル内で直接プレースホルダーを使用してデータを置換します。

対応するデータアクセス方法：

- 単純な変数：`{{var1}}`
- ネストされたオブジェクト：`{{other.var3}}`
- 配列要素：`{{list1.[0].var1}}`
- 深いネスト：`{{data.user.profile.name}}`

## 2. 縦方向ループ（範囲ループ）

形式：`<for item in list>...</for>`。垂直方向に複数行のデータを生成するために使用します：

```
<for item in list1>
{{item.var1}}  {{item.var2}}  {{item.detail.var3}}
</for>
```

特徴：

- データ配列の長さに応じて対応する行数を自動生成
- 複数行テンプレートに対応（ループ範囲内に複数行を定義可能）
- ループ内でネストされたオブジェクトや配列を使用可能

## 3. 横方向ループ

形式：`<hfor item in list>...</hfor>`。水平方向に複数列のデータを生成するために使用します：

```
<hfor item in demo.list2>
{{item.var1}}  {{item.detail.var2}}
</hfor>
```

特徴：

- データが右方向に複数列として展開される
- 表のヘッダーや横方向のデータ表示に適している
- ループ変数 `item` は現在処理中のデータ項目を表す

## 4. 画像の挿入

形式：`{{@expression}}`。Excel の図形内で画像プレースホルダーを使用します：

```
{{@imgurl1}}                // 静态图片
{{@item.aaImage}}           // 循环中的动态图片
{{@data.other.imgurl2}}     // 嵌套对象中的图片
```

対応する画像形式：

- URL 画像：`https://example.com/image.jpg`
- Base64 形式：`data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA...`

画像処理の特性：

- 画像形式（PNG、JPEG）を自動識別
- 画像をセルサイズに自動的にフィット
- ループ内で動的に画像を挿入可能
- 元の図形の位置とサイズ情報を保持
