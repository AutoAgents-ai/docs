---
title: "データ型変換"
---

一部のシナリオでは、通常のテキスト / URL をプラットフォーム内部の「画像」「ファイル」タイプに変換する必要があり、「情報処理」コンポーネントを通じて変換を行うことができます。

<Frame>
  <img src="/images/advanced-development/adv_004.png" alt="情報処理コンポーネントによるデータ型変換" />
</Frame>

## 画像 URL アドレスを画像情報タイプに変換

```json
[{"url": "http://你的图片URL地址"}]
```

## ファイル URL アドレスをファイル情報タイプに変換

```json
[
  {
    "fileName": "你的文件名.docx",
    "fileUrl": "https://你的文件URL地址"
  }
]
```
