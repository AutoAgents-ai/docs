---
title: "ナレッジベース応用 - 高度なクエリの例"
---

「ナレッジベース検索」コンポーネントの情報入力では高度なクエリ設定に対応しており、グループごとの並列リコール、指定ファイルからのリコール、グループごとに異なる重みと類似度の設定などをサポートします。

## 例

```json
{
  "keywords": "2025年3月18日晚峰短信的内容是什么？",
  "overwrite": "true",
  // 可以固定指定，也可以通过{{$kbIdList}}获取用户选择的知识库ID列表动态指定
  "kbIdList": [2, 3, 4, 5, 6],
  "searchGroups": [
    {
      "kbIdList": [5],
      "topK": 22,
      "fileNameKeywords": ["特高压", "运行规定"]
    },
    {
      "kbIdList": [2, 3, 4, 5, 6],
      "topK": 6
    }
  ]
}
```

## 高度なクエリフィールドの説明

| フィールド | 説明 |
| --- | --- |
| `keywords` | クエリキーワード |
| `overwrite` | ナレッジベース検索コンポーネントで選択されたナレッジベースを上書きするかどうか。デフォルトは `true`。`false` の場合、ナレッジベース検索コンポーネントで選択されたナレッジベースと `kbIdList` を結合します |
| `kbIdList` | 指定するナレッジベース ID の全体集合。`searchGroups` がある場合は、各 `searchGroups` との積集合を取ってグループ化します。固定で指定することも、`{{$kbIdList}}` でユーザーが選択したナレッジベース ID リストを取得して動的に指定することもできます |
| `searchGroups[]` | グループの配列。ナレッジベースをグループ化して並列にクエリします |
| `searchGroups[].kbIdList[]` | ナレッジベース ID の配列。そのグループのナレッジベース ID を指定します |
| `searchGroups[].topK` | リコール数 |
| `searchGroups[].fileNameKeywords[]` | 指定するファイル名キーワードのあいまい検索。`%` はあいまい一致する部分を表します。例：`%年%月%晚峰短信` |
| `searchGroups[].fileNameKeywordsTopK` | 指定ファイルの関連チャンクのリコール数。デフォルトは `topK` と同じで、`fileNameKeywords` で指定したファイルからリコールするチャンク数を表します。この数が `topK` より小さい場合、`(topK - fileNameKeywordsTopK)` は同じナレッジベース内の指定外ファイルからリコールするチャンク数を表します |
| `similar` | 類似度のしきい値。デフォルトはナレッジベース検索コンポーネントの値と同じ |
| `vectorSimilarWeight` | ベクトル類似度の重み。デフォルトはナレッジベース検索コンポーネントの値と同じ |
| `enableRerank` | 再ランキングのスイッチ、`true`/`false`。デフォルトはナレッジベース検索コンポーネントの値と同じ |
| `rerankModelType` | 再ランキングモデル。デフォルトはナレッジベース検索コンポーネントの値と同じ |
| `rerankSimilarLimit` | 再ランキングのしきい値。デフォルトはナレッジベース検索コンポーネントの値と同じ |
| `rerankTopK` | 再ランキングのリコール数。デフォルトはナレッジベース検索コンポーネントの値と同じ |
