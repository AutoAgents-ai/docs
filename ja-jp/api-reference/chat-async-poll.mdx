---
title: "Agentチャット非ストリーミング（非同期）結果ポーリング取得インターフェース"
---

[Agentチャット非ストリーミングインターフェース（非同期）](/ja-jp/api-reference/chat-async)と組み合わせて使用し、`requestId` によって非同期実行結果をポーリングで取得します。

## リクエストURL

```
{{host}}/openapi/agents/chat/completions/async/polling/v1?agentId={}&requestId={}
```

または

```
{{host}}/openapi/v2/chat/completions/async/polling?agentId={}&requestId={}
```

## リクエストメソッド

`GET`

## リクエストヘッダー

[インターフェース仕様](/ja-jp/api-reference/overview)を参照してください。Agent Token ✅、個人シークレットキー ✅ に対応しています。

## リクエストパラメータ

| パラメータ | 必須 | 説明 |
| --- | --- | --- |
| `agentId` | はい | Agent の ID |
| `requestId` | はい | リクエスト ID（[非同期インターフェース](/ja-jp/api-reference/chat-async)が返却する `data.requestId`） |

リクエスト例：

```
agentId=4328bb87fdd145e2a25ec53bsada27c95
requestId=2498bb87fdd145e2a25ec53b50b27c95
```

## cURL の例

`{{host}}` は実際の環境アドレスに、`{authKey}`/`{authSecret}` はご自身の認証情報に置き換えてください（[インターフェース仕様](/ja-jp/api-reference/overview)を参照）：

```bash
curl -X GET "{{host}}/openapi/agents/chat/completions/async/polling/v1" \
  -H "Authorization: Bearer {authKey}.{authSecret}" \
  -G \
  --data-urlencode "agentId=4328bb87fdd145e2a25ec53bsada27c95" \
  --data-urlencode "requestId=2498bb87fdd145e2a25ec53b50b27c95"
```

## レスポンスボディ

| フィールド | 説明 |
| --- | --- |
| `code` | レスポンス結果コード。`1` は成功、それ以外は失敗を示します |
| `msg` | エラーメッセージ |
| `data.requestId` | バックエンドログのリクエスト ID。問題調査時にこの ID を使ってログを検索できます |
| `data.output` | [Agentチャット非ストリーミングインターフェース（同期）](/ja-jp/api-reference/chat-sync)の返却ボディの構造と同一で、状態が `DONE` のときのみ値が入ります |
| `data.state` | 非同期タスクの実行状態：`0`、`1`、`2`、`3` |

```sql
NOT_EXIST(0, "存在しません"),
RUNNING(1, "実行中"),
DONE(2, "実行終了"),
EXCEPTION(3, "実行異常")
```
