---
title: "データセットの削除"
---

## リクエストURL

```
{{host}}/openapi/kb/deleteDs
```

## リクエストメソッド

`POST`

## リクエストヘッダー

[インターフェース仕様](/ja-jp/api-reference/overview)を参照してください。Agent Token は ❌ 非対応、個人シークレットキーのみ ✅ 対応です。

<Warning>
本インターフェースは個人シークレットキー（`authKey` / `authSecret`）による認証呼び出しのみサポートしており、Agent Token による呼び出しはサポートしていません。
</Warning>

## リクエストボディパラメータ

| パラメータ | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `dsIdList` | array\<number\> | はい | 削除対象のデータセットIDリスト |

## リクエストボディの例

```json
{
    "dsIdList": [2343, 2233]
}
```

## レスポンスボディ

| フィールド | 説明 |
| --- | --- |
| `code` | レスポンス結果コード。`1` は成功、それ以外は失敗を示します |
| `msg` | エラーメッセージ |
| `data` | 削除に成功したかどうか（`boolean`） |

## レスポンスボディの例

```json
{
    "code": 1,
    "msg": "操作に成功しました",
    "data": true
}
```

<Info>
データセットの作成・変更については[データセットの作成とタスクの開始](/ja-jp/api-reference/dataset-create)、[データセットの変更とタスクの再開](/ja-jp/api-reference/dataset-update)インターフェースを参照してください。
</Info>
