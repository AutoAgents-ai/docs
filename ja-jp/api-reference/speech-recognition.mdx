title: "音声認識インターフェース"
---

## リクエストURL

```
{{host}}/openapi/voice/recognize
```

## リクエストメソッド

`POST`

## リクエストヘッダー

[インターフェース仕様](/ja-jp/api-reference/overview)を参照してください。Agent Token ❌、個人シークレットキー ✅ に対応しています。

<Info>
本インターフェースはヘッダーに `Content-Type: multipart/form-data` を指定する必要があります。
</Info>

## リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `file` | file | はい | アップロードするファイル。音声ファイル、`wav` 形式、16kHz、モノラル |

## cURL の例

`{{host}}` は実際の環境アドレスに、`{authKey}`/`{authSecret}` はご自身の認証情報に置き換えてください（[インターフェース仕様](/ja-jp/api-reference/overview)を参照）：

```bash
curl -X POST "{{host}}/openapi/voice/recognize" \
  -H "Authorization: Bearer {authKey}.{authSecret}" \
  -F "file=@/path/to/your/audio.wav"
```

## レスポンスボディ

| フィールド | 説明 |
| --- | --- |
| `code` | レスポンス結果コード。`1` は成功、それ以外は失敗を示します |
| `msg` | エラーメッセージ |
| `data` | 音声認識結果テキスト |

## レスポンスボディの例

```json
{
    "code": 1,
    "msg": "操作に成功しました",
    "data": "北京の天気"
}
```
