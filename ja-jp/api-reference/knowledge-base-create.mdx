---
title: "ナレッジベースの作成"
---

## リクエストURL

```
{{host}}/openapi/kb/createKb
```

## リクエストメソッド

`POST`

## リクエストヘッダー

[インターフェース仕様](/ja-jp/api-reference/overview)を参照してください。Agent Token は ❌ 非対応、個人シークレットキーのみ ✅ 対応です。

<Warning>
本インターフェースは個人シークレットキー（`authKey` / `authSecret`）による認証呼び出しのみサポートしており、Agent Token による呼び出しはサポートしていません。
</Warning>

## リクエストボディパラメータ

| パラメータ | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `name` | string | はい | ナレッジベース名 |
| `description` | string | いいえ | 説明 |
| `avatarUrl` | string | いいえ | アイコンURL |
| `vectorModel` | string | はい | ベクトルモデル（Embeddingモデル） |

## リクエストボディの例

```json
{
    "name": "test",
    "description": "説明",
    "vectorModel": "oneapi-xinference:bce-embedding",
    "avatarUrl": "/assets/avatar/63.png"
}
```

<Info>
`vectorModel` は、現在の環境で実際に利用可能なベクトルモデル（Embeddingモデル）の識別子に置き換えてください。
</Info>

## レスポンスボディ

| フィールド | 説明 |
| --- | --- |
| `code` | レスポンス結果コード。`1` は成功、それ以外は失敗を示します |
| `msg` | エラーメッセージ |
| `data` | 新規作成されたナレッジベースのID（`kbId`） |

## レスポンスボディの例

```json
{
    "code": 1,
    "msg": "操作に成功しました",
    "data": 121
}
```

<Info>
ナレッジベース作成後に返される `kbId` は、[データセットの作成とタスクの開始](/ja-jp/api-reference/dataset-create)インターフェースの `kbId` パラメータとして使用でき、当該ナレッジベースにデータセットを追加できます。
</Info>
