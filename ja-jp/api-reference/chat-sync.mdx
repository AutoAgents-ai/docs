---
title: "Agentチャット非ストリーミングインターフェース（同期）"
---

リクエストパラメータは [Agentチャットストリーミングインターフェース](/ja-jp/api-reference/chat-stream) とほぼ同一ですが、本インターフェースは完全なレスポンス結果を一度に返却する点が異なります（SSE ストリームではありません）。

## リクエストURL

```
{{host}}/openapi/agents/chat/completions/v1
```

または

```
{{host}}/openapi/v2/chat/completions
```

## リクエストメソッド

`POST`

## リクエストヘッダー

[Agentチャットストリーミングインターフェース](/ja-jp/api-reference/chat-stream#リクエストヘッダー)と同一です。Agent Token ✅、個人シークレットキー ✅ に対応しており、`X-username` は任意です。

## リクエストボディパラメータ

パラメータは[ストリーミングインターフェースのリクエストボディパラメータ](/ja-jp/api-reference/chat-stream#リクエストボディパラメータ)と完全に同一です（`agentId`、`chatId`、`userChatInput`、`state`、`buttonKey`、`images`、`files`、`formData`、`debug`）。

## リクエストボディの例

```json
{
    "agentId":"a2207c2f6d3d44d2b4a5dae5b5593750",
    "chatId": null,
    "userChatInput":"Mybatis",
    "images":[{"url":"your image url here"}],
    "files":[],
    "state":{
        "yourKey1":"yourValue1",
        "yourKey2":"yourValue2"
    },
    "buttonKey":"按钮id或者名字",
    "debug":false
}
```

## cURL の例

`{{host}}` は実際の環境アドレスに、`{authKey}`/`{authSecret}` はご自身の認証情報に置き換えてください（[インターフェース仕様](/ja-jp/api-reference/overview)を参照）：

```bash
curl -X POST "{{host}}/openapi/agents/chat/completions/v1" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer {authKey}.{authSecret}" \
  -d '{
    "agentId":"a2207c2f6d3d44d2b4a5dae5b5593750",
    "chatId": null,
    "userChatInput":"Mybatis",
    "images":[{"url":"your image url here"}],
    "files":[],
    "state":{
        "yourKey1":"yourValue1",
        "yourKey2":"yourValue2"
    },
    "buttonKey":"按钮id或者名字",
    "debug":false
}'
```

## レスポンスボディ

| フィールド | 説明 |
| --- | --- |
| `chatId` | 対話 ID |
| `conversationId` | 現在の会話 ID。1 回の対話には複数回の会話が含まれます |
| `state` | 渡された環境変数パラメータ。key/value はそのままの値で返却されます |
| `memory` | Agent の実行過程で生成された変数情報（key/value）。例：`{"memoryKey1":"memoryValue1"}` |
| `choices` | 返信内容の配列。複数の返信内容が含まれる場合があり、各要素の構造は[ストリーミングレスポンスボディ](/ja-jp/api-reference/chat-stream#ストリーミングレスポンスボディ)内の単一メッセージと同一です（`messageId`、`type`、`componentName`、`content`、`complete`、`finish`、`status`、`role`、`bill`、`referenceType`、`reference` などのフィールドの意味も同一です） |

<Info>
`choices` 内では、最後の `finish:true` を示す終了メッセージを除き、各メッセージが1回の独立した返信を表します（1回の会話に複数回の返信が含まれる場合があります）。
</Info>
