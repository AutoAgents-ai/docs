## リクエストURL

```
{{host}}/openapi/agents/chat/stream/v1
```

または

```
{{host}}/openapi/v2/chat/stream
```

## リクエストメソッド

`POST`

## リクエストヘッダー

[インターフェース仕様](/ja-jp/api-reference/overview)の認証方式の章を参照してください。Agent Token ✅、個人シークレットキー ✅ に対応しています。

| ヘッダー | 説明 |
| --- | --- |
| `X-username` | `{Your UserName}`。ユーザーのログイン名で、必須ではありません。指定した場合、システムはこのログイン名の身元でインターフェースを呼び出し、アクセスログなどはすべてこのユーザー名で記録されます。指定しない場合は、デフォルトで Token の所有者を呼び出し元の身元として記録します。（v1.9.3+） |

## リクエストボディパラメータ

| パラメータ | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `agentId` | string | はい | Agent の UUID |
| `chatId` | string | いいえ | 対話 ID。必須ではなく、最初の会話では指定不要です。後続の会話でコンテキストを利用したい場合は、次回のリクエストで前回のストリームレスポンスボディに含まれる `chatId` を指定する必要があります |
| `userChatInput` | string | はい | ユーザー入力 |
| `state` | object | いいえ | 環境変数パラメータを渡します。key/value は呼び出し側が自由に定義できます。Agent オーケストレーションでは `{{_state.yourKey}}` によって対応するパラメータを取得できます。例：`{"yourKey1":"yourValue1","yourKey2":"yourValue2"}` |
| `buttonKey` | string | いいえ | ボタン名またはボタン ID |
| `images` | array | いいえ | 画像による質問パラメータ。画像 URL の指定に対応し、Data URI の指定にも対応しています（AIチャットコンポーネントと画像質問コンポーネントで対応、他のコンポーネントは非対応）。例：`[{"url":"your image url here"}]` |
| `files` | array | いいえ | ドキュメント質問/ドキュメント審査用。下記の例を参照してください |
| `formData` | object | いいえ | フォーム入力。`formConfig` はフォームの表示設定を表し、`values` はユーザーの key-value 形式の入力を表します。key は表示設定内の `fields` の key に対応します |
| `debug` | boolean | いいえ | デバッグモードを有効にするかどうか。デフォルトは `false`。デバッグモードを有効にすると、各リクエストの入力パラメータ、出力パラメータ、例外情報を詳細に記録するため、内容が多くなります。有効にしない場合は、異常な呼び出しの情報のみ記録されます。本番環境では `false` に設定するか、指定しないことを推奨します |

```json
    "fileUrl": "https://test.agentspro.cn/api/fs/66979252197ded4838301ac4", // fileIdとfileUrlはいずれか一方が必須
```

## ストリーミングレスポンスボディ

レスポンスは SSE ストリームであり、各行は `data:` で始まり、1 つの JSON オブジェクトを伴います。

| フィールド | 説明 |
| --- | --- |
| `chatId` | 対話 ID |
| `conversationId` | 現在の会話 ID。1 回の対話には複数回の会話が含まれます |
| `messageId` | メッセージ ID。特定の返信メッセージを識別し、いいね/イマイチに使用できます。`complete=true&finish=false` のときに値が入ります |
| `type` | メッセージタイプ。下表を参照してください |
| `componentName` | 現在のコンポーネント名 |
| `content` | ストリーミングコンテンツ。形式は `type` によって変化します |
| `reasoningContent` | 思考・推論内容。思考モデル（deepseek-R1 など）のみがこのフィールドを返却対応しています |
| `thinkingElapsedMillSecs` | 思考・推論の所要時間（ミリ秒単位）。思考モデルのみがこのフィールドを返却対応しています |
| `complete` | `true` の場合、ストリーミングの1回の会話内における、ある返信の終了を表します（1回の会話に複数回の返信が発生する場合があります） |
| `finish` | `true` の場合、ストリーミングの1回の会話リクエストがすべて終了したことを表します |
| `status` | メッセージの状態：`1` は正常メッセージ、`0` は失敗メッセージ、`-1` は異常メッセージ |
| `role` | 現在のメッセージの役割。一般的にはユーザー情報または Agent 情報（アバター、名前など） |
| `bill` | ストリーミングの1回の会話内における、ある返信の終了時（`complete=true`）の Token 消費状況 |
| `referenceType` | 引用タイプ：`web_search`（Web検索）、`kb_search`（ナレッジベース検索）、`kb_search_img_list`（ナレッジベース画像検索） |
| `reference` | 引用内容。形式は `referenceType` によって変化します |
| `references` | `Map<$referenceType, $reference>`。1回の呼び出しで複数種類の引用内容が発生した場合、複数の引用内容をまとめて出力します。key は引用タイプ、value は引用内容です。ストリーミングインターフェースでは通常まとめて出力されませんが、非ストリーミングインターフェースではまとめて出力される場合があります |

### `type` の値

| 値 | 説明 |
| --- | --- |
| `text` | 通常のテキスト |
| `markdown` | markdown 形式 |
| `pic` | 画像のアドレス。主にテキストから画像生成する場合に使用 |
| `buttons` | オーケストレーション内のボタンメッセージ。フォームを含む場合もあります |
| `feedback` | フィードバック。複数 Agent が連携する際に、あるAgentの結果状況をフィードバックし、後続のフローを進めるために使用します。フィードバックインターフェースは[Agentフィードバックインターフェース](/ja-jp/api-reference/agent-feedback)を参照してください |
| `chart` | SQL クエリ結果を可視化したチャート情報 |
| `table` | SQL クエリの結果情報 |
| `result_file` | 生成されたファイル |

`buttons` の例：

```json
{"buttonConfigs":[{"label":"退出业务流程","key":"e09b35e8-23f2-412c-8b53-5e45032afe9c"}],"fileContrast":false,"fileReview":false,"inputText":true,"uploadFile":false,"uploadImage":false}
```

`feedback` の例：
