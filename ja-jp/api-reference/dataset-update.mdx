---
title: "データセットの変更とタスクの再開"
---

## リクエストURL

```
{{host}}/openapi/kb/modifyDsAndTask
```

## リクエストメソッド

`POST`

## リクエストヘッダー

[インターフェース仕様](/ja-jp/api-reference/overview)を参照してください。Agent Token は ❌ 非対応、個人シークレットキーのみ ✅ 対応です。

<Warning>
本インターフェースは個人シークレットキー（`authKey` / `authSecret`）による認証呼び出しのみサポートしており、Agent Token による呼び出しはサポートしていません。
</Warning>

## リクエストボディパラメータ

| パラメータ | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `id` | number | はい | 変更対象のデータセットID（[データセットの作成とタスクの開始](/ja-jp/api-reference/dataset-create)インターフェースが返す `dsId`） |
| `fileId` | string | はい | アップロードしたファイルのID（[ファイルアップロード](/ja-jp/api-reference/file-upload)インターフェースで取得） |
| `name` | string | はい | データセット名 |
| `extJson` | string (JSON) | いいえ | 拡張フィールド。JSON文字列形式で、チャンク分割・解析方式などを設定するために使用します（[データセットの作成とタスクの開始](/ja-jp/api-reference/dataset-create#リクエストボディパラメータ)の解析設定を参照可能） |

## リクエストボディの例

```json
{
    "id": 123,
    "fileId": "67dccd3ae1138d0f6d12ca6a",
    "name": "データセット名",
    "extJson": "{}"
}
```

## レスポンスボディ

| フィールド | 説明 |
| --- | --- |
| `code` | レスポンス結果コード。`1` は成功、それ以外は失敗を示します |
| `msg` | エラーメッセージ |
| `data` | 変更後のデータセットID |

## レスポンスボディの例

```json
{
    "code": 1,
    "msg": "操作に成功しました",
    "data": 123
}
```

<Info>
データセットを削除する場合は[データセットの削除](/ja-jp/api-reference/dataset-delete)インターフェースを使用してください。
</Info>
