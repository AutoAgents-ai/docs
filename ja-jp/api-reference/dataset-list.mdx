---
title: "データセット一覧の取得"
---

## リクエストURL

```
{{host}}/openapi/kb/ds/query
```

## リクエストメソッド

`POST`

## リクエストヘッダー

[インターフェース仕様](/ja-jp/api-reference/overview)を参照してください。Agent Token ❌、個人シークレットキー ✅ に対応しています。

## リクエストボディパラメータ

| パラメータ | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `kbId` | number | はい | ナレッジベースID（例：`123`） |
| `pageNum` | number | いいえ | ページ番号 |
| `pageSize` | number | いいえ | ページあたりの件数 |
| `parentId` | number | いいえ | 親ID。指定フォルダ配下のデータセットを検索する際に使用 |
| `keywords` | string | いいえ | データセット名 |
| `fileIds` | array | いいえ | ファイルIDリスト（例：`["file_001", "file_002", "file_003"]`） |
| `dsIds` | array | いいえ | データセットIDリスト（例：`[1001, 1002, 1003, 1004]`） |
| `taskStatus` | number | いいえ | タスク状態：`0` 未実行、`1` 実行中、`2` 実行成功、`3` 実行失敗、`4` キャンセル済み |
| `approvalState` | number | いいえ | 審査状態：`1` 審査中、`2` 承認済み、`3` 拒否済み、`4` キャンセル済み |
| `notSelf` | boolean | いいえ | 自分が作成したデータセットを除外するかどうか（例：`false`） |

## リクエストボディの例

```json
{
  "pageNum": 1,
  "pageSize": 20,
  "keywords": "機械学習データセット",
  "kbId": 123,
  "parentId": 456,
  "fileIds": [
    "file_001",
    "file_002",
    "file_003"
  ],
  "dsIds": [
    1001,
    1002,
    1003,
    1004
  ],
  "taskStatus": 1,
  "approvalState": 2,
  "notSelf": false
}
```

## レスポンスボディ

| フィールド | 説明 |
| --- | --- |
| `code` | レスポンス結果コード。`1` は成功、それ以外は失敗を示します |
| `msg` | エラーメッセージ |
| `data.pageNum` | 現在のページ番号 |
| `data.pageSize` | ページあたりの件数 |
| `data.count` | 総件数を集計するかどうか |
| `data.total` | 総レコード数 |
| `data.isFirstPage` | 最初のページかどうか |
| `data.isLastPage` | 最後のページかどうか |
| `data.list[]` | データセットリスト。フィールド説明は下表を参照 |

### `data.list[]` フィールド説明

| フィールド | 説明 |
| --- | --- |
| `id` | データセットID |
| `state` | 状態 |
| `trainingState` | トレーニング状態 |
| `kbId` | 所属するナレッジベースID |
| `parentId` | 親ID |
| `fileId` | ファイルID |
| `name` | データセット名 |
| `extJson` | 拡張情報（JSON文字列）。説明やタグなど |
| `createAt` | 作成日時 |
| `type` | 種別：`file` ファイル、`folder` フォルダ |
| `dataAmount` | データ量 |
| `parserType` | パーサー種別 |
| `taskStatus` | タスク状態。値の意味は前述のリクエストボディパラメータを参照 |
| `progress` | タスク進捗 |
| `taskId` | タスクID |
| `allowDownload` | ダウンロードを許可するかどうか：`1` 許可、`0` 不許可 |
| `downloadUrl` | ダウンロードURL |
| `allowPreview` | プレビューを許可するかどうか：`1` 許可、`0` 不許可 |
| `previewUrl` | プレビューURL |
| `uuid` | 一意識別子 |
| `approvalId` | 審査レコードID |
| `approvalState` | 審査状態。値の意味は前述のリクエストボディパラメータを参照 |
| `approvalCode` | 審査状態コード |
| `operateCode` | 操作種別コード |
| `operatorUserName` | 操作者名 |
| `auditorUserNames` | 審査者名リスト |
| `creatorUserName` | 作成者名 |
| `operateComment` | 操作コメント |
| `approvalComment` | 審査コメント |
| `referenceCount` | 参照回数 |
