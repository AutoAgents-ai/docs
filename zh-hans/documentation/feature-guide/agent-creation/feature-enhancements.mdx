---
title: "功能增强"
---

◦ 单节点调试 ：支持在画布中对单个节点进行独立调试，无需运行完整工作流即可验证节点逻辑与输出，大幅提升开发调试效率。

  <img src="/images/documentation/ch6_6.1.40_0114.png" alt="功能增强" />
</Frame>

◦ 代码块外部环境支持 ：代码块模块新增外部执行环境支持，可调用系统外部资源与依赖库，扩展代码处理的能力边界。
◦ 变量引用提醒 ：在编排过程中引用变量时，系统自动提供可用变量列表与格式提示，减少因变量名拼写错误导致的工作流异常。
◦ 自然语言工作流生成 ：支持基于用户的自然语言描述自动生成工作流节点，并完成基础连线与执行顺序构建，无需手动拖拽即可快速搭建工作流框架。
◦ 工作流调优 ：支持通过自然语言指令或手工拖拽两种方式，对自动生成的工作流进行调整和优化，兼顾效率与灵活性。
◦ 智能工具编排 ：根据任务语义自动选择合适的工具，并完成与 Agent 或工作流的绑定，实现工具调用的智能化匹配。
◦ 数据源自动关联 ：在生成过程中自动关联知识库或数据源，用于增强 Agent 的执行能力与信息获取范围。
