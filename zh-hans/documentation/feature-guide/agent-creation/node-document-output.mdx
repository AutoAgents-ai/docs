### 功能概述

文档输出模块是平台中用于将上游生成的内容以 Word 文档形式输出的核心组件。它支持两种工作模式：

### 直接输出模式：

在不使用模板的情况下，将上游组件的输出内容直接填入空白 Word 文档中。

### 模板替换模式：

支持上传包含占位符的 Word 文档模板，系统会自动将上游传入的变量值替换到模板的指定位置，从而生成格式统一、内容个性化的结构化报告。
该模块的核心价值在于实现工作流中数据到标准化文档的自动转换，极大提升报告生成、合同草拟、报告汇总等场景的效率。

### 准备工作

明确上游数据源 ：确定需要输出到文档的内容来自哪些上游模块，例如用户提问的文本、智能对话模块生成的总结、信息提取模块提取的结构化数据等。
设计输出模板（可选） ：如果需要结构化报告，提前在 Word 中设计好模板，并在需要填充动态内容的位置使用 {{占位符Key}} 的格式标记，例如 {{客户名称}}、{{合同金额}}。

### 模块拖拽与基础配置

拖拽模块 ：在工作流画布的左侧组件库中，找到“文档输出”模块，将其拖拽到画布中合适的位置。
命名模块 ：为模块重命名，如“生成报价单”，以便于流程理解。
设置激活条件 ：根据业务逻辑，配置“联动激活”或“任一激活”，以决定模块在何种条件下开始执行。

### 模式一：直接输出（无模板）

适用场景 ：需要快速将一段或多段文本内容整理成 Word 文档，格式要求不高。
操作步骤 ：
在模块配置抽屉中，确保“添加自定义信息输入”区域未被使用，或不上传任何模板。
将上游模块（如“智能对话”、“信息加工”）的输出节点（如“回复内容”）与文档输出模块的“信息输入”节点连接。
当工作流运行至此模块时，上游的所有输出内容将被合并并生成一个空白的 Word 文档进行下载。

### 模式二：模板替换（有模板）

适用场景 ：需要生成格式固定、内容动态变化的标准文档，如合同、报告、通知书等。
操作步骤 ：
上传模板 ：在模块配置抽屉中，找到“上传模板”区域，上传您提前准备好的包含占位符的 Word 文档。
添加自定义信息输入 ：上传模板后，系统会提示您添加自定义信息输入。
点击“添加自定义信息输入”。
在弹出的配置项中， Key 需严格填写模板中占位符的名称（如 客户名称）， 名称 可填写便于理解的描述（如“客户名称字段”）。
将上游模块中对应此 Key 的输出节点与此自定义信息输入节点连接。
重复此步骤，为模板中的每一个占位符添加对应的自定义信息输入。
运行与下载 ：工作流运行时，系统会将所有上游变量值填充到模板的对应位置，并生成最终的 Word 文档供用户下载。

### 测试与发布

单节点调试 ：在画布中对文档输出模块进行独立调试，无需运行完整工作流即可验证输出效果，大幅提升开发效率。
完整流程测试 ：运行整个工作流，模拟用户输入或触发条件，检查生成的 Word 文档是否符合预期。
发布智能体 ：测试无误后，发布智能体，文档输出功能即可在实际业务场景中使用。

### 常见问题与注意事项

模板格式支持 ：上传的 Word 模板支持基本的字体、字号、段落格式。系统会尽力复刻模板中的样式，但对于过于复杂的排版（如多层嵌套表格、特殊字体效果）可能无法完全保留。
占位符格式 ：模板中的占位符必须使用 {{占位符Key}} 的格式，且 Key 名称需与配置的“自定义信息输入”中的 Key 完全一致，否则无法替换。
上游变量类型 ：上游传入的变量值应为文本类型。如果上游是 JSON 结构，可能需要先通过“信息处理”模块或“代码块”模块进行解析和拼接。
文件下载 ：文档生成后，会在用户对话界面提供下载链接。请注意，大型文档的生成可能需要几秒钟时间。
模块运行结束 ：文档输出模块运行结束后，会输出“True”，可用于触发后续流程，如将文档发送至指定邮箱或存储到知识库。
