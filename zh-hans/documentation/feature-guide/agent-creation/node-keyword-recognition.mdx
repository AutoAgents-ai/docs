title: "关键词识别"

### 功能概述

添加关键词识别模块后，系统会自动执行指定关键词的识别校验。你可在此配置多组独立的识别分组，完成多维度的关键词审核管控。系统将根据不同的匹配结果，自动反馈差异化的回复内容，精准适配各类审核场景与业务需求。

### 功能入口

登录平台后可在模块里面找到关键词识别模块

<Frame>
  <img src="/images/documentation/ch6_6.1.20.2_0060.png" alt="关键词识别" />
</Frame>

点击关键词模块进入配置页面，点击添加新识别分组来创建新的关键词识别分组

<Frame>
  <img src="/images/documentation/ch6_6.1.20.2_0061.png" alt="关键词识别" />
</Frame>

填入需要识别的敏感词后，模块会对文档进行识别，若含有敏感词，则会按照包含时的描述输出。若不含有敏感词，则按照不包含时的描述输出。
