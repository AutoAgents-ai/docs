### 模块介绍

在需要将特定内容回复给用户时，可以使用确定回复模块，当触发条件判断成立，用户将直接收到「回复内容」文本框中配置好的内容。如果回复内容节点链接外部信息源，则链接信息将覆盖「回复内容」输入框配置的信息。
