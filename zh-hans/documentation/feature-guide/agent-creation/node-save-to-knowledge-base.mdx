### 功能概述

在工作流运行过程中，将指定输出信息存储至目标知识库。存储内容会自动经过解析和切片处理，可被其他知识库搜索模块引用，实现知识的动态积累。输入时，需要同时填入数据内容和数据集名称，这两项为必填项，如果不填，该组件无法生效。

界面操作流程说明
点击存储到知识库模块进入配置页面，点击添加来添加新的数据。

<Frame>
  <img src="/images/documentation/ch6_6.1.24.1_0072.png" alt="存储到知识库" />
</Frame>

点击高级设置进行详细配置，其中切片字数是用来设置文本分片的最大字符数，较小的值会产生更多片段但查询更精确，而覆盖率则用来设置相邻片段之间的重叠比例，有助于保持上下文连贯性。
