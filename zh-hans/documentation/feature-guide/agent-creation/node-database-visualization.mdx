### 功能概述

数据可视化模块是平台基础版的核心功能组件，旨在将结构化数据（尤其是数据库查询结果）转化为直观的图表，提升数据洞察与决策效率。该模块通常与“数据库查询”模块搭配使用，能够将抽象的 JSON 格式查询结果，自动或按需生成为柱状图、条形图等多种可视化图表，并支持在对话界面进行二次编辑调整。
核心价值 ：
降低使用门槛 ：无需掌握专业的可视化工具或编程技能，通过简单配置即可实现数据图形化展示。
提升决策效率 ：将复杂数据以直观图表形式呈现，帮助用户快速识别趋势、对比差异、发现异常。
流程无缝衔接 ：作为工作流中的关键节点，可视化结果可直接传递给后续模块（如“确定回复”、“文档输出”），实现从数据查询、可视化到结果交付的自动化闭环。
适用场景 ：
业务报表生成 ：自动将销售数据、财务数据转化为月度/季度趋势图。
数据分析报告 ：在行业研究、竞品分析报告中，插入自动生成的对比图表。
智能体对话输出 ：智能体在回答用户问数问题时，直接以图表形式呈现结果，提升交互体验。

### 功能入口

数据可视化模块作为独立的功能节点，集成在平台的可视化工作流编排画布中。获取该功能的入口步骤如下：
登录与进入画布 ：登录平台，进入目标智能体的“规划”画布编辑界面。
查找模块 ：在画布左侧的组件库中，找到并展开 “数据库” 分类。
拖拽节点 ：在“数据库”分类下，找到 “数据可视化” 模块，将其拖拽至画布中合适的位置。
命名与激活 ：为拖拽至画布的模块重命名，并根据业务逻辑配置“联动激活”或“任一激活”条件。

### 数据可视化界面

该界面用于配置图表生成参数，核心参数包括：
联动激活/任一激活 ：布尔型输入。用于配置模块的执行条件。“联动激活”表示上游所有条件均为 True 时执行；“任一激活”表示上游任一条件为 True 时执行。
原始数据 ：文本类型输入。上游“数据库查询”组件输出的查询结果（JSON 格式）将作为输入数据。
图表类型 ：下拉选择框。根据需求选择生成的图表类型（如柱状图、条形图等）。该参数可选填，未设置时前端会默认填充。
模块运行结束 ：布尔型输出。该模块运行结束后，输出值为 True，通常用于触发下游流程。

### 操作流程

以下以执行一个简单的“数据库查询 + 数据可视化”工作流为例，说明具体操作步骤。
步骤一：前提准备 - 添加数据库查询节点
拖拽查询节点 ：在工作流画布的左侧组件库“数据库”分类中，将“数据库查询”模块拖拽至画布中。
配置查询参数 ：
选择数据库 ：在“数据库”下拉菜单中，选择已配置好的数据库（如jointpilot或自有数据库）。
编写 SQL 语句 ：在“SQL 语句”输入框中，编写查询语句。例如：SELECT \* FROM sample_table WHERE condition = 'value' LIMIT 10;。
运行测试 ：点击“运行”或“测试”按钮，在“输出”区域查看 JSON 格式的查询结果。
步骤二：添加并配置数据可视化节点
拖拽可视化节点 ：在左侧组件库“数据库”分类下，找到“数据可视化”模块，拖拽至画布中，并放置在“数据库查询”节点之后。
建立数据连接 ：将“数据库查询”节点的“查询结果”输出端口，连接到“数据可视化”节点的“原始数据”输入端口。
配置图表参数 ：
设置激活条件 ：根据业务逻辑，配置“联动激活”或“任一激活”。
选择图表类型 ：在“图表类型”下拉框中，选择所需的图表样式（如柱状图）。
步骤三：执行工作流并查看结果
保存并试运行 ：保存当前工作流，然后点击画布右上角的“试运行”按钮。
输入触发条件 ：在弹出的对话界面中，输入能触发“数据库查询”节点的问题或指令。
查看可视化结果 ：系统将自动执行查询并生成图表。在对话界面中，您可以直接看到生成的可视化图表，并支持进行二次编辑调整。
步骤四：结果传递与应用（可选）
生成的可视化图表可作为变量，直接传递给后续的“确定回复”模块（用于固定回复用户）或“文档输出”模块（用于生成报告），实现工作流的自动化闭环。
注意事项 ：
数据格式 ：确保上游“数据库查询”模块输出的 JSON 数据结构清晰，字段明确，以便正确映射为图表维度。
权限管理 ：确保当前用户对所选数据库具有查询权限，且对生成的可视化结果有访问权限。
图表编辑 ：对话界面中的二次编辑功能允许用户根据实际需求调整图表样式，使结果更符合展示要求。
通过以上步骤，您可以在平台中高效地使用数据可视化模块，将冰冷的数据转化为清晰的洞察，赋能业务决策。
