### 功能概述

代码提取器模块是平台为开发者提供的一项实用工具，旨在从大语言模型生成的 Markdown 格式内容中，精准提取出指定类型的代码片段。它支持 SQL、Python、Java、C、JSON、JavaScript 六种主流代码类型，能够将混杂在自然语言描述中的代码段识别并分离出来，输出为纯净的代码文本，方便后续的直接使用、执行或进一步处理。
该模块的核心价值在于：
提升开发效率 ：自动从模型回复中提取可执行代码，避免手动复制粘贴和格式清理的繁琐工作。
确保代码纯净 ：有效分离自然语言与代码，确保提取的代码片段可直接用于运行或集成。
流程无缝衔接 ：提取的代码可作为变量，直接传递给后续的代码块模块进行执行，或传递给文档输出模块进行保存，实现工作流的自动化。

### 功能入口

代码提取器模块作为一个独立的功能节点，集成在平台的可视化工作流编排画布中。获取该功能的入口步骤如下：
拖拽模块 ：在工作流画布的左侧组件库中，找到“代码提取器”模块，将其拖拽到画布中合适的位置。
命名模块 ：为拖拽至画布的模块重命名，以便于流程理解和后续管理。
设置激活条件 ：根据业务逻辑，配置“联动激活”或“任一激活”，以决定模块在何种条件下开始执行。

### 界面说明

代码提取器工具的配置界面简洁明了，主要包含输入参数设置和输出结果展示区。
核心参数配置
配置界面主要包含以下参数：
联动激活 ：布尔型。该节点可连接多条布尔型输入，当 上游所有条件均为 True 时可激活当前组件执行 ，即“全部条件满足时，则执行该模块”。
任一激活 ：布尔型。该节点可连接多条布尔型输入， 上游任一条件传入为 True 可激活当前组件执行逻辑 ，即“任一条件满足，则执行该模块”。
Markdown 输入 ：字符串类型。连接上游输出的 Markdown 格式文本，作为代码提取的原始内容。
代码类型 ：下拉选择框。从 SQL、Python、Java、C、JSON、JavaScript 六种代码类型中选择一种，作为本次提取的目标类型。
输出 ：只读展示区域。执行提取后，系统会在此处展示提取到的纯代码文本。

### 操作流程

以下以从一段 Markdown 文本中提取 Python 代码为例，说明具体操作步骤。
步骤一：添加提取节点
在微应用编排的画布中，从工具箱拖拽 “代码提取器” 节点至合适位置。
步骤二：配置提取参数
点击画布中的节点，在右侧弹出的配置面板中进行设置：
设置激活条件 ：根据业务逻辑，选择“联动激活”或“任一激活”。
连接 Markdown 输入 ：将上游节点（如智能对话模块）输出的 Markdown 内容，连接到“Markdown 输入”端口。
选择代码类型 ：在 “代码类型” 下拉菜单中，选择 “Python” 。
步骤三：执行与查看结果
点击配置面板底部的 “运行” 或 “测试” 按钮。
系统将执行提取逻辑，并在 “输出” 区域直接显示提取到的纯 Python 代码文本。
此代码输出可直接作为变量，被后续的 代码块模块 引用执行，或被 文档输出模块 保存为文件。
步骤四：连接下游模块
执行代码 ：将“输出”端口连接到“代码块”模块的“代码内容”输入，即可直接运行提取的代码。
保存代码 ：将“输出”端口连接到“文档输出”模块，可将代码保存为 Word 文档。
最佳实践与注意事项
输入格式 ：确保上游输入的内容是标准的 Markdown 格式，代码块需用 包裹并正确指定语言（如 python），这是准确提取的前提。
代码类型匹配 ：选择的代码类型必须与 Markdown 中实际包含的代码类型一致，否则可能提取失败或返回空结果。
错误处理 ：建议在工作流中，在代码提取器节点后连接分支判断节点，根据是否成功提取到代码，来设计不同的后续流程。
版本支持 ：该模块属于平台基础版功能，所有用户均可使用。
