### 简介

简单来说，这个功能就是用来决定“谁能看什么数据、谁能用什么功能”的。在团队合作中，合理地发这些“通行证”，既能保护重要数据不泄露，又能让大家各司其职，工作起来更安心。
权限页面去哪找？
这里主要分成了两个页面：“我创建的”和“授权给我的”。您可以把它们简单理解为\\“我发给别人的通行证”和“别人发给我的通行证”\\。

### “我创建的”页面

这个页面是您的专属“控制台”。所有由您亲自设置的权限规则都在这里。您可以在这里新建规则、修改规则，或者把权限发给其他人。
看列表： 页面中间的大表格会显示您建好的所有规则。上面会清楚地列出：
策略名称： 这条规则叫什么名字（比如“销售部查看权限”）。
数据类型： 管的是哪类数据。
策略描述： 这条规则的具体说明，方便您自己日后想起来它是干嘛的。
创建时间： 这条规则是什么时候建的（精确到年月日和时分秒）。
找规则 & 建新规则： 规则太多找不到？在顶部的“搜索框”搜一下名字就行。如果想加一条全新的规则，点一下蓝色的“新增”按钮就可以开始了。
常用操作： 在列表的最右侧有一列叫“操作”，这里有三个最常用的功能：
编辑（改一改）： 发现名字填错了，或者想换一批人？点这里修改。在“策略设置”里，您可以像拉微信群一样，勾选哪些部门、哪些人或者哪些角色能用。如果想让全公司所有人都能用，直接勾选最底部的\\“全部可见”\\，一键搞定！

分配使用权限（发给别人）： 规则建好了，要在这一步发给具体的人才算生效。同样地，您可以挑选特定的部门、人员或者角色，也可以图省事直接选最下方的\\“全部可见”\\，把权限发给大家。

删除（不要了）： 如果这条规则以后彻底废弃了，点这里删掉。（小提示：删除前系统会提示您确认，千万别手滑误删哦！）

### “授权给我的”页面

这里放着别人（比如您的领导或同事）分配给您的权限。请注意，这个页面是“只读”的，您可以把它当成一个展示柜，只能看，不能修改或删除里面的任何内容。
找规则与看列表： 如果别人给您的权限太多，同样可以用顶部的搜索框找一找。下面的表格也会清清楚楚地写明：策略名称、数据类型、策略描述和给您的创建时间。
查看详情： 在列表最右侧的“操作”列，只有一个“查看”按钮。点进去，您就能看到这条权限的具体内容了（比如能看到这个权限还同时发给了哪些部门或人，或者是不是“全部可见”的）。
