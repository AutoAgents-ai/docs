简介
简单来说，这个模块就像是一位“火眼金睛的阅读助理”。您丢给它一篇长篇大论的文件，它能帮您把里面的“核心关键信息”精准地摘抄下来，并整理成系统能看懂的整齐格式，方便后面的流程继续处理。

### 模块长什么样？（输入与输出）

和工作流里的其他组件一样，这位“助理”也有接收任务的“进货口”和交接工作的“出货口”。
进货口（输入节点）：助理什么时候开始看文件？
启动开关（执行逻辑）：
联动激活： 必须等上游所有的步骤都搞定了，它才开始接手工作。
任一激活： 上游的步骤只要有任何一个完成了，它就立刻开工。
接收的数据（内容输入逻辑）： 接收叫做文档信息的数据（也就是需要助理阅读和提取的那份原始文档内容）。
出货口（输出节点）：助理干完活交出什么？
交出的数据（内容输出逻辑）： 提取完毕后，交出整理好的抽取结果（系统能读懂的 JSON 格式数据包），递给下一个环节。
干活的状态（执行逻辑）：
执行成功 或 执行异常： 这两个是“二选一”的汇报（要么顺利提取到了关键信息，要么因为某些原因卡壳报错了）。
模块运行结束： 这是最后的总结陈词。只要这位助理把活干完了（不管上面是成功还是报错），这个开关都会打开，通知后面的环节：“我这步走完了，你们可以接着往下进行了”。

### 模块内部怎么设置？（配置抽取规则）

点开这个组件，我们需要给这位“阅读助理”配一把合适的“放大镜”，告诉它遇到什么类型的文件，该用什么特定的方法去解析。
在“抽取配置”中，您需要做两步选择：先选文件类型，再选解析方法。系统为您提供了多种常见的文件类型（八选一），每个类型下都有对应的“专属解析秘籍”：
① 综合全能 (all)： \ 解析方式：auto（自动）*。最省事的选项，让系统自己看着办。
② 表格文件 (excel)： \ 解析方式三选一：general（通用）、tika、excel*（表格专属解析）。
③ 音频文件 (voice)：
解析方式：general（通用）。把声音里的信息提取出来。
④ PDF文件 (pdf)： （由于 PDF 结构最复杂，系统给的工具也最多）
解析方式五选一：mineru、general（通用）、tika、pp_structure_v3（擅长识别版面结构）、paddleocr-vl（擅长图文识别）。
⑤ 文档文件 (document，如 Word)：
解析方式二选一：general（通用）、tika。
⑥ 纯文本文件 (text)：
解析方式二选一：general（通用）、tika。
⑦ 幻灯片文件 (powerpoint，如 PPT)：
解析方式二选一：general（通用）、tika。
💡 进阶小技巧：添加多套规则
如果您这套流程里既有 PDF，又有 Excel 怎么办？别担心，在这个设置选项的旁边有一个“添加”按钮。点击它，您可以同时添加好几个抽取配置（比如：设置一条规则专门对付 PDF，再添加一条规则专门对付 Excel）。这样一来，“助理”就能从容应对各种复杂任务啦！
