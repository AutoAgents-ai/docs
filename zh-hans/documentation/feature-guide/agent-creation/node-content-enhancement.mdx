简介
简单来说，这个模块就像是一个“学霸小助手”。当系统要回答问题时，它会先去翻阅我们的知识库，用里面的专业内容对回答进行“润色和加工（增强）”，让最终给出的答案更准确、更专业。

### 模块长什么样？（输入与输出）

这个模块是一个工作流组件，就像流水线上的一个加工站，有“进货口”（输入节点）和“出货口”（输出节点）。
进货口（输入节点）：模块什么时候开始干活？
这部分包含“启动开关”和“接收的数据”：
启动开关（执行逻辑）： 有两种启动方式。
联动激活： 必须等前面所有的步骤都完成了（大家都亮绿灯），它才开始干活。
任一激活： 前面的步骤只要有任何一个完成了（只要有一个人亮绿灯），它就立马开始干活。
接收的数据（内容输入逻辑）： 接收叫做切片信息的数据包（您可以把它理解为系统能读懂的一种带格式的数据文本，通常叫 JSON 信息），这是它要加工的“原材料”。
出货口（输出节点）：模块干完活后交出什么？
加工完成后，它要把结果和状态传递给下一个环节：
交出的数据（内容输出逻辑）： 加工完毕后，吐出增强后的切片信息（同样是 JSON 格式的数据包），交给下一步去用。
干活的状态（执行逻辑）： 模块运行完会给出汇报，分为以下几个信号：
执行成功 或 执行异常： 这两个结果是“二选一”的（要么顺利搞定，要么中途报错）。
模块运行结束： 只要这个模块干完活了（不管上面是成功还是报错），这个开关都会打开，告诉后面的环节：“我这边完事了，你们可以接着往下走了”。

### 模块内部怎么设置？（组件内容）

点开这个组件，我们就可以设置它具体用什么“大脑”和“方法”来加工数据了。
在面板里，您会看到一个\\“选择算法”\\的选项，这里有三种不同的“加工秘籍”供您三选一：
① 摘要增强： 让小助手给内容写个更精准的总结。选择这个后，您需要配置两项内容：
增强配置： 需要在下拉菜单里\\“选择模型”\\（就是挑选一个给力的 AI 大脑来干这件活）。
提示词： 这里会有一个输入框，您可以在里面写一段提示词（相当于给小助手下达的具体指令，比如告诉它“请用通俗的语言概括重点”）。

② 文件名增强： 根据文件的名称来进行内容的补充和强化（适合文件名本身就包含重要信息的情况）。
③ 目录增强： 根据文件存放的目录层级来进行内容强化。
增强配置： 选择这个选项后，同样需要\\“选择模型”\\，为它指定一个用来处理目录信息的 AI 大脑。
