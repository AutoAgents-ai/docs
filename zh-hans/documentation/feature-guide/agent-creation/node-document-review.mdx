### 模块介绍

用于文档读取和审核场景。用户上传文档后，系统根据预设的批量审核问题（最多 100 个）逐一提问并由 AI 作答。支持 CSV 模板批量导入问题，适用于合同审核、合规检查等场景。左侧输入文档，经过大模型处理后，将作为回复内容进行输出。

详细界面说明
支持右上角自行添加提问，也支持模版添加提问。
可以自由选择模型，支持国内大多数主流模型。
提示词（prompt）:模型引导词，可通过调整该提示，引导模型聊天方向，该内容会被固定在开头。
