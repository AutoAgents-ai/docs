### 功能概述

数据库查询模块是平台为开发者提供的关键数据处理工具，旨在解决微应用编排过程中的结构化数据访问需求。它允许开发者在无需直接管理数据库连接池和复杂驱动的情况下，通过简单的配置即可执行数据检索，将查询结果无缝集成到后续的业务逻辑或 AI 模型中。
该模块的核心价值在于：
降低使用门槛 ：无需编写底层连接代码，通过可视化配置即可完成数据查询。
提升开发效率 ：将结构化数据查询能力直接嵌入到工作流中，实现业务流程与数据处理的一体化。
保障数据安全 ：严格限制操作权限，目前仅支持查询（ SELECT）操作，有效防止未授权的数据写入、修改或删除。

### 功能入口

数据库查询模块作为一个独立的功能节点，集成在平台的可视化工作流编排画布中。获取该功能的入口步骤如下：
拖拽模块 ：在工作流画布的左侧组件库的“数据库”分类中，找到“数据库查询”模块，将其拖拽到画布中合适的位置。
命名模块 ：为拖拽至画布的模块重命名，以便于流程理解和后续管理。
设置激活条件 ：根据业务逻辑，配置“联动激活”或“任一激活”，以决定模块在何种条件下开始执行。

### 数据库查询界面

该界面用于配置标准 SQL 查询，核心参数包括：
数据库 ：下拉选择框。默认选项为平台提供的 jointpilot 数据库。如需使用自有数据库，需提前在平台后台完成配置，方可在此处选择。
SQL 语句 ：文本输入框。用于编写查询语句。 请注意 ，当前仅开放查询（ SELECT）语句的执行权限。若有更新、插入或删除等其他操作需求，需联系平台负责人进行沟通。
输出 ：只读展示区域。执行查询后，系统会在此处以 JSON 格式展示返回的数据结果。

### 搜索引擎数据库查询界面

该界面用于配置搜索引擎专用查询，核心参数包括：
搜索引擎数据库 ：下拉选择框。平台已预置“众标标讯”搜索引擎。若需接入其他自有搜索引擎数据库，需先联系平台负责人配置至后台。
DSL 语句 ：文本输入框。用于编写符合特定搜索引擎语法规则的 Domain Specific Language 查询语句。
输出 ：只读展示区域。查询执行后，结果同样以 JSON 格式返回。
重要提示 ：
权限限制 ：数据库查询工具目前 仅支持查询（SELECT）操作 ，不支持数据写入、修改或删除，以确保数据安全。
复杂查询 ：“众标标讯”搜索引擎的字段结构及查询语法较为复杂，建议初次使用时联系平台负责人获取支持或参考示例。
自有库配置 ：使用自有数据库前，必须由管理员在平台后台完成连接信息（如地址、端口、用户名、密码）的配置。

### 操作流程

以下以执行一个简单的数据库查询为例，说明具体操作步骤。
步骤一：添加查询节点
在微应用编排的画布中，从工具箱拖拽 “数据库查询” 节点至合适位置。
步骤二：配置查询参数
点击画布中的节点，在右侧弹出的配置面板中进行设置：
选择数据库 ：在 “数据库” 下拉菜单中，保留默认的 jointpilot 或选择已配置好的自有数据库。
编写 SQL 语句 ：在 “SQL 语句” 输入框中，编写您的查询。例如，输入 SELECT \* FROM sample_table WHERE condition = 'value' LIMIT 10;。
最佳实践 ：尽量明确指定所需字段，而非使用 SELECT \*，以减少网络传输和提高查询效率。
变量引用 ：SQL 语句中支持引用上游节点输出的变量，格式如 WHERE id = { { upstream_var } }（注意去除花括号内空格），可实现动态查询。
步骤三：执行并获取结果
点击配置面板底部的 “运行” 或 “测试” 按钮。
系统将执行 SQL 语句，并在 “输出” 区域直接显示查询结果。结果是一个 JSON 数组，其中每个对象代表一行数据，字段名与数据库列名对应。
此 JSON 输出可直接作为变量，被后续的大语言模型（LLM）节点、API 工具节点或文本处理节点引用和处理。

### 搜索引擎数据库查询流程

操作流程与上述类似，区别在于：
需选择 “搜索引擎数据库查询” 节点。
在 “搜索引擎数据库” 中选择“众标标讯”。
在 “DSL 语句” 中输入符合该搜索引擎要求的查询语法。
执行后，同样获得 JSON 格式的检索结果。
最佳实践与注意事项
查询优化 ：对于可能返回大量数据的查询，务必在 SQL 语句中使用 LIMIT 子句限制返回行数，避免响应超时或前端渲染压力。
错误处理 ：建议在工作流中，在数据库查询节点后连接分支判断节点，根据查询是否成功或结果是否为空，来设计不同的后续流程。
结果处理 ：返回的 JSON 数据可配合“JSON 提取 key 值”或“JSON 数据解析”工具节点，快速提取特定字段，进行进一步的数据转换和展示。
权限管理 ：数据库连接的访问权限可通过平台的【数据权限管理】模块进行精细化分配，支持按部门、人员、角色或预定义策略进行授权，确保数据安全。
