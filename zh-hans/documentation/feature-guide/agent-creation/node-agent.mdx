### 模块介绍

相较一般模型+提示词的智能体，Agent节点 集成了知识库，工具（mcp），技能（skill），具备了较为完善的功能。
Agent节点 既是智能体接入各种专家skill的入口，也是平台实现多agent协作的重要一步。

</Frame>

### 应用场景

需要用到 mcp 和 skill 的功能，都可以通过 Agent节点 实现，
其中，
mcp 可以模型掌握复杂的工具能力，如联网搜索，浏览器操作等，
skill 可以让模型掌握一些专业的SOP（标准工作流）。
