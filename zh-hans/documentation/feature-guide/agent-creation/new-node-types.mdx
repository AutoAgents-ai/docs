◦ Agent 智能体节点 ：支持 Agent 根据目标自动拆解任务、规划执行步骤、动态调度MCP工具 / 知识库 / skill等资源，并实时监控执行状态进行异常重试与策略调整，实现复杂问题的自主闭环处理。

◦ 文档审查节点 ：支持工作流根据业务流程自动触发审查任务、配置多级审查流程、灵活分配审查人员与权限，并实时同步审查进度与处理意见，对驳回、超时、异常提交等情况自动触发流转规则与提醒通知，实现文档从提交、审核、修订到归档的全流程闭环管理。
