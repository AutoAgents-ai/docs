### 功能概述

当我们在首页点击“创建智能体”后，会跳转进入Agent基础配置页面。我们可以在该页面配置Agent的基本信息，这些配置决定了智能体的呈现样式及功能。同时你也能在此了解与智能体的相应数据，持续进行使用优化，或将智能体进行发布，服务更多用户。

### 功能入口

登录Agents 平台，点击首页上方创建智能体，智能体类型选择智能体工作流，创建方式可选择从空白创建或从模板创建。创建智能体后，即可在右侧配置输入栏填写相关配置信息。

### 界面说明

Agent基础配置页面
智能体头像：设置智能体头像，可上传自定义头像图片，支持JPG、PNG格式。

<Frame>
  <img src="/images/documentation/ch6_6.1.3.3_0010.png" alt="基础配置" />
</Frame>

智能体头像设置
智能体名称：设置智能体的名称。
描述：设置智能体的使用简介。
智能体类型：设置智能体类型，在发布页面会根据类型对智能体进行分类展示。
对话背景：设置智能体对话页面背景图，可上传自定义背景图片，支持JPG、PNG格式，建议尺寸为1920\*1080。
语音输入：设置智能体对话页面中语音输入功能是否展示，开启后用户可点击输入框右侧的麦克风按钮进行语音输入。
开场白：设置智能体开场白，用户首次打开智能体页面时，对话窗口呈现开场白内容。
问题建议：设置智能体问题建议，用户首次打开智能体页面时，对话窗口呈现推荐问题便捷输入按钮。

<Frame>
  <img src="/images/documentation/ch6_6.1.3.3_0011.png" alt="基础配置" />
</Frame>

智能体基础信息配置
对话模型：设置智能体使用的大模型类型。注意：该设置会被后续工作流规划的智能对话配置所覆盖。
提示词：设置智能体的提示词内容。注意：该设置会被后续工作流规划的智能对话配置所覆盖。
推荐问私隐保护关键词：设置智能体的私隐保护关键词，智能体在生成推荐问题时，会主动避免生成隐私类的问题。
开启富文本展示：当开启富文本展示时，智能体输出的内容会进行markdown格式渲染。当关闭富文本展示时，智能体输出内容会以纯文本形式显示。
开启word转pdf：当开启word转pdf时，用户在对话框上传的word文件会自动转为pdf格式用于后续智能体作文件相关处理，例如：OCR、文档解析……等。
是否显示知识库引用：当开启知识库引用后，智能体输出内容会显示召回的知识库和具体文件，用户可点击卡片进行查看。
是否显示图片引用：当开启显示图片引用后，智能体输出内容会显示召回的图片，用户可点击卡片进行查看。
是否显示引用角标：当开启显示引用角标后，智能体输出内容会在句子末尾带上引用角标，用户可点击角标查看该字段引用来源。

  <img src="/images/documentation/ch6_6.1.3.3_0012.png" alt="基础配置" />

知识库引用
是否开启扩展问：当开启扩展问时，智能体会在回答完成后，生成若干个推荐问题，用户可以快速点击输入提问。
显示推荐问：当开启显示推荐问时，智能体会基于知识库内容生成推荐问题，用户首次打开智能体页面时，对话窗口呈现推荐问题便捷输入按钮。
知识库：设置智能体选用的知识库。注意：该设置会被后续工作流规划的知识库搜索配置所覆盖。

### 功能概述

支持自定义时间区间，查看 PV、UV、DAU、智能体总量及 Token 总消耗量。提供部门互动量排名、日均会话趋势、用户活跃趋势与页面流量趋势等图表。

### 功能入口

登录Agents 平台，点击首页上方创建智能体，智能体类型选择智能体工作流，创建方式可选择从空白创建或从模板创建。
敏感词审核
添加敏感词审核：添加对应敏感词库后，当用户输入内容包含敏感词时，智能体会自动提示：“您输入的内容包含违禁词，请修改后重试”。
