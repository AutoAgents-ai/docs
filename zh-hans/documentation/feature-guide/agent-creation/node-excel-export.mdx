---
title: "Excel生成模块"
---

简介
简单来说，这个模块就是一个“自动填表机器人”。在工作流中，如果您需要把前面收集到的数据导出来，或者做成一张报表，交给它准没错。它能按照您给的模板，自动把数据填进去，生成一份完整的 Excel 电子表格。
模块长什么样？（输入与输出）
作为流水线上的制表专员，它同样有接收任务的“进货口”和交出表格的“出货口”。
进货口（输入节点）：机器人需要接收什么指令和材料？
启动开关（执行逻辑）：
联动激活： 必须等前面的步骤都顺利完成了，它才开始制表。
任一激活： 前面的步骤只要有一个完成了，它就立刻开工。
信息输入（填表数据）： 这是系统传过来的“填表答案”（一种叫 JSON 的数据包）。
💡 小白科普：它怎么知道填在哪？您只需要在 Excel 模板里写上特殊记号（比如 {{var1}}），机器人就会自动把对应的数据填到这个格子里。
Excel 文档名称（动态起名）： 前面的流程可以传一个名字过来，直接决定最后生成的表格叫什么。
出货口（输出节点）：机器人干完活交出什么？
文档信息（交出表格）： 表格做好后，它会输出一个包含“文件信息”的数据包。里面有两个最关键的东西：fileName（表格叫什么名字）和 fileURL（表格的下载链接）。拿着这个链接，下一步就可以直接下载了。
模块运行结束（交接信号）： 只要表格做完了，这个信号开关就会打开，通知后面的环节：“我的表格做好了，你们继续往下走吧”。
模块内部怎么设置？（配置填表规则）
点开这个组件，我们需要给“自动填表机器人”进行一些基础的设置，告诉它用什么模板，以及叫什么名字。
在面板里，您需要按顺序完成以下配置：
① Excel 名称（兜底起名）： 这里有一个输入框。如果前面的流程没有传名字过来（也就是上面提到的“Excel 文档名称”没有数据），机器人就会用您在这里填写的名字作为表格的最终名称。
② 文档信息用户可见（展示开关）： 下方有一个开关。打开它，最终使用这个流程的用户就能看到生成的表格信息了。
③ Excel 模板（上传空白表格）： 这里是给机器人“空白表格”的地方。系统非常贴心地提供了一个【上传窗口】和一个【上传文件】按钮（这两个功能是一样的，您拖拽文件到窗口里，或者点击按钮上传都可以，选自己习惯的操作即可）。
⚠️ 温馨提示：您上传的模板就是未来表格的样子，记得提前在需要填空的地方写好 {{变量名}} 语法哦！
④ 文件大小限制： 在最下方有一行小字提示，您上传的 Excel 模板文件最大不能超过 30MB，尽量保持模板清爽，这样机器人干活也更迅速！
