title: "添加记忆变量"
---

### 功能概述

在工作流中存储临时变量，能弥补智能对话模块上下文长度限制（最多 6 轮）。通过将对话内容拼接追加至记忆变量，可以实现长轮次对话的上下文延续与跨 Agent 数据传递。

### 功能入口

可在模块里面找到添加记忆变量的模块。

  <img src="/images/documentation/ch6_6.1.33.2_0095.png" alt="添加记忆变量" />

### 界面操作流程说明

点击添加记忆变量模块，进入配置界面，点击添加按钮添加记忆变量。

<Frame>
  <img src="/images/documentation/ch6_6.1.33.3_0096.png" alt="添加记忆变量" />
</Frame>

按照提示填写完数据类型，字段key，字段描述后点击添加即可成功创建一个添加记忆变量模块。

<Frame>
  <img src="/images/documentation/ch6_6.1.33.3_0097.png" alt="添加记忆变量" />
</Frame>

### 字段key

字段 key 是这个字段在系统里的唯一、不可重复的标识符，相当于给这个字段起一个「系统内部用的名字」，用来在代码、数据库、接口里精准定位这个字段，和用户看到的「字段名称」是分开的。
