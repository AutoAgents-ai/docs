### 模块介绍

通过正则表达式对字符串进行规则化处理，实现从入参到出参的格式转换，适用于数据清洗、字段拼接、格式标准化等场景，仅支持字符串类型的输入与输出。

### 入参字段key

字段 Key 是该字段在系统、接口或数据结构中的唯一标识，是定位和获取对应字段值的核心依据。

### 入参字段描述

字段描述是对该字段功能、含义、取值范围、使用场景及约束条件的详细说明，是理解字段用途的核心依据。

### 出参字段key

字段 Key 是该字段在系统、接口或数据结构中的唯一标识，是定位和获取对应字段值的核心依据。

### 出参字段描述

字段描述是对该字段功能、含义、取值范围、使用场景及约束条件的详细说明，是理解字段用途的核心依据。

### 转换规则

定义如何将入参转换为此出参。 使用 {{variableName}} 引用变量。
