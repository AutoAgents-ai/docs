### 功能概述

Markdown 转 Word 模块是一个用于将 Markdown 格式的文本内容转换为 Microsoft Word (.docx) 格式文件的工具组件。该模块能够智能解析 Markdown 语法（如标题、列表、表格、代码块、图片链接等），并将其映射为 Word 文档中对应的样式和对象，从而生成排版规范、可直接编辑和分发的 Word 文档。

### 功能入口

进入智能体规划页面，模块 -\> 高阶能力 -\> Markdown 转 Word
