### 第一步：创建智能体

### 从空白/模板创建

进入Agents 平台后，请点击页面左侧「创建智能体」进入创建流程。创建智能体支持以下两种方式：
从空白创建：点后将从零开始创建一个智能体；
从模板创建：点击后将进入「应用模板」选择页面，包含可选择的模板类型有以下7种：所有类别、泛互联网、金融保险、公共服务、电力能源、医疗健康、其他。可根据你的实际需求进行选择，点击「复制模板」即可使用该模板。

智能体配置
智能体是用户和目标想法之间连接的关键桥梁，它承担起指令接收、分析、执行和对话的工作，所以智能体配置也是平台核心的功能，影响着智能体使用效果。
从空白/模板创建智能体后将进入智能体配置页面。智能体支持以所见即所得的方式进行配置，左侧为配置信息栏，右侧为预览窗口。

<Frame>
  <img src="/images/documentation/ch6_6.1.44.3_0122.png" alt="创建你的第一个智能体" />
</Frame>

配置信息栏用于配置与 Agent 相关的参数，决定了Agent 的用途和方向。需要配置的信息如下：
智能体名称：为你的 Agent 起一个名字；
描述：为你的 Agent 写一段简短说明，用于描述用途；
智能体类型：选择合适的 Agent 类型，包括：所有类别、泛互联网、金融保险、公共服务、电力能源、医疗健康、其他；
对话背景：为你的 Agent 选择合适的对话背景，可选择系统内置背景，也可自定义选择；
开场白：与Agent 对话前的提示；
问题建议：暂时不需要设置
对话模型：默认
提示词：使用提示词（Prompt）定义这个 Agent 所实现的目标，这里请发挥你天马行空的想象力，给 Agent 赋予相应的能力。
知识库：本次我们暂时不需要用到知识库，这里不需要勾选

### 规划连线

点击上方 ⌈规划⌋，进入智能体规划页面，此页面用来规划智能体的运行流程，可以通过拖拽的方式将需要使用的模块拖入画布，并连接节点，使其顺利运行。
在此次示例中，智能体已经将左侧 ⌈文本信息⌋节点，与右侧 ⌈信息输入⌋连接起来。这个连线的含义是，用户提问的文本问题，将输出至智能对话模块，接下来就由智能对话模块进行信息处理，并回复到对话中，如图所示。

以上，我们就完成了一个智能体的基本信息设置，现在，从这个智能体已经具备我们指定的知识以及AI能力，点击右上角⌈保存⌋。
第二步：对话测试
这样我们的第一个智能体就创建完成了，我们在右侧的对话预览界面，就可以输入内容和智能体开始对话了，请尝试下你的专属智能体。
在对话过程中，如果对智能体的对话有更多想法，可以随时调整 提示词（Prompt）的设计，以最终达到所期望的效果。
