### 发布方式

首先点击右上角的“···”按钮，然后在弹出的二级菜单中选择“发布”按钮，进入智能体发布页面。

### Http应用

创建和管理HTTP应用链接:
创建链接:
点击右上角"创建链接"按钮
必填项:链接名称、有效期
默认使用方式:"自行充值使用"
可选:启用/禁用链接密码

<Frame>
  <img src="/images/documentation/ch6_6.1.1.2_0003.png" alt="发布智能体" />
</Frame>

链接操作:
创建成功后可执行:打开、复制、嵌入网页
点击链接右侧"···"按钮:删除或编辑链接

### API服务

API服务页面信息与操作:
可用信息:
Uuid：智能体API的唯一标识符，用于识别和区分不同的API实例。
AuthKey：用于验证API调用权限的密钥，确保只有授权用户可以访问API。
AuthSecret：用于进一步保护API调用的安全密钥，通常与AuthKey配合使用以增强安全性。
创建时间：API创建时间。
用户操作:
对API信息进行: 复制、刷新、删除。
详细API调用方法:参考AgentsOpenApi-v1.5
