信息抽取
功能模块概述：
信息抽取是知识库 Pipeline 的核心前置环节，用于从各类格式的原始文档中提取有效文本、结构化内容，去除冗余信息，为后续的内容切分、向量化提供高质量的原始数据，是保障知识库检索准确性的基础。
模块入口：
在 Pipeline 编排画布中，双击「信息抽取」节点，即可打开模块配置面板，面板包含 【配置】和【调试】 两个核心标签页。
【配置】标签页：抽取规则设置
核心配置项
配置操作步骤
点击「+ 添加」，新增一条抽取规则
在「选择文件类型」下拉框中，选择需要适配的文档格式（可多选，也可直接选all适配全格式）
在「选择解析方式」下拉框中，为对应格式选择合适的解析算法
如需删除规则，点击对应规则右侧的「删除」图标即可
配置完成后，关闭面板自动保存设置
【调试】标签页：单点功能验证
调试参数说明：
调试操作步骤
点击「拖拽文件上传 或 点击上传」，选择一份待测试的文档（需与配置的文件类型匹配）
确认测试文档无误后，点击底部「运行调试」按钮
查看抽取结果，验证是否完整提取了文档中的有效内容
若抽取效果不符合预期，返回【配置】页调整解析方式，重新调试直至效果达标

### 内容切分

模块功能概述
内容切分是知识库 Pipeline 的核心中间环节，承接「信息抽取」模块输出的结构化文本，将长文档按照预设规则切分为适配向量模型的短文本片段，解决长文本语义丢失、检索精度低的问题，是保障知识库检索效果的关键步骤
模块入口
在 Pipeline 编排画布中，双击「内容切分」节点，即可打开模块配置面板，面板包含 【配置】和【调试】两个核心标签页。
【配置】标签页：切分规则设置
核心配置项：
各算法配置详情：
算法 1：大模型切分
依托大模型能力智能识别文本结构进行切分，适合无固定格式的非结构化文档。
算法 2：按页切分
按文档物理页码进行切分，适合 PDF、PPT 等分页格式文档。
算法 3：自定义切分
支持自定义规则切分，适合有明确分隔特征的文档（如表格、固定分隔符文本）。
算法 4：父子切分
双层切分逻辑，先切分 “父文档” 再拆分 “子文档”，适合长文档、层级结构文档。
算法 5：标题切分
按标题层级结构化切分，适合 Markdown、含标准标题的技术文档 / 手册。
【调试】标签页：单点功能验证
调试参数说明
调试操作步骤
在「抽取结果」输入框中，粘贴上游节点输出的测试文本（需匹配算法适用场景）；
点击底部「运行调试」按钮，执行切分逻辑；
查看切分结果：验证片段长度、分隔逻辑、语义完整性是否符合预期；
若效果异常，返回【配置】页调整算法 / 参数，重新调试。

### 内容增强

模块功能概述
内容增强是知识库 Pipeline 的核心优化环节，承接「内容切分」模块输出的文本切片，通过大模型能力对切片进行语义优化、摘要提炼、信息补全，提升文本的语义完整性和检索匹配度，最终优化知识库的问答准确性，降低模型幻觉。
模块入口
在 Pipeline 编排画布中，双击「内容增强」节点，即可打开模块配置面板，面板包含 【配置】和【调试】 两个核心标签页。
【配置】标签页：增强规则设置
核心配置项
配置操作步骤
确认增强算法：当前通用场景默认选择「摘要增强」，无需额外调整
选择增强模型：在「选择模型」下拉框中，选择适配业务需求的大模型
配置提示词：在「提示词」输入框中，填写自定义增强指令，示例参考：
通用增强：请为这段文本生成100字以内的精准摘要，保留核心信息和关键术语，用于知识库检索增强
业务增强：请提炼这段技术文档的核心功能、适用场景和关键参数，生成结构化摘要，提升检索匹配度
配置完成后，关闭面板自动保存设置
【调试】标签页：单点功能验证
调试参数说明
调试操作步骤
在「切片信息」输入框中，粘贴一份「内容切分」模块输出的测试文本切片
确认测试文本无误后，点击底部「运行调试」按钮
查看增强结果，验证是否符合提示词要求、是否保留核心信息、是否提升了语义完整性
若增强效果不符合预期，返回【配置】页调整提示词或更换模型，重新调试直至效果达标
