title: "中级：信息分类"
---

除了知识库外，平台还提供多种文本处理模块，用于更加多元的场景中。
例如“信息分类”模块，能够通过 AI 对信息进行分类，从而针对分类进行不同流程。“字段提取”模块可以将信息中指定字段提取出来，便于在后续需要使用字段相关的场景中使用。“信息加工”模块能够将信息进行加工如组合处理。

### 画布规划

本次我们以“文学大师”这个 Agent 来演示 AI 如何处理不同的诗歌制作需求，并以不同的格式实现输出。因此 Agent 的整体规划是首先就需要一个“信息分类”模块，来将用户意图进行分类，再根据不同的分类执行文案创作。
连线1：通过“用户提问”模块，获取用户输入信息，并通过“用户提问”输出
“信息分类”模块通过“信息输入”输入用户的问题，后会执行如下几个步骤：
将模块的 prompt 与 “用户提问”、聊天上下文进行传给天工大模型进行分类处理
返回分类处理结果，并触发下一个模块的功能
连线2-4：接下来，根据分类结果，将触发不同的智能对话功能。在本次 Agent 中，3 个“智能对话”将分别进行“诗词/儿歌/歌词”的创作，完成用户需求的输出。
连线5：在“信息分类”的模块中，我们建议增加“其他”分类，来承接对于未能识别或没有定义的分类，以便引导用户更加清晰明确的表达自己需求意图。因此当用户的消息不属于以上分类时，触发“确定回复”模块，并回复指定内容。
