---
title: "智能体评测"
---

在智能体（Agent）的开发迭代中，输出结果的随机性与不可控性往往是阻碍其进入生产环境的核心瓶颈。缺乏标准化的度量手段，使得优化过程如同“盲盒”调试。“智能体评测” 模块正是为了破解这一难题而构建的工业级评估引擎。
其核心价值在于：
从“随机”到“确定”： 支持海量测试用例的批量并发执行，告别碎片化的单次点对点调试，实现从“抽样检查”到“全面质检”的工程化跨越。
多维精准度量： 深度集成回复准确性评估体系，通过对语义一致性、逻辑完整性及业务合规性的自动对标，将主观的感官体验转化为客观、可量化的数据指标。
数据驱动迭代： 提供多版本效果的横向对比分析，直观呈现参数调整或 prompt 优化前后的增益差异，构建“测试—分析—调优”的持续改进闭环，让 AI 能力的进化清晰可见。

### 功能入口

登录 Agents 平台，在左侧一级导航菜单中点击【评测】，即可展开 评测数据集、评测规则、评测任务 管理。
