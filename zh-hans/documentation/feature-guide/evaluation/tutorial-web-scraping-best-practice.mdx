本文以新华网的“新华文化”一栏为例，展示平台爬虫工具的使用与配置逻辑😊
写在前面：平台爬虫的使用逻辑
用户可以在平台的“工具”模块中创建并且使用平台的“网页抓取”任务。通常来说，用户的需求可能是：利用爬虫工具，基于某一包含诸多标题信息的网页，去爬取这些标题对应的具体页面下的具体内容信息。据此，平台爬虫工具使用逻辑为：填写包含诸多标题信息的网址 ➡️ 利用正则筛选出想要爬取的链接 ➡️ 批量爬取这些链接对应的网页上的需求内容。

### 新建爬虫任务

首先，我们需要在平台上新建一个爬虫任务。创建方法：登陆平台后，点击“工具”-“官方工具”-“网页抓取”-页面右上位置的“新建抓取任务”。

### 抓取配置

任务开始，我们需要确定好作为信息来源的的网页地址。该网址应包含多条新闻标题（标题点开后会进入对应的具体的新闻内容）。
对于本任务来说，新华网的“新华文化”页，网址为：http://www.news.cn/culture/ 我们可以将这个网址复制，填写进“抓取网址”中，同时可以给新建的爬取任务取个简单易记的名称，例如“新华网-新华文化”，以便后续检查。
接下来点击“下一步”，进入“抓取字段配置”页面。

### 抓取字段配置（一）

首先，点击“添加爬取字段”的按钮。这是第一个爬取字段，我们使用它的逻辑为：根据刚刚输入的网址，筛选出网址中要爬取的那些新闻链接，然后逐一进入链接去爬取新闻内容。同时，因为该网址中可能包含比较多且杂的新闻链接，因此我们需要观察不同链接的特点，再用正则表达式来筛选出需要的链接。

<Frame>
  <img src="/images/documentation/ch6_6.10.10.4_0265.png" alt="网页抓取工具最佳实践" />
</Frame>

“字段key” ： 作为提供新闻链接的网址，此处我们可以设置字段key为“all”（代表着提取正则筛选后的全部新闻链接）。需要说明的是，字段key的名称会关联到后续agent的工作，所以对于平台的新手来说，用我们设定好的几个key名就好，不宜乱取名噢🤔
“字段描述”： 这是对于key的解释，因为这个网站筛选出来的实际上也是各条新闻的链接地址，所以我们不妨命名为“网页”。这一描述可以根据用户个人的理解来填写，具有个性化👏🏻
“字段类型”：下拉之后有两个选项，分别是“string”（提取网页内的文字内容）和“网页”（提取链接）两个选项。本任务中，由于这部分我们提取的是网页链接，所以请选择“网页”。
字段提取规则：这是根据网页的代码，我们应该设置的提取规则。与提取规则所对应的，是我们所需要的新闻网页。这里我们需要用正则筛选出链接。我们可以参考下面两张图，会发现需要的新闻的链接都带有“/culture/”，所以可以据此设置正则。

### 开始任务

返回爬虫任务页面下，在启动爬虫之前，我们还需要对爬虫任务进行“定时采集”的时间间隔设置。平台有“分钟”、“小时”、“天”这三个级别的爬取间隔，您可以根据需求进行配置。该部分填写完成后，点击“启动”，爬虫任务立即开始运行。
稍等一段时间后，您可以通过查看“爬取链接个数”确认爬虫是否成功爬取到网页内容；也可以在相应的知识库中查看，爬取到的内容是否已经按照您需求的格式存储进入知识库内。

### 补充部分：爬虫任务配套的agent规划

在这一部分，我们来简要地介绍下与爬虫配套的agent背后的设计逻辑。
上文已经介绍，每一个新闻的网页下，我们需要爬取的key主要有title、content、date，3个字段对应着网页上新闻的标题、新闻的内容、新闻发布的日期这3部分内容。实际上，对于每一部分内容，平台都是将其保存在以key名命名的变量中。另外，对于正则提取到的链接，平台会自动保存链接的url地址，也存进一个变量之中。我们在设计agent时，需要按照平台的逻辑将这些变量根据自己的格式需求进行变换、组装，最终存进知识库中。
在本任务中，我们需要每一个新闻页面的内容保存在一个知识库的切片中。具体来说，我们需要将新闻内容（content）保存在知识库切片的内容中，将新闻标题、url地址、发布时间保存在切片的标题之中。对于切片标题来说，我们可以通过agent规划中的“确定回复”模块，将新闻标题、url地址、发布时间以需求的格式表示出来，进而存进知识库中。
