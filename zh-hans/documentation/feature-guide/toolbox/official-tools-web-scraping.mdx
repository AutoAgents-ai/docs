### 概述

### 语法介绍

脚本语法由指令和指令参数组成。每个指令必须独占一行。
语法：\<指令\> \[=\>指令参数\]
指令：必须，每行只能有一个指令。指令如果返回值是选择器类型，则可以继续链式操作，如果非选择器类型则终止操作返回最终结果。最后一个指令一定是终止类型（非选择器类型）的指令。
=\> : 非必须，用于指定参数的符号
指令参数：非必须，无参数的指令就不用输入指令参数
示例1：
获取所有链接且过滤出只包含/articles/的链接
示例2：
获取任一html标签\<article\>中包含class属性是article-body的节点下的任一html标签\<h1\>下的标题内容
示例3：
获取任一html标签\<div\>中包含class属性是article-body的节点下的所有文章内容
