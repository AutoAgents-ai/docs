---
title: "数据字段说明表"
---

「使用记录与数据看板」中展示的关键数据字段及说明如下，便于业务人员理解统计口径。

| 字段 | 说明 |
| --- | --- |
| 智能体名称 | 用户创建的智能体名称，支持自定义命名或默认命名 |
| 创建人 | 创建该智能体的用户账号，用于归属管理和溯源 |
| 创建时间 | 智能体被创建的时间戳，用于追溯创建时间线 |
| 调用量 | 智能体被调用发起的对话交互总次数，反映使用活跃度 |
| Token 消耗量 | 该智能体在所有会话中消耗的 Token 总量，直接关联调用成本 |
| 使用部门/人员 | 调用该智能体的部门或人员，用于按维度统计使用情况 |
