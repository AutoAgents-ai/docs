页面头部与全局操作
页面标题：「数据库配置演示」，展示当前管理的数据库连接名称，左侧返回箭头可回到数据库列表页。
刷新数据源按钮：位于页面右上角，点击可重新同步数据库最新表结构与数据。
表搜索框：位于左侧列表顶部，支持通过输入表名、中文名对数据库表进行模糊检索。
左侧数据表列表
以树形列表形式展示当前数据库下的所有数据表，点击表名可在右侧查看对应表的结构详情。
当前选中表「XX章节」以高亮样式展示，标识当前操作的目标表。

### 表基础信息区

表名称与描述：展示当前选中表的名称「XX章节」，默认显示「暂无描述」。
数据表自定义描述输入框：支持输入该数据表的个性化说明。
字段搜索框：支持通过输入字段名、注释对当前表的字段进行模糊检索。
字段信息管理表格
表格包含 5 列核心信息，用于管理数据表字段：
字段名称：展示数据库原生的字段名（如chapter_content、chapter_number等），不可编辑。
字段注释：展示数据库原生的字段注释，无注释时显示「-」。
自定义注释：可编辑项，点击「点击编辑...」可输入自定义字段说明。
字段类型：展示字段的数据库数据类型（如text、int、varchar(255)等），不可编辑。
是否启用：开关控件，蓝色开启状态表示该字段可使用。
