title: "适用范围"
---

### 适用对象

本手册适用于Agents 平台在客户单位中的平台管理员、业务配置人员、应用搭建人员及普通使用人员。不同角色依据授权范围完成资源管理、能力搭建、应用发布和日常使用等工作。

| 适用维度 | 说明 |
| --- | --- |
| 组织对象 | 总部部门、分支机构、项目团队、专项工作组等 |
| 业务场景 | 知识服务、流程辅助、智能助手、应用封装、结果展示等 |
| 使用目标 | 快速搭建、持续优化、统一治理、提升协同效率 |
| 阅读对象 | 客户管理人员、建设人员、实际使用人员 |

### 适用场景

Agents 平台适用于知识问答、流程协作、业务填报、数据查询、应用展示、运营辅助和成果发布等场景，尤其适合希望以更低门槛、更快周期完成数字化能力建设和持续迭代的业务部门。

### 使用边界

本手册主要说明平台业务使用与配置方法，不替代基础设施部署说明、网络与安全制度说明以及中间件专项运维文档。涉及部署、资源申请、端口开通、数据库高可用和容灾备份等内容时，应同步参照《智能体平台部署方案-V2.0》。
