---
title: "明细穿透分析"
---

智能体：用户创建的 AI 应用 / 机器人的名称，支持自定义命名或默认命名。
创建者：创建该智能体的用户账号，用于归属管理和溯源。
创建日期：该智能体被创建的时间戳，用于追溯创建时间线。
总会话量：该智能体被用户调用发起的对话交互总次数，反映智能体的使用活跃度。
消耗 TOKEN 数：该智能体在所有会话中，用户输入和模型输出文本的 Token（文本处理单位）消耗总量，直接关联调用成本。

账号：发起会话的用户账号标识，用于用户行为追踪。
用户提问：用户向智能体发送的原始问题 / 指令内容，记录交互的输入侧信息。
点赞量：用户对该次智能体回复的正向反馈次数，反映用户对回复的满意度。
点踩量：用户对该次智能体回复的负向反馈次数，用于识别回复质量问题。
昵称：发起会话的用户昵称，便于业务侧识别用户身份。
所属部门：用户所属的组织 / 部门，用于按部门维度统计使用情况。
Agent 回复：智能体针对用户提问生成的回答内容，记录交互的输出侧信息。
