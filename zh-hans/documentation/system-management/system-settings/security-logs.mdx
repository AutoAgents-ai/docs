### 功能概述

功能名称：系统管理模块下的安全日志能力，用于核心价值：提供详尽的审计追踪面板，完整记录平台所有用户操作的全维度信息，支持条件查询与数据导出，满足等保合规要求，适用于适用场景：系统管理员在进行安全审计、操作追溯、合规检查及问题排查时使用。
安全日志功能可自动记录平台内所有用户的操作行为，包括操作时间、用户身份、操作内容、执行结果及设备网络信息等关键数据。系统管理员可通过该功能快速筛选特定时间范围的操作记录，追溯异常操作来源，同时支持将日志数据导出为 CSV 格式文件，为企业信息安全管理和等保合规审计提供完整的数据支撑。

### 功能入口

登录 Agents 平台，点击左侧导航栏的【系统管理】一级菜单，展开菜单列表后点击【安全日志】二级菜单，进入安全日志功能页面。

### 日志列表区域

展示所有符合查询条件的安全日志记录，每条记录包含以下 12 个字段：
序号：日志记录的顺序编号
创建时间：操作发生的具体时间（精确到秒）
用户 ID：执行操作的用户唯一标识
用户名：执行操作的用户名称
操作类型：操作的类别（如 LOGIN 登录、UPDATE 更新、LOGOUT 登出等）
操作内容：操作的具体参数和内容
操作结果：操作的执行状态，绿色 "成功" 表示操作执行完成，红色 "失败" 表示操作执行异常
来源 IP：执行操作的设备 IP 地址
MAC 地址：执行操作的设备物理地址
设备信息：执行操作的设备操作系统及浏览器信息
请求路径：操作对应的系统 API 接口地址
操作详情：操作的完整描述信息
日志列表底部提供分页控件，支持通过页码或翻页按钮浏览多页日志数据，同时显示日志总条数。

### 导出功能区域

数据导出按钮：位于页面右上角，点击后可将当前查询条件下的所有安全日志记录导出为 CSV 格式文件。
导出格式与内容：支持导出为标准 CSV 格式，兼容 Excel、WPS 等主流文档工具或notepad等相关文本工具直接打开查看、编辑、分析与归档等
