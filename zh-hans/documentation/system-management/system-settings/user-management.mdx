### 功能概述

支持添加和管理员工账号，填写昵称、密码、手机号、邮箱、用户角色及所属组织；可对账号执行启用/禁用操作，并支持账号搜索与整体导出。

### 功能入口

登录Agents 平台，点击首页左侧“系统管理”按钮，然后点击“用户管理”模块。

### 界面说明

用户管理
账号：用户登录平台的唯一身份标识，是平台识别用户的核心字段。
昵称：用户在平台内的展示名称，可自定义，用于友好识别用户身份。
组织：用户所属的组织 / 部门，用于按组织维度进行权限控制和数据统计。
邮箱：用户绑定的电子邮箱，可用于账号找回、通知推送等场景。
手机号：用户绑定的手机号码，用于账号安全验证、通知触达等场景。
添加账号：平台管理员可通过该功能新增用户账号，配置用户的基础信息与权限。
导出：支持将当前用户列表数据导出为文件，方便批量归档或线下分析。
编辑：管理员可修改用户的昵称、邮箱、手机号、所属组织等账号信息。
启用 / 禁用：管理员可控制账号的使用状态，禁用状态下用户无法登录平台，启用后恢复正常访问权限。
组织机构树：用于层级化展示用户所属的组织架构，方便按部门 / 组织筛选和管理用户。
