---
title: "运维建议"
---

建议客户单位建立“账号与权限定期巡检、模型与资源统一纳管、日志与用量持续监控、发布前后变更复核”的运维机制。对于面向较大范围使用的场景，应同步落实问题闭环、权限审计和使用反馈收集机制，保证平台长期稳定、规范运行。

| 模块 | 主要用途 |
| --- | --- |
| 模型配置 | 系统管理模块下的模型配置能力，用于核心价值：统一纳管平台接入的大模型，支持配置模型类型（对话 / 文生图 / 文本向量 / 重排序）、名称、Base URL 及 API Key（AES 加密存储）；模型创建后可设置上下文长度、是否为推理模型，并按部门 / 人员 / 角色 / 权限策略分配使用权限；提供 "我创建的" 与 "授权给我的" 两个独立视图，实现模型资源的全生命周期管理，适用于适用场景：系统管理员在接入企业自有大模型、配置模型参数、分配模型使用权限、统一管理平台模型资源时使用。 |
| 词典管理 | 功能名称：系统管理模块下的词典管理能力，用于核心价值：统一管理企业专属词典体系，提供敏感词库（风控合规拦截）、同义词库（标准化表述）、专业名词库（行业术语注入）三类词库管理，支持词库及词条的增删改查、批量导入与整体导出，提升智能体模型理解准确性与合规保障能力，适用于适用场景：系统管理员在配置智能体语言理解规则、设置内容风控策略、注入行业专业知识时使用。 |
| 权限策略管理 | 权限策略管理，可以为智能体、知识库、自定义工具、MCP、模型、数据库制定权限策略，控制用户是否可以查看和使用他人或组织上传的智能体、知识库和工具。 |
| 系统配置 | 系统配置包含通用，智能体类型、智能体推荐问、代码块外部环境的配置。 |
| 安全日志 | 功能名称：系统管理模块下的安全日志能力，用于核心价值：提供详尽的审计追踪面板，完整记录平台所有用户操作的全维度信息，支持条件查询与数据导出，满足等保合规要求，适用于适用场景：系统管理员在进行安全审计、操作追溯、合规检查及问题排查时使用。 |
| 数据看板 | 支持在智能体配置中设置隐私关键词拦截（禁止用户输入的内容），并关联预设敏感词库，从对话入口层面保障企业信息安全与合规要求。 |
