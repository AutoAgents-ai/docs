---
title: "Agent 聊天非流式接口（同步）"
---

请求参数与 [Agent 聊天流式接口](/zh-hans/api-reference/chat-stream) 基本一致，区别在于本接口一次性返回完整的响应结果（非 SSE 流）。

## 请求地址

```
{{host}}/openapi/agents/chat/completions/v1
```

或

```
{{host}}/openapi/v2/chat/completions
```

## 请求方式

`POST`

## 请求 Header

与 [Agent 聊天流式接口](/zh-hans/api-reference/chat-stream#请求-header) 相同：支持 ✅ Agent Token、✅ 个人秘钥，可选 `X-username`。

## 请求体参数

参数与[流式接口的请求体参数](/zh-hans/api-reference/chat-stream#请求体参数)完全一致（`agentId`、`chatId`、`userChatInput`、`state`、`buttonKey`、`images`、`files`、`formData`、`debug`）。

## 请求体示例

```json
{
    "agentId":"a2207c2f6d3d44d2b4a5dae5b5593750",
    "chatId": null,
    "userChatInput":"Mybatis",
    "images":[{"url":"your image url here"}],
    "files":[],
    "state":{
        "yourKey1":"yourValue1",
        "yourKey2":"yourValue2"
    },
    "buttonKey":"按钮id或者名字",
    "debug":false
}
```

## 响应体说明

| 字段 | 说明 |
| --- | --- |
| `chatId` | 对话 ID |
| `conversationId` | 当前会话 ID，一次对话包含多次会话 |
| `state` | 传入的环境变量参数，key/value 原值不变返回 |
| `memory` | Agent 运行过程中产生的变量信息（key/value），例如 `{"memoryKey1":"memoryValue1"}` |
| `choices` | 回复的内容数组，可能会有多条回复内容，每条结构与[流式响应体](/zh-hans/api-reference/chat-stream#流式响应体说明)中的单条消息一致（`messageId`、`type`、`componentName`、`content`、`complete`、`finish`、`status`、`role`、`bill`、`referenceType`、`reference` 等字段含义相同） |

<Info>
`choices` 中除最后一条 `finish:true` 的结束消息外，每条消息代表一次独立的回复（一次会话可能包含多次回复）。
</Info>
