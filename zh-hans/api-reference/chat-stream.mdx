---
title: "Agent 聊天流式接口"
---

## 请求地址

```
{{host}}/openapi/agents/chat/stream/v1
```

或

```
{{host}}/openapi/v2/chat/stream
```

## 请求方式

`POST`

## 请求 Header

参考[接口规范](/zh-hans/api-reference/overview)的认证方式章节；支持 ✅ Agent Token、✅ 个人秘钥。

| Header | 说明 |
| --- | --- |
| `X-username` | `{Your UserName}`，用户登录名，非必填；传入后系统会以该登录名身份调用接口，访问日志等均记录为该用户名下。不传默认使用 Token 所属人作为调用者身份记录。（v1.9.3+） |

## 请求体参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `agentId` | string | 是 | Agent UUID |
| `chatId` | string | 否 | 对话 ID，非必填，第一次会话不填；如果想在后续会话使用上下文，需要在下一次请求时带上上一次会话的流响应体中的 `chatId` |
| `userChatInput` | string | 是 | 用户输入 |
| `state` | object | 否 | 传入环境变量参数，key/value 由调用方自主定义；智能体编排通过 `{{_state.yourKey}}` 可以获取到对应参数，例如 `{"yourKey1":"yourValue1","yourKey2":"yourValue2"}` |
| `buttonKey` | string | 否 | 按钮名或者按钮 ID |
| `images` | array | 否 | 图片提问参数，支持传入图片 URL，也支持传入 Data URI（智能对话组件和图片提问组件支持，其他组件不支持），例如 `[{"url":"http://imageUrl"}]` |
| `files` | array | 否 | 文档提问/文档审核，参见下方示例 |
| `formData` | object | 否 | 表单输入，`formConfig` 表示表单的展示配置，`values` 表示用户 key-value 形式的输入，key 对应展示配置里面 `fields` 里面的 key |
| `debug` | boolean | 否 | 是否启用调试模式，默认 `false`；启用调试模式后会详细记录每次请求的入参、出参、异常信息，内容会比较多，如果不开启只会记录异常调用的信息。生产环境建议设置为 `false` 或不填 |

## 流式响应体说明

响应为 SSE 流，每行以 `data:` 开头，携带一个 JSON 对象。

| 字段 | 说明 |
| --- | --- |
| `chatId` | 对话 ID |
| `conversationId` | 当前会话 ID，一次对话包含多次会话 |
| `messageId` | 消息 ID，标识某个回复消息，可以用于点赞/踩；当 `complete=true&finish=false` 时有值 |
| `type` | 消息类型，见下表 |
| `componentName` | 当前组件名 |
| `content` | 流式内容，格式随 `type` 变化 |
| `reasoningContent` | 思考推理内容，仅思考模型（如 deepseek-R1）支持返回该字段 |
| `thinkingElapsedMillSecs` | 思考推理耗时，单位毫秒，仅思考模型支持返回该字段 |
| `complete` | `true` 代表流式一次会话中某次回复结束（一次会话可能会有多次回复） |
| `finish` | `true` 代表流式一次会话请求全部结束 |
| `status` | 消息状态：`1` 正常消息，`0` 失败消息，`-1` 异常消息 |
| `role` | 当前消息角色，一般是用户信息或 Agent 信息（头像、名称等） |
| `bill` | 流式一次会话中某次回复结束（`complete=true`）的 Token 消耗情况 |
| `referenceType` | 引用类型：`web_search` 网页搜索、`kb_search` 知识库搜索、`kb_search_img_list` 知识库搜索图片 |
| `reference` | 引用内容，格式随 `referenceType` 变化 |
| `references` | `Map<$referenceType, $reference>`；当某次调用出现多种引用内容时，会将多个引用内容合并输出，key 为引用类型，value 为引用内容。流式接口一般不会合并输出，非流式接口会有合并输出的情况 |

### `type` 取值

| 取值 | 说明 |
| --- | --- |
| `text` | 普通文本 |
| `markdown` | markdown 格式 |
| `pic` | 图片地址，一般用于文生图 |
| `buttons` | 编排中的按钮消息，也可能包含表单 |
| `feedback` | 反馈，一般用于多 Agent 协作时反馈某 Agent 的结果情况，以进行后续流程；反馈接口参考 [Agent 反馈接口](/zh-hans/api-reference/agent-feedback) |
| `chart` | SQL 查询结果可视化图表信息 |
| `table` | SQL 查询的结果信息 |
| `result_file` | 生成的文件 |
