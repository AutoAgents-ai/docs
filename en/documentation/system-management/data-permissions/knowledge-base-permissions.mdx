### Feature Overview

Feature Name: The Knowledge Base Permission Management capability under the Data Permission Management module. Core Value: Controls the retrieval and visibility boundaries of sensitive document collections, supporting authorization assignment by department, user, role, or predefined permission policy to ensure that different departments / roles can only access authorized knowledge base content. Use Cases: Used by system administrators when assigning access permissions for enterprise knowledge bases, protecting internal sensitive documents, or defining the scope of knowledge base usage across different business lines.

Through the Knowledge Base Permission Management feature, administrators can apply unified access control across all knowledge bases within the enterprise, preventing unauthorized users from accessing sensitive documents and data, safeguarding enterprise knowledge assets, and enabling fine-grained, tiered management of knowledge base resources.

### Accessing the Feature

Log in to the Agents platform, click the top-level [Data Permission Management] menu in the left navigation, then click the [Knowledge Base Permission Management] submenu after the menu list expands, to enter the Knowledge Base Permission Management page.

### Search Area

Search box: Enter the knowledge base name or description to quickly filter matching knowledge bases; supports fuzzy search.

<Frame>
  <img src="/images/documentation/ch7_7.5.3.4_0328.png" alt="Knowledge Base Permission Management" />

### Knowledge Base List

Displays basic information and the permission management entry point for all knowledge bases on the platform. Each record includes the following fields:
Name: The name of the knowledge base
Creator: The user account that created the knowledge base
Description: A description of the knowledge base's content and purpose
Authorization Management: Provides a "Manage Permissions" button; clicking it opens the usage permission assignment dialog for the knowledge base
The bottom of the list shows the total number of knowledge bases and pagination controls, supporting browsing across multiple pages via page numbers or navigation buttons.

<Frame>
  <img src="/images/documentation/ch7_7.5.3.5_0329.png" alt="Knowledge Base Permission Management" />
</Frame>

### Assign Usage Permissions

Click the "Manage Permissions" button next to any knowledge base to open the usage permission assignment dialog, which contains four authorization dimension tabs plus a global authorization option:

<Frame>
  <img src="/images/documentation/ch7_7.5.3.6_0330.png" alt="Knowledge Base Permission Management" />
</Frame>

### Department Tab

Organizational structure tree: Displays the enterprise's complete department hierarchy, supporting expand / collapse at each level
Search box: Enter a department name to quickly locate the target department
Checkbox: Select the departments to authorize; all users in the selected department(s) will gain access to the corresponding knowledge base
Visible to All option: When checked, the knowledge base becomes visible to all platform users with basic access permissions

<Frame>
  <img src="/images/documentation/ch7_7.5.3.7_0331.png" alt="Knowledge Base Permission Management" />
</Frame>

### User Tab

User list: Displays all user accounts on the platform, with search support
Selected Users area: Displays the users who have been selected for authorization, with support for removal
Once a user is selected, they automatically gain basic access to the corresponding knowledge base

<Frame>
  <img src="/images/documentation/ch7_7.5.3.8_0332.png" alt="Knowledge Base Permission Management" />
</Frame>

### Role Tab

Role list: Displays all predefined user roles on the platform, with search support
Selected Roles area: Displays the roles that have been selected for authorization, with support for removal
Once a role is selected, all users under that role automatically gain basic access to the corresponding knowledge base

<Frame>
  <img src="/images/documentation/ch7_7.5.3.9_0333.png" alt="Knowledge Base Permission Management" />
</Frame>

### Permission Policy Tab

Permission policy list: Displays all predefined permission policies applicable to knowledge bases, with search support
Selected Policies area: Displays the policies that have been selected for authorization, with support for removal
Once a permission policy is selected, all permissions defined in that policy are automatically applied to the corresponding knowledge base

<Frame>
  <img src="/images/documentation/ch7_7.5.3.10_0334.png" alt="Knowledge Base Permission Management" />
</Frame>

### Dialog Footer Buttons

Cancel: Closes the dialog without saving any authorization changes
Confirm: Saves and applies all authorization configurations

### Operation Steps

### 1. Access the Knowledge Base Permission Management Page

Following the steps above, log in to the Agents platform and navigate to the Knowledge Base Permission Management page

<Frame>
  <img src="/images/documentation/ch7_7.5.3.13_0336.png" alt="Knowledge Base Permission Management" />
</Frame>

To quickly locate a target knowledge base, enter its name or description in the search box to filter results

<Frame>
  <img src="/images/documentation/ch7_7.5.3.13_0337.png" alt="Knowledge Base Permission Management" />
</Frame>

### 2. Assign Knowledge Base Usage Permissions

Find the knowledge base for which you want to configure permissions in the list, then click the [Manage Permissions] button on its right to open the usage permission assignment dialog

<Frame>
  <img src="/images/documentation/ch7_7.5.3.14_0338.png" alt="Knowledge Base Permission Management" />
</Frame>

Select one or more of the following authorization methods based on your needs:

<Frame>
  <img src="/images/documentation/ch7_7.5.3.14_0339.png" alt="Knowledge Base Permission Management" />
</Frame>

Method 1: Authorize by Department
Switch to the [Department] tab
Select the departments to authorize in the organizational structure tree (multiple departments can be selected at once)
To grant access to all users, check the [Visible to All] option in the lower-left corner
Click [Confirm] to complete department authorization

<Frame>
  <img src="/images/documentation/ch7_7.5.3.14_0340.png" alt="Knowledge Base Permission Management" />
</Frame>

Method 2: Authorize by User
Switch to the [User] tab
Select the users to authorize in the user list (multiple users can be selected at once)
Click [Confirm] to complete user authorization

<Frame>
  <img src="/images/documentation/ch7_7.5.3.14_0341.png" alt="Knowledge Base Permission Management" />
</Frame>

Method 3: Authorize by Role
Switch to the [Role] tab
Select the roles to authorize in the role list (multiple roles can be selected at once)
Click [Confirm] to complete role authorization

<Frame>
  <img src="/images/documentation/ch7_7.5.3.14_0342.png" alt="Knowledge Base Permission Management" />
</Frame>

Method 4: Authorize by Permission Policy
Switch to the [Permission Policy] tab
Select the predefined permission policies to apply in the permission policy list (multiple policies can be selected at once)
Click [Confirm] to complete policy authorization
Once authorization is configured, the corresponding departments / users / roles will immediately gain access to the knowledge base and can retrieve and view its documents

<Frame>
  <img src="/images/documentation/ch7_7.5.3.14_0343.png" alt="Knowledge Base Permission Management" />
</Frame>
