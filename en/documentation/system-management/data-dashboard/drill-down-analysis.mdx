---
title: "Drill-Down Analysis"
---

Agent: The name of the AI application/bot created by the user, which supports custom or default naming.
Creator: The user account that created the Agent, used for ownership management and traceability.
Creation Date: The timestamp when the Agent was created, used to trace the creation timeline.
Total Conversations: The total number of dialogue interactions initiated by users with the Agent, reflecting its usage activity.
Tokens Consumed: The total number of Tokens (text-processing units) consumed by user input and model output across all conversations with the Agent, directly tied to invocation costs.

Account: The user account identifier that initiated the conversation, used for user behavior tracking.
User Question: The original question/instruction content sent by the user to the Agent, recording the input side of the interaction.
Likes: The number of positive feedback ratings the user gave this Agent response, reflecting user satisfaction with the reply.
Dislikes: The number of negative feedback ratings the user gave this Agent response, used to identify response quality issues.
Nickname: The nickname of the user who initiated the conversation, making it easier to identify the user's identity from a business perspective.
Department: The organization/department the user belongs to, used for usage statistics by department.
Agent Response: The answer content generated by the Agent in response to the user's question, recording the output side of the interaction.
