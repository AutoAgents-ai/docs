---
title: "System Management Capability Overview"
---

The System Management module serves as the central hub for platform security, compliance, and stable operation, providing unified governance capabilities across four areas: operation assurance, data dashboard, data permissions, and system configuration.
- Operation Assurance: Provides maintenance recommendations and inspection mechanisms to ensure the platform's long-term stable operation (see "Operation Assurance Recommendations" and "Maintenance Recommendations").
- Data Dashboard: Ranges from global operating metrics to detailed drill-down analysis, helping administrators understand platform usage (see "Data Dashboard").
- Data Permission Management: Manages access rights for shared resources such as databases, Agents, and knowledge bases (see "Data Permission Management").
- System Management: Covers capabilities such as security logs, permission policies, model configuration, user/tenant/organization/role management, and dictionary management (see "System Management").
