### Feature Overview

Tenant management supports creating tenants on a per-company basis, with the core capability of enforcing strict information isolation between tenants. Different tenants operate completely independently: all data created by users under Tenant A—such as Agents and knowledge bases—is fully inaccessible to users of other tenants (e.g., Tenant B), ensuring data security and privacy. Each tenant also has its own dedicated platform environment, guaranteeing operational independence and data privacy.

### Use Cases

This feature is suited for scenarios where multiple user groups need to use platform features independently.

### Accessing the Feature

Click the [System Management \> Tenant Management] menu in the left navigation to enter the Tenant Management page.
