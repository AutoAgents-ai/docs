### Feature Overview

Feature Name: The dictionary management capability under the System Management module. Core Value: Provides unified management of an enterprise's dedicated terminology systems, covering three types of word lists—sensitive word lists (for risk control and compliance interception), synonym lists (for standardizing terminology), and specialized term lists (for injecting industry-specific terminology)—supporting create, read, update, and delete operations on word lists and entries, as well as batch import and bulk export, improving the Agent model's comprehension accuracy and compliance safeguards. Use Cases: Used by system administrators when configuring an Agent's language understanding rules, setting content risk-control policies, or injecting industry-specific knowledge.
The dictionary management feature helps enterprises build a terminology system tailored to their own business needs: sensitive word lists enforce content compliance and risk control, synonym lists standardize the interpretation of different expressions, and specialized term lists inject industry-specific knowledge into the Agent—ensuring the accuracy, professionalism, and compliance of Agent responses.

### Accessing the Feature

Log in to the Agents platform, click the top-level [System Management] menu in the left navigation, then click the [Dictionary Management] submenu after the menu list expands, to enter the Dictionary Management page.

### Word List Area

Displays all word lists under the current tab. Each word list record includes the following fields:
Word List Name: The unique name identifying the word list
Description: A description of the word list's purpose and content
Creator: The user account that created the word list
Last Modified: The time the word list was last modified
Actions: Provides "Edit" and "Delete" buttons for modifying or deleting the word list
The bottom of the list shows the total number of word lists and pagination controls for browsing multiple pages.

<Frame>
  <img src="/images/documentation/ch7_7.6.10.6_0427.png" alt="Dictionary Management" />
</Frame>

### Create Word List Button Area

Create Word List button: Located in the top-right corner of the page; the button label changes based on the current tab (e.g., "Create Sensitive Word List," "Create Synonym List," "Create Specialized Term List"). Clicking it opens the new word list dialog.

<Frame>
  <img src="/images/documentation/ch7_7.6.10.7_0428.png" alt="Dictionary Management" />
</Frame>

New Word List dialog
Dictionary Type: Automatically determined by the currently selected word list tab; cannot be manually selected, and cannot be changed after creation
Word List Name\*: Required. Enter the word list name, up to 50 characters
Word List Description: Optional. Enter a description of the word list's purpose and content, up to 500 characters
Cancel / Confirm buttons: Click "Cancel" to close the dialog, or "Confirm" to complete word list creation

### Entry List Area

Displays all entries within the current word list. Entry fields vary by word list type:
