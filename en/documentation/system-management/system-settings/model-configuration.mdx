### Feature Overview

The model configuration capability under the System Management module. Core Value: Provides unified management of large language models connected to the platform, supporting configuration of model type (Chat / Text-to-Image / Text Embedding / Reranking), name, Base URL, and API Key (stored with AES encryption). After a model is created, its context length and whether it is a reasoning model can be set, and usage permissions can be assigned by department / user / role / permission policy. Provides two independent views—"Created by Me" and "Shared with Me"—enabling full lifecycle management of model resources. Use Cases: Used by system administrators when connecting proprietary enterprise models, configuring model parameters, assigning model usage permissions, or centrally managing platform model resources.

Through the model configuration feature, enterprises can connect self-hosted or third-party large language models to the Agents platform in a unified way, flexibly configure model parameters and access permissions, and ensure the secure and orderly use of model resources—while meeting the differentiated needs of various business scenarios for model capabilities.

### Accessing the Feature

Log in to the Agents platform, click the top-level [System Management] menu in the left navigation, then click the [Model Configuration] submenu after the menu list expands, to enter the Model Configuration page.

### Interface Overview

### Main Interface

The main model configuration interface uses a dual-view design: view-switching tabs at the top, function buttons in the top-right corner, the model list as the main content area, and the platform's built-in model provider section at the bottom.
View-switching tabs: Includes "Created by Me" and "Shared with Me" tabs; click to switch between models within different permission scopes
Add Custom Model button: Located in the top-right corner of the page; click to open the add custom model dialog
Model list: Displays model information as cards; hovering over a model card in "Created by Me" reveals action buttons
Model provider section: Displays all built-in large language model providers and their models, allowing you to quickly add models from a given provider

### Assign Usage Permissions

Click the "Assign Usage Permissions" button on a model card to open the permission assignment dialog. This dialog follows the same logic as other permission management modules on the platform and supports four authorization dimensions.
Department: Authorize by enterprise organizational structure; once a department is selected, all users in that department gain usage permissions for the model
User: Authorize individual users; precisely specify which users can use the model
Role: Authorize by user role; all users under the same role receive the same permissions
Permission Policy: Apply a predefined permission policy to assign permissions in bulk
Visible to All: When checked, the model becomes available to all platform users
For detailed permission control information, see [\*\*Agent Permission Management](https://uxkpl4cba3j.feishu.cn/wiki/KsoowkS6li29rMkdijdc8BjrnRd#share-HUT1dvySPoYtU5x6WDdcFJE8nae) (sections 2.1 - 2.4)
