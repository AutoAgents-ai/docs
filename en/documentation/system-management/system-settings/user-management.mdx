### Feature Overview

Supports adding and managing employee accounts, including nickname, password, phone number, email, user role, and organization. Accounts can be enabled or disabled, and support search and bulk export.

### Accessing the Feature

Log in to the Agents platform, click the "System Management" button on the left side of the homepage, then click the "User Management" module.

### Interface Overview

### User Management

Account: The unique identifier a user uses to log in to the platform; the platform's core field for identifying users.
Nickname: The user's display name on the platform; customizable, used to friendlily identify the user's identity.
Organization: The organization / department the user belongs to, used for permission control and data statistics by organization.
Email: The user's bound email address, which can be used for account recovery, notification delivery, and other scenarios.
Phone Number: The user's bound phone number, used for account security verification, notification delivery, and other scenarios.
Add Account: Allows platform administrators to create new user accounts and configure basic information and permissions.
Export: Supports exporting the current user list as a file for batch archiving or offline analysis.
Edit: Allows administrators to modify a user's nickname, email, phone number, organization, and other account information.
Enable / Disable: Allows administrators to control an account's usage status; a disabled account cannot log in to the platform, while enabling it restores normal access.
Organizational Structure Tree: Displays the organizational structure that users belong to in a hierarchical view, making it easier to filter and manage users by department / organization.
