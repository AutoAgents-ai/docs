### Feature Overview

System configuration includes general settings, Agent type configuration, Agent recommended questions, and code block external environment configuration.

<Frame>
  <img src="/images/documentation/ch7_7.6.7.1_0401.png" alt="System Configuration" />
</Frame>

### Use Cases

This feature is used in scenarios where system parameters need to be configured.

### Accessing the Feature

Click the [System Management \> System Configuration] menu in the left navigation to enter the System Configuration page.

  <img src="/images/documentation/ch7_7.6.7.3_0402.png" alt="System Configuration" />
</Frame>

### Operation Steps

### General

<Frame>
  <img src="/images/documentation/ch7_7.6.7.6_0404.png" alt="System Configuration" />
</Frame>

The general configuration interface allows you to configure the system logo, login page background, and other system parameters.
Parameter Notes:
Differences across deployment environments
Agent Type

<Frame>
  <img src="/images/documentation/ch7_7.6.7.6_0405.png" alt="System Configuration" />
</Frame>

The Agent Type configuration page allows you to configure Agent types. Click Add, enter the tag name in the popup, and click Confirm.

<Frame>
  <img src="/images/documentation/ch7_7.6.7.6_0406.png" alt="System Configuration" />
</Frame>

Agent Recommended Questions

<Frame>
  <img src="/images/documentation/ch7_7.6.7.6_0407.png" alt="System Configuration" />
</Frame>

This interface allows you to configure whether recommended questions are enabled, along with the embedding model, summarization model, relevance threshold, and privacy protection keywords for recommended questions.
Code Block External Environment

<Frame>
  <img src="/images/documentation/ch7_7.6.7.6_0408.png" alt="System Configuration" />
</Frame>

This feature allows you to configure the name, URL, programming language, and other information for external environments. Click Add Environment and fill in the relevant information to add one.
