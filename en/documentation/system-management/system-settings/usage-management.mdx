### Feature Overview

The usage management feature allows users to view information such as the system model's Token limit, the system model's remaining available Tokens, the system model's expiration date, and the Tokens already used under the tenant's configured model.

  <img src="/images/documentation/ch7_7.6.5.1_0396.png" alt="Usage Management" />
</Frame>

### Use Cases

Scenarios where users want to understand model usage.

### Accessing the Feature

Click the [System Management \> Usage Management] menu in the left navigation to enter the Usage Management page and view usage information.
