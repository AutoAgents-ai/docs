### Feature Overview

Feature Name: The security log capability under the System Management module. Core Value: Provides a detailed audit trail dashboard that fully records all-dimensional information on every user operation on the platform, supporting conditional queries and data export to meet compliance requirements for classified protection standards. Use Cases: Used by system administrators for security audits, operation traceability, compliance checks, and issue investigation.
The security log feature automatically records the operational behavior of all users on the platform, including key data such as the operation time, user identity, operation content, execution result, and device/network information. System administrators can use this feature to quickly filter operation records within a specific time range, trace the source of anomalous operations, and export log data as CSV files, providing complete data support for enterprise information security management and classified protection compliance audits.

### Accessing the Feature

Log in to the Agents platform, click the top-level [System Management] menu in the left navigation, then click the [Security Logs] submenu after the menu list expands, to enter the Security Logs page.

### Query Area

Query Range: Used to filter security log records within a specified time range. Supports selecting a start date and end date; click the date picker to set the time range.

  <img src="/images/documentation/ch7_7.6.1.4_0346.png" alt="Security Logs" />

### Log List Area

Displays all security log records matching the query criteria. Each record includes the following 12 fields:
No.: The sequential number of the log record
Created At: The exact time the operation occurred (to the second)
User ID: The unique identifier of the user who performed the operation
Username: The name of the user who performed the operation
Operation Type: The category of the operation (e.g., LOGIN, UPDATE, LOGOUT, etc.)
Operation Content: The specific parameters and content of the operation
Operation Result: The execution status of the operation—green "Success" indicates the operation completed successfully, red "Failure" indicates an execution error
Source IP: The IP address of the device that performed the operation
MAC Address: The physical address of the device that performed the operation
Device Info: The operating system and browser information of the device that performed the operation
Request Path: The system API endpoint corresponding to the operation
Operation Details: The full description of the operation
The bottom of the log list provides pagination controls for browsing multiple pages of log data via page numbers or navigation buttons, along with the total number of log records.

### Export Function Area

Export Data button: Located in the top-right corner of the page; click to export all security log records matching the current query criteria as a CSV file.
Export Format and Content: Supports exporting to standard CSV format, compatible with mainstream document tools such as Excel and WPS, or text tools like Notepad, for direct viewing, editing, analysis, and archiving.
