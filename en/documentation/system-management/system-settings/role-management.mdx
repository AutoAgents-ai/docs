### Feature Overview

Role management is a core module in information systems, access control, and organizational governance. Its core logic is to group users by "role" and assign permissions and responsibilities uniformly, rather than granting permissions to individual users directly—achieving standardized, reusable, and easily manageable permission control.

### Use Cases

Roles can be categorized by usage permissions, such as regular users, operations staff, Agent developers, and knowledge base developers.

### Accessing the Feature

Click the [System Management \> Role Management] menu in the left navigation to enter the Role Management page.

### Operation Steps

### Add a Role

<Frame>
  <img src="/images/documentation/ch7_7.6.9.6_0413.png" alt="Role Management" />
</Frame>

Click the Add Role button to enter the add role page.

<Frame>
  <img src="/images/documentation/ch7_7.6.9.6_0414.png" alt="Role Management" />
</Frame>

Fill in the role name and configure the menu permissions the role should have. Then switch to the data permissions view.

<Frame>
  <img src="/images/documentation/ch7_7.6.9.6_0415.png" alt="Role Management" />
</Frame>

Configure the data scope and data permissions, then click Confirm to complete adding the role.
Notes:
Menu Permissions: Defines which menus the role can see.
Data Scope: Defines which range of data the role can see, such as data belonging to a specific organization, or only the user's own data.
Data Permissions: If the data scope is set to "Custom," data permissions can be configured by organization.
Edit a Role

<Frame>
  <img src="/images/documentation/ch7_7.6.9.6_0416.png" alt="Role Management" />
</Frame>

Click the edit link in the list to enter the edit role page. Following the same steps described for adding a role, modify the elements as needed, then click the Confirm button to complete the edit.
Delete a Role

<Frame>
  <img src="/images/documentation/ch7_7.6.9.6_0417.png" alt="Role Management" />
</Frame>

Click the delete link in the list to delete the role.
