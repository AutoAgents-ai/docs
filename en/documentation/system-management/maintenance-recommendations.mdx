---
title: "Maintenance Recommendations"
---

We recommend that client organizations establish an operational mechanism covering "regular inspection of accounts and permissions, unified management of models and resources, continuous monitoring of logs and usage, and change review before and after releases." For scenarios with broader usage, organizations should also implement issue closed-loop tracking, permission audits, and usage feedback collection to ensure the platform's long-term stable and standardized operation.

| Module | Primary Purpose |
| --- | --- |
| Model Configuration | The model configuration capability under the System Management module. Core Value: Provides unified management of large language models connected to the platform, supporting configuration of model type (Chat / Text-to-Image / Text Embedding / Reranking), name, Base URL, and API Key (stored with AES encryption). After a model is created, its context length and whether it is a reasoning model can be set, and usage permissions can be assigned by department / user / role / permission policy. Provides two independent views—"Created by Me" and "Shared with Me"—enabling full lifecycle management of model resources. Use Cases: Used by system administrators when connecting proprietary enterprise models, configuring model parameters, assigning model usage permissions, or centrally managing platform model resources. |
| Dictionary Management | Feature Name: The dictionary management capability under the System Management module. Core Value: Provides unified management of an enterprise's dedicated terminology systems, covering three types of word lists—sensitive word lists (for risk control and compliance interception), synonym lists (for standardizing terminology), and specialized term lists (for injecting industry-specific terminology)—supporting create, read, update, and delete operations on word lists and entries, as well as batch import and bulk export, improving the Agent model's comprehension accuracy and compliance safeguards. Use Cases: Used by system administrators when configuring an Agent's language understanding rules, setting content risk-control policies, or injecting industry-specific knowledge. |
| Permission Policy Management | Permission policy management allows administrators to define permission policies for Agents, knowledge bases, custom tools, MCP, models, and databases, controlling whether users can view and use Agents, knowledge bases, and tools uploaded by other users or organizations. |
| System Configuration | System configuration includes general settings, Agent type configuration, Agent recommended questions, and code block external environment configuration. |
| Security Logs | Feature Name: The security log capability under the System Management module. Core Value: Provides a detailed audit trail dashboard that fully records all-dimensional information on every user operation on the platform, supporting conditional queries and data export to meet compliance requirements for classified protection standards. Use Cases: Used by system administrators for security audits, operation traceability, compliance checks, and issue investigation. |
| Data Dashboard | Supports configuring privacy keyword interception (blocking specific user input) in Agent settings, and linking to a preset sensitive word list, safeguarding enterprise information security and compliance requirements at the conversation entry point. |
