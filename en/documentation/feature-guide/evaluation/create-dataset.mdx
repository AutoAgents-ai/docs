### Steps

Step 1: Click the "Create Dataset" button in the upper-right corner.
Step 2: Enter the dataset name, then configure the column name, type, whether it's required, and description for each column. If you need to add more columns, click the "Add Column" button.
Step 3: Click the "Create" button.
