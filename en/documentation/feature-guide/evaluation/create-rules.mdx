### Steps

Step 1: Click the "Create Rule" button in the upper-right corner.
Step 2: Enter the rule name and description, and select the rule type.
Step 3 (Code rule): Enter a Python function (can be created from a template) and define the evaluation input parameters.
Step 3 (Prompt rule): Enter a prompt (can be created from a template), and select the evaluation model, Max Tokens, Temperature, and Top P parameters.
Step 4: Click "Confirm" in the lower-right corner.

### Evaluation Tasks

On the "Evaluation Tasks" page, users can create evaluation tasks using existing evaluation datasets and evaluation rules, and can also manage and monitor the running status of Agent evaluation tasks.
