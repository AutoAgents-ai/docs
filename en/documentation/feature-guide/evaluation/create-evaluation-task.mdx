---
title: "Create an Evaluation Task"
---

### Steps

Step 1: Click the "Create Rule" button in the upper-right corner.
Step 2 (Evaluation Target Configuration): Enter the evaluation task name and description, select the evaluation target (Agent), and set the concurrency for the evaluation.
Step 3 (Evaluation Set Configuration): Select the evaluation dataset and the data range (optional), and choose the user input (which field in the dataset serves as the Agent's input), the image (optional), and the attachment (optional).
Step 4 (Rule and Mapping Configuration): Select and add one or more evaluation rules, then choose the data source for the parameters mapped to fields within each rule.
Step 5: Click the "Create" or "Create and Run" button in the lower-right corner.
