Role-play bots are a common type of AI Agent. By having the AI play a specific character and giving it defined knowledge and a particular personality, you can build a role-play bot. In this example, we'll use an AI Agent that role-plays as "Sun Wukong" to walk through the logic of canvas planning and help you quickly get familiar with how Agents are orchestrated.

### Optimization Tips

Here we've also adjusted the parameter that controls the model's response creativity.
In machine learning and AI, temperature—i.e., response creativity—is typically a parameter used when generating text or samples, especially with probability distributions like the Softmax function. This parameter controls the diversity of the model's output.
The model calculates a probability for each possible output and normally picks the one with the highest probability as the final result. The temperature parameter introduces a control factor that affects how flat or sharp these probability distributions are. A higher temperature flattens the probability distribution, making the model more likely to produce more diverse output; a lower temperature sharpens the distribution, making the model more likely to choose the most probable output.
We want the "Sun Wukong" character's responses to feel more lively and creative, so we set this value to 0.8. Below is a simple comparison, showing the Agent's responses with creativity set to 0 (left) and 0.8 (right).

### Response Creativity Set to 0.8

You can clearly see that with creativity set to 0.8, the AI's answers cover a wider range of angles, even bringing up less common motivations like "achieving a world of universal harmony," whereas with creativity set to 0, the answers lean toward more conventional and rigorous motivations, such as "protecting the master" or "vanquishing demons."
In addition, when designing an Agent, you'll often need to continually refine the prompt design and adjust related parameters to eventually arrive at a satisfying, personalized AI Agent.
