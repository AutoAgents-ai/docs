---
title: "System Settings"
---

During evaluation and debugging, you'll often need system built-in variables (such as `{{cTime}}`, `{{userChatInput}}`) and system built-in functions (date handling, string handling, JSON extraction, etc.) to configure node parameters or validation rules.

<Info>
The complete, up-to-date reference for system variables and functions now lives in the Advanced Development Guide, and is no longer duplicated on this page:

- [System Variables](/en/advanced-development/system-variables) — time, input, and resource variables, plus `{{systemContext}}` usage
- [System Functions](/en/advanced-development/system-functions) — date handling, string handling, JSON processing, conditionals/comparisons, encoding/language, file and web-scraping functions

For more advanced usage such as command-style invocation and code-block embedding, see [Built-in Commands](/en/advanced-development/built-in-commands) and [Code Block Embedding](/en/advanced-development/code-block-embedding) in the Advanced Development Guide.
</Info>
