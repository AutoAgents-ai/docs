### System Built-in Variables

### Usage Syntax

{{var}} references a variable
{{var:defautValue}} references a variable and sets a default value
{{@var}} references a variable; if the variable does not exist, this expression is still displayed as-is
{{cTime}} current date and time, yyyy-MM-dd HH:mm:ss
{{cDate}} current date, yyyy-MM-dd
{{cYear}} current year, yyyy

### {{cMonth}} Current Month

### {{cDay}} Current Day

{{cHHmmss}} current clock time, HH:mm:ss

### {{cMills}} Current Timestamp

{{cWeekdayNum}} day of week - number
{{cWeekdayEn}} day of week - English
{{cWeekdayEn2}} day of week - English abbreviation
{{cWeekdayCn}} day of week - Chinese
{{\_input}} all input parameter information
{{\_state}} input state parameter information
{{userChatInput}} input text parameter information
{{\_images\_}} input image parameter information
{{\_files\_}} input file parameter information
{{\$*db_type*}} database type information referenced by the Agent
{{\$*db_schema*}} database table schema information referenced by the Agent
{{\$kbIdList}} retrieves the list of knowledge base IDs selected by the user
{{systemContext}} retrieves the current system environment and logged-in user information (v1.9.0.0+)
