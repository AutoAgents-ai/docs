### Feature Overview

An enterprise-level platform for Skill sharing and governance. The platform ships with a built-in public Skill library covering mainstream scenarios, which enterprises can select from and localize as needed during private deployment. It also supports building a fully isolated internal SkillHub, where employees can publish, discover, and install internal-only Skills, forming a sustainable and governable in-house AI capability ecosystem.

### Entry Point

Log in to the Agents platform, click the Skill Management menu on the left side of the home page, and select the SkillHub tab to enter the SkillHub detail page.
