---
title: "Data Field Reference"
---

The key data fields shown in "Usage Records and Dashboard" are described below to help business users understand the statistical definitions.

| Field | Description |
| --- | --- |
| Agent Name | The name of the Agent created by the user; supports custom or default naming |
| Creator | The user account that created the Agent, used for ownership management and traceability |
| Created At | The timestamp when the Agent was created, used to trace the creation timeline |
| Invocation Count | The total number of conversation interactions initiated with the Agent, reflecting usage activity |
| Token Consumption | The total number of Tokens consumed by the Agent across all sessions, directly tied to invocation cost |
| Department/User | The department or user that invoked the Agent, used for usage statistics by dimension |
