Provides visualized data operation analysis and detailed interaction logs to help creators track an Agent's usage frequency, user distribution, interaction depth, and frequently asked questions, providing data support for the continuous optimization of the Agent.

### Steps

Step 1: Open the dashboard. On the target Agent card, click the "..." button in the lower-right corner and select "Usage Records" to navigate to that Agent's dedicated data analytics dashboard.
Step 2: Filter the data. At the top of the page, set the "query period" (such as the last week or last month), or enable "department linkage" and select a specific department in the dropdown tree to drill down by organizational dimension. For detailed records, you can also search precisely by account, session ID, input content, or output content keywords.
Step 3: Review trend metrics. In the dashboard area at the top, view the line-chart trends for each core operational metric. Some charts support multi-dimensional drill-down—for example, the user satisfaction rate can be switched between "likes" and "dislikes" via a dropdown, and data can also be filtered by access source (such as Discover Agents or shared links) via checkboxes.
Step 4: Review details and logs. In the "Usage Records" and "Frequently Asked Questions" lists at the bottom of the page, you can review individual conversation details and task status. For records that need investigation, click "Download Execution Log" in the Actions column to obtain the underlying run information.
Step 5: Export data. All detailed data tables on the page support data export—click the "Export Data" button in the top-right corner to download the complete data report locally for in-depth analysis.
