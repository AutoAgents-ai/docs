### Module Introduction

Allows users to upload an image and analyze it or ask questions about it using the visual model's image-recognition capabilities. Supports PNG, JPG, and JPEG formats, with a per-image limit of 30MB, suitable for visual understanding scenarios such as industrial inspection and receipt/invoice recognition.
