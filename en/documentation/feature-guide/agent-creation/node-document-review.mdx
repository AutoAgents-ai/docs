### Module Introduction

Used for document reading and review scenarios. After a user uploads a document, the system asks a series of preset batch review questions (up to 100) one by one, with AI providing the answers. Supports batch question import via a CSV template, making it suitable for scenarios such as contract review and compliance checks. The document is input on the left, and after being processed by the large language model, the result is output as the reply content.

Detailed interface description
Supports adding questions manually in the top-right corner, as well as adding questions via a template.
You can freely choose the model, with support for most mainstream domestic models.
Prompt: guidance text for the model. You can adjust this prompt to steer the direction of the model's responses; this content is fixed at the beginning of the conversation.
