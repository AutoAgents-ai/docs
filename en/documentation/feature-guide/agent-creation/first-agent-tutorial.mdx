### Introduction

Hi, welcome to the Agents Platform! In this tutorial, we'll walk you through building your first dedicated Agent, helping you quickly get familiar with the Agents Platform and experience the power of AI firsthand. The whole process takes about 3 minutes, and by the end you'll have turned your idea into an Agent you can chat with in real time. Let's get started!

### Step 1: Create an Agent

### Create from Blank or from a Template

After entering the Agents Platform, click "Create Agent" on the left side of the page to start the creation process. You can create an Agent in either of the following two ways:
Create from blank: Start building an Agent from scratch.
Create from template: Clicking this takes you to the "Application Templates" selection page, which includes 7 selectable template categories: All Categories, General Internet, Finance & Insurance, Public Services, Power & Energy, Healthcare, and Other. Choose based on your actual needs, then click "Copy Template" to use it.

Agent configuration
An Agent is the key bridge connecting users to their goals — it's responsible for receiving instructions, analyzing, executing, and conversing. Agent configuration is therefore a core platform capability that directly affects how well the Agent performs.
After creating an Agent from blank or from a template, you'll enter the Agent configuration page. Agents support a what-you-see-is-what-you-get configuration approach: the configuration panel is on the left, and the preview window is on the right.

<Frame>
  <img src="/images/documentation/ch6_6.1.44.3_0122.png" alt="Create Your First Agent" />
</Frame>

The configuration panel is used to configure parameters related to the Agent, determining its purpose and direction. The information you need to configure includes:
Agent name: Give your Agent a name;
Description: Write a brief description of your Agent explaining its purpose;
Agent type: Choose an appropriate Agent type, including: All Categories, General Internet, Finance & Insurance, Public Services, Power & Energy, Healthcare, and Other;
Chat background: Choose an appropriate chat background for your Agent — you can select a built-in background or customize your own;
Opening line: A prompt shown before the conversation with the Agent begins;
Suggested questions: No need to set this for now
Chat model: Default
Prompt: Use a prompt to define the goal this Agent is meant to achieve. Feel free to let your imagination run wild here, giving the Agent the capabilities you envision.
Knowledge base: We won't need a knowledge base this time, so there's no need to select one here

### Planning and Connections

Click "Planning" at the top to enter the Agent's planning page. This page is used to plan the Agent's execution flow — you can drag the modules you need onto the canvas and connect the nodes so that everything runs smoothly.
In this example, the Agent has already connected the "Text Information" node on the left to the "Information Input" node on the right. This connection means that the text question asked by the user will be output to the intelligent chat module, which will then process the information and reply within the conversation, as shown in the figure below.

With that, we've completed the basic setup for an Agent. Now that the Agent has the knowledge and AI capabilities we've assigned to it, click "Save" in the top-right corner.
Step 2: Chat Testing
Now our first Agent has been created. In the chat preview panel on the right, you can enter content and start chatting with the Agent — go ahead and try out your very own Agent.
As you chat, if you have more ideas for how the Agent should respond, you can adjust the prompt design at any time to achieve the results you want.
