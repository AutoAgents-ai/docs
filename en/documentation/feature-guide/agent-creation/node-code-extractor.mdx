### Feature Overview

The Code Extractor module is a practical tool the platform provides for developers, designed to precisely extract code snippets of a specified type from Markdown content generated by a large language model. It supports six mainstream code types — SQL, Python, Java, C, JSON, and JavaScript — and can identify and separate code segments mixed within natural language descriptions, outputting clean code text for subsequent direct use, execution, or further processing.
The core value of this module lies in:
Improved development efficiency: Automatically extracts executable code from model responses, avoiding the tedious work of manual copy-pasting and format cleanup.
Clean code guaranteed: Effectively separates natural language from code, ensuring the extracted code snippet can be directly run or integrated.
Seamless downstream flow: The extracted code can be passed as a variable directly to a subsequent Code Block module for execution, or to a Document Output module for saving, enabling workflow automation.

### Entry Point

The Code Extractor module is an independent functional node integrated into the platform's visual workflow orchestration canvas. To access this feature:
Drag the module: In the component library on the left side of the workflow canvas, find the "Code Extractor" module and drag it to the desired position on the canvas.
Name the module: Rename the module you've dragged onto the canvas for easier understanding and later management of the workflow.
Set the activation condition: Based on your business logic, configure "activate when all conditions met" or "activate when any condition met" to determine under what conditions the module begins execution.

### Interface Description

The Code Extractor's configuration interface is clean and straightforward, mainly consisting of an input parameter settings area and an output results display area.
Core parameter configuration
The configuration interface mainly includes the following parameters:
Activate when all conditions met: Boolean. This node can connect to multiple boolean inputs; when all upstream conditions are True, the current component is activated — that is, "execute this module only when all conditions are met."
Activate when any condition met: Boolean. This node can connect to multiple boolean inputs; when any upstream condition is True, the current component's execution logic is activated — that is, "execute this module when any condition is met."
Markdown input: String type. Connects to the Markdown-formatted text output by an upstream node, serving as the source content for code extraction.
Code type: Dropdown selector. Choose one of six code types — SQL, Python, Java, C, JSON, JavaScript — as the target type for this extraction.
Output: Read-only display area. After extraction runs, the system displays the extracted pure code text here.

### Operating Procedure

The following example demonstrates how to extract Python code from a Markdown text passage.
Step 1: Add the extraction node
On the micro-app orchestration canvas, drag the "Code Extractor" node from the toolbox to the desired position.
Step 2: Configure the extraction parameters
Click the node on the canvas, and configure it in the settings panel that appears on the right:
Set the activation condition: Based on your business logic, choose "activate when all conditions met" or "activate when any condition met."
Connect the Markdown input: Connect the Markdown content output by an upstream node (such as an intelligent chat module) to the "Markdown Input" port.
Select the code type: In the "Code Type" dropdown menu, select "Python."
Step 3: Run and view the result
Click the "Run" or "Test" button at the bottom of the configuration panel.
The system will execute the extraction logic and display the extracted pure Python code text directly in the "Output" area.
This code output can be used directly as a variable, referenced and executed by a subsequent Code Block module, or saved as a file by a Document Output module.
Step 4: Connect downstream modules
Execute the code: Connect the "Output" port to the "Code Content" input of a Code Block module to directly run the extracted code.
Save the code: Connect the "Output" port to a Document Output module to save the code as a Word document.
Best practices and notes
Input format: Ensure the upstream input content is in standard Markdown format, with code blocks wrapped in triple backticks and the correct language specified (e.g., `python`) — this is a prerequisite for accurate extraction.
Code type matching: The selected code type must match the actual code type contained in the Markdown; otherwise extraction may fail or return an empty result.
Error handling: It's recommended to connect a branch/condition node after the Code Extractor node in the workflow, designing different downstream paths based on whether code was successfully extracted.
Version support: This module is a base-tier platform feature, available to all users.
That covers the complete operating guide for the platform's Code Extractor module, helping you efficiently complete code extraction and integrate it into your business processes.
