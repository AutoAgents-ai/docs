### Feature Overview

The Document Output module is a core component in the platform used to output upstream-generated content as a Word document. It supports two working modes:

### Direct output mode:

Without using a template, the upstream component's output content is filled directly into a blank Word document.

### Template replacement mode:

Supports uploading a Word document template containing placeholders. The system automatically replaces the placeholders at the specified positions in the template with the variable values passed in from upstream, generating a structured report with consistent formatting and personalized content.
The core value of this module lies in automatically converting workflow data into standardized documents, greatly improving efficiency in scenarios such as report generation, contract drafting, and report summarization.

### Preparation

Identify the upstream data sources: Determine which upstream modules provide the content to be output to the document — for example, the user's question text, a summary generated by the intelligent chat module, or structured data extracted by an information extraction module.
Design the output template (optional): If you need a structured report, design the template in Word ahead of time, marking the positions where dynamic content should be inserted using the `{{placeholderKey}}` format, for example `{{CustomerName}}` or `{{ContractAmount}}`.

### Dragging the Module and Basic Configuration

Drag the module: In the component library on the left side of the workflow canvas, find the "Document Output" module and drag it to the desired position on the canvas.
Name the module: Rename the module, for example "Generate Quote," for easier understanding of the workflow.
Set the activation condition: Based on your business logic, configure "activate when all conditions met" or "activate when any condition met" to determine under what conditions the module begins execution.

### Mode 1: Direct Output (No Template)

Use case: You need to quickly assemble one or more pieces of text content into a Word document, without strict formatting requirements.
Steps:
In the module's configuration drawer, make sure the "Add Custom Information Input" section is not used, and don't upload any template.
Connect the output node (such as "Reply Content") of an upstream module (such as "Intelligent Chat" or "Information Processing") to the Document Output module's "Information Input" node.
When the workflow reaches this module during execution, all upstream output content will be merged and used to generate a blank Word document for download.

### Mode 2: Template Replacement (With Template)

Use case: You need to generate a standard document with a fixed format but dynamically varying content, such as a contract, report, or notice.
Steps:
Upload the template: In the module's configuration drawer, find the "Upload Template" section, and upload your pre-prepared Word document containing placeholders.
Add custom information inputs: After uploading the template, the system will prompt you to add custom information inputs.
Click "Add Custom Information Input."
In the configuration item that appears, the Key must exactly match the name of a placeholder in the template (e.g., `CustomerName`), and the Name can be a more descriptive label (e.g., "Customer Name Field").
Connect the output node from the upstream module that corresponds to this Key to this custom information input node.
Repeat this step for every placeholder in the template, adding a corresponding custom information input for each.
Run and download: When the workflow runs, the system fills all upstream variable values into their corresponding positions in the template, and generates the final Word document for the user to download.

### Testing and Publishing

Single-node debugging: Independently debug the Document Output module on the canvas, verifying the output result without running the entire workflow, significantly improving development efficiency.
Full workflow testing: Run the entire workflow, simulating user input or trigger conditions, to check whether the generated Word document meets expectations.
Publish the Agent: Once testing confirms everything works correctly, publish the Agent so the document output feature can be used in real business scenarios.

### FAQ and Notes

Template format support: Uploaded Word templates support basic fonts, font sizes, and paragraph formatting. The system will do its best to replicate the template's styling, but overly complex layouts (such as deeply nested tables or special font effects) may not be fully preserved.
Placeholder format: Placeholders in the template must use the `{{placeholderKey}}` format, and the Key name must exactly match the Key in the configured "Custom Information Input" — otherwise the replacement will fail.
Upstream variable type: Values passed in from upstream should be of text type. If the upstream data is a JSON structure, it may need to be parsed and concatenated first via an "Information Processing" module or a "Code Block" module.
File download: Once the document is generated, a download link is provided in the user's chat interface. Note that generating large documents may take a few seconds.
Module execution complete: After the Document Output module finishes running, it outputs "True," which can be used to trigger subsequent processes, such as sending the document to a specified email address or storing it in the knowledge base.
