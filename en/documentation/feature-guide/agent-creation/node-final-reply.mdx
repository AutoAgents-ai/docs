### Module Introduction

When you need to reply to the user with specific content, you can use the Confirm Reply module. When the trigger condition is met, the user will receive exactly the content configured in the "Reply Content" text box. If the Reply Content node is connected to an external information source, the linked information will override the content configured in the "Reply Content" input box.

### Built-in System Variables

Syntax
`{{var}}` references a variable
`{{cTime}}` current time, yyyy-MM-dd HH:mm:ss
`{{cMills}}` current timestamp
`{{cWeekdayNum}}` day of week - number
`{{cWeekdayEn}}` day of week - English
`{{cWeekdayEn2}}` day of week - English abbreviation
`{{cWeekdayCn}}` day of week - Chinese

### Built-in System Functions

Note: The most commonly used function is for extracting JSON data, followed by regular expressions.
Extracting JSON data:
Extraction for dictionaries and arrays works the same way, for example: `[@["ExtractJsonArr","{{list}}", "$.0.baseUrl"]@]`
The only difference is: when the outermost structure is `[]` (an array), use the `ExtractJsonArr` function;
when the outermost structure is `{}` (a dictionary), use the `ExtractJsonObj` function.
