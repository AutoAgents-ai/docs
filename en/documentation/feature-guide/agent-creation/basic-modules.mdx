End Agent Chat

### Module Introduction

This module is used in multi-Agent collaboration scenarios. Only after this module is added to an Agent's orchestration will that Agent appear under "Agents" on the left side of the "Planning" canvas, allowing it to be dragged into another Agent's canvas to enable collaboration between multiple Agents.
Memory variables are temporary variables stored within the current scenario. When an Agent appears as a node in another Agent's orchestration, its memory variables represent that Agent's output parameters, enabling cross-Agent referencing.
