title: "New Node Types"
---

◦ Agent node: Enables an Agent to automatically decompose tasks based on a goal, plan execution steps, dynamically schedule resources such as MCP tools, knowledge bases, and skills, and monitor execution status in real time for exception retries and strategy adjustments — enabling fully autonomous, closed-loop handling of complex problems.

◦ Document Review node: Enables a workflow to automatically trigger review tasks based on business processes, configure multi-level review flows, flexibly assign reviewers and permissions, and synchronize review progress and comments in real time. It automatically triggers routing rules and notifications for rejections, timeouts, or abnormal submissions, enabling end-to-end closed-loop management of documents from submission and review to revision and archiving.
