### Module Introduction

Compared with a typical model-plus-prompt Agent, the Agent node integrates a knowledge base, tools (MCP), and skills, giving it much more comprehensive capabilities.
The Agent node serves both as the entry point for connecting an Agent to a variety of expert skills, and as a key building block for the platform's multi-Agent collaboration capabilities.

### Use Cases

Any functionality that requires MCP or skills can be implemented via the Agent node.
Specifically,
MCP allows the model to acquire complex tool capabilities, such as web search and browser operations,
while skills allow the model to master specialized SOPs (standard operating procedures).
