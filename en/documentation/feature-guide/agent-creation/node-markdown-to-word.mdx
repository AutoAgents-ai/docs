### Feature Overview

The Markdown to Word module is a tool component for converting Markdown-formatted text content into a Microsoft Word (.docx) file. It intelligently parses Markdown syntax (such as headings, lists, tables, code blocks, and image links) and maps each element to the corresponding style or object in the Word document, producing a well-formatted Word document that can be edited and distributed directly.

### Feature Entry Point

Go to the Agent Planning page, then Modules -> Advanced Capabilities -> Markdown to Word.
