### Feature Introduction

The scheduled trigger lets you configure scheduled tasks that automatically trigger an Agent to run a workflow at a preset time. It supports several time-based trigger modes, tasks can be created from multiple entry points, task information can be viewed in the management interface and quickly identified via icons, and the configuration is application-level, so it remains active even after closing the tab.

### Feature Entry Point

Go to the Agent's basic configuration page and find the "Scheduled Trigger" option.
Click "Create Trigger" and enter a name for the trigger.
Set the trigger time — you can choose modes such as daily or weekly triggers.
Configure the trigger input content, i.e. the instruction the Agent should execute when triggered.
Click "Confirm" to finish creating the trigger.

### Configuration

On the Agent's basic configuration page, you can set up a scheduled trigger, including its name, trigger time, and trigger input. The trigger time supports multiple modes, including a specific time, daily, and weekly triggers.
