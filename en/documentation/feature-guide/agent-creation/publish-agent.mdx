### HTTP Application

Creating and managing HTTP application links:
Creating a link:
Click the "Create Link" button in the top-right corner
Required fields: link name, validity period
Default usage mode: "Top up and use on your own"
Optional: enable/disable a link password

<Frame>
  <img src="/images/documentation/ch6_6.1.1.2_0003.png" alt="Publishing an Agent" />
</Frame>

Link actions:
Once created, you can: open, copy, or embed the link in a web page
Click the "···" button next to the link to delete or edit it

### API Service

API Service page information and actions:
Available information:
Uuid: The unique identifier for the Agent's API, used to identify and distinguish between different API instances.
AuthKey: The key used to verify API call permissions, ensuring that only authorized users can access the API.
AuthSecret: An additional security key used to further protect API calls, typically used together with AuthKey to enhance security.
Created at: The time the API was created.
User actions:
For the API information, you can: copy, refresh, or delete.
For detailed API usage instructions, refer to AgentsOpenApi-v1.5.
