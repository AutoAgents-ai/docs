title: "Add Memory Variable"
---

### Feature Overview

Stores temporary variables within the workflow, helping to overcome the context length limit of the Intelligent Dialogue module (up to 6 turns). By appending conversation content to a memory variable, you can extend context continuity across long conversations and pass data across Agents.

### Feature Entry Point

The Add Memory Variable module can be found in the module panel.

<Frame>
  <img src="/images/documentation/ch6_6.1.33.2_0095.png" alt="Add Memory Variable" />
</Frame>

### Interface Walkthrough

Click the Add Memory Variable module to open the configuration screen, then click the Add button to add a memory variable.

<Frame>
  <img src="/images/documentation/ch6_6.1.33.3_0096.png" alt="Add Memory Variable" />
</Frame>

Fill in the data type, field key, and field description as prompted, then click Add to successfully create an Add Memory Variable module.

<Frame>
  <img src="/images/documentation/ch6_6.1.33.3_0097.png" alt="Add Memory Variable" />
</Frame>

### Field Key

The field key is the unique, non-repeatable identifier for this field within the system — essentially an "internal system name" for the field, used to precisely locate it in code, databases, and interfaces. It is separate from the "field name" shown to users.
