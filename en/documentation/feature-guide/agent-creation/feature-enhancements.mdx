---
title: "Feature Enhancements"
---

◦ Single-node debugging: Supports independently debugging a single node on the canvas, allowing you to verify a node's logic and output without running the entire workflow, significantly improving development and debugging efficiency.

◦ External environment support for Code node: The Code node now supports an external execution environment, enabling it to call external system resources and dependency libraries, expanding the boundaries of code-based processing.
◦ Variable reference hints: When referencing variables during orchestration, the system automatically provides a list of available variables along with format hints, reducing workflow errors caused by variable name typos.
◦ Natural language workflow generation: Automatically generates workflow nodes based on a user's natural language description, and completes basic connections and execution order, allowing you to quickly build a workflow skeleton without manual dragging and dropping.
◦ Workflow tuning: Supports adjusting and optimizing auto-generated workflows via either natural language instructions or manual drag-and-drop, balancing efficiency and flexibility.
◦ Intelligent tool orchestration: Automatically selects the appropriate tool based on task semantics and completes binding with the Agent or workflow, enabling intelligent matching of tool invocations.
◦ Automatic data source association: Automatically associates knowledge bases or data sources during generation, enhancing the Agent's execution capabilities and scope of information access.
