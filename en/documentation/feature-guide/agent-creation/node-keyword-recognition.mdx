### Feature Overview

Once the Keyword Recognition module is added, the system automatically performs recognition and verification against specified keywords. You can configure multiple independent recognition groups here to enable multi-dimensional keyword review and control. Based on the different match results, the system automatically returns differentiated reply content, precisely adapting to a variety of review scenarios and business needs.

### Feature Entry Point

After logging into the platform, you can find the Keyword Recognition module in the module panel.

<Frame>
  <img src="/images/documentation/ch6_6.1.20.2_0060.png" alt="Keyword Recognition" />
</Frame>

Click the Keyword module to enter the configuration page, then click "Add Recognition Group" to create a new keyword recognition group.

<Frame>
  <img src="/images/documentation/ch6_6.1.20.2_0061.png" alt="Keyword Recognition" />
</Frame>

After entering the sensitive words to be recognized, the module scans the document for them. If a sensitive word is found, the output follows the description configured for "when matched"; if no sensitive word is found, the output follows the description configured for "when not matched."
