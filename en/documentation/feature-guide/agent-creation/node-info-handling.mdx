### Module Overview

Uses regular expressions to apply rule-based processing to strings, converting the format from input parameters to output parameters. Suitable for scenarios such as data cleansing, field concatenation, and format standardization. Only string-type input and output are supported.

### Input Field Key

The field key is the unique identifier for this field within the system, interface, or data structure — it is the core reference used to locate and retrieve the corresponding field value.

### Input Field Description

The field description provides detailed information about the field's function, meaning, value range, use cases, and constraints — it is the core reference for understanding the purpose of the field.

### Conversion Rule
