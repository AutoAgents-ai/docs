---
title: "Toolbox"
---

The Toolbox is used to build up reusable capability components that agents or workflows can call on. Combined with the Workflow 2.0 materials, the platform supports intelligent tool orchestration, calls to external execution environments, and capability reuse. When onboarding customers, it's worth paying particular attention to how tools are created, how invocation logic works, their scope of applicability, and permission controls.
