### Contract Review

### Feature Overview

The Contract Review tool supports document upload and the entry of review rules to perform compliance checks on contract content, improving review efficiency, ensuring consistency, and reducing risk.

### Entry Point

Click the "Toolbox" module in the left navigation bar of the Agents platform to enter the tool management page.
In the "Official Tools" section of the Toolbox page, find and click the "Contract Review" feature card to enter the Contract Review tool's operating page, which includes the home page, rule entry, audit records, project management, and other related features. The card includes a dedicated icon, feature name, and feature description.

### Home Page

Document Review

### Interface Description

<Frame>
  <img src="/images/documentation/ch6_6.7.1.5_0173.png" alt="Official Tools: Contract Review" />
</Frame>

Feature navigation area: contains two feature modules, "Document Review" and "Document Comparison," used respectively for in-depth review of a single document and comparative analysis of multiple documents.
Project management area: located below the feature navigation area, includes a project selection dropdown, a "New Project" button, and a document type selection dropdown, supporting management of review tasks by project and document type.
File upload area: the dashed box in the central area is the file upload zone, supporting click-to-upload or drag-and-drop, and displays the supported file formats (PDF, DOC, DOCX) and size limit (30 MB).
Parameter configuration area: located below the upload area, includes a review model selection dropdown and a decision-tree model parameter input field, supporting customization of the review model and its parameters.
Execute button: the "Start" button at the bottom of the page, used to submit the review task.

<Frame>
  <img src="/images/documentation/ch6_6.7.1.5_0174.png" alt="Official Tools: Contract Review" />
</Frame>

Document content display area: on the left side of the review results page, displays the detailed content of the uploaded contract as a PDF preview, including information about the contracting parties, addresses, contact details, and so on.
Dialogue window: on the right side of the review results page, displays the content review assistant's list of questions and corresponding review conclusions, with each question including a sequence number and a detailed review answer.
Re-review button: the "Re-review" button in the top-right corner of the dialogue window, used to resubmit the current document for review.

### Operating Instructions

Step 1: Select a project. Select the target project from the project selection dropdown, or click "New Project" to create a new one.
Step 2: Upload a file. Click the file upload area or drag and drop a file into it, selecting the contract file to be reviewed (PDF, DOC, and DOCX formats supported, up to 30 MB).
Step 3: Configure parameters. In the parameter configuration area, select the appropriate review model and set the decision-tree model parameters.
Step 4: Start the review. Click the "Start" button to submit the review task.
Step 5: View the results. Once the review is complete, view the contract document content on the left and the content review assistant's conclusions and detailed answers on the right.
Step 6: Re-review (optional). If a re-review is needed, click the "Re-review" button in the top-right corner of the dialogue window.
Document Comparison

### Rule Entry

Used to manage contract review rules, supporting rule grouping, creation, editing, and deletion. Rules can be categorized by tag and searched by keyword, allowing flexible configuration of review standards.

### Interface Description

<Frame>
  <img src="/images/documentation/ch6_6.7.1.10_0181.png" alt="Official Tools: Contract Review" />
</Frame>

Rule group navigation area: on the left side of the page, displays all rule groups in a tree structure, supporting group selection and search, with the currently selected group highlighted.
Rule list display area: on the right side of the page, displays the rule list in a table, including tag, group, rule content, rule source, rule type, creation time, and an actions column.
Search and filter area: above the rule list, includes a search content field, a query date-range picker (start date, end date), and a search button, supporting rule lookup by keyword and time range.
Tag management area: below the search area, displays all available tags (All, No Tag, Multi-Document, Single Document, etc.), supporting filtering by tag, with "+ Add" and "Delete" tag buttons.
Add Rule button: the blue "+ Add Rule" button in the top-right corner of the page, used to open the rule entry dialog.
Add Rule dialog: a form with fields such as group, tag, rule type, rule content, and rule source, supporting the creation of new rules.
Edit Rule dialog: structurally similar to the Add Rule dialog, but pre-filled with the existing rule's data, supporting modification of rule information.
Add Tag feature: click the "+ Add" button in the tag bar to enter a new tag name and create a tag.

### Operating Instructions

Step 1: Select a rule group. Select the target group in the rule group navigation area on the left; the list on the right will show all rules under that group.

<Frame>
  <img src="/images/documentation/ch6_6.7.1.11_0182.png" alt="Official Tools: Contract Review" />
</Frame>

Step 2: Add a rule. Click the "+ Add Rule" button in the top-right corner, select the group, tag, and rule type in the dialog, enter the rule content, select the rule source, and click "Confirm."

<Frame>
  <img src="/images/documentation/ch6_6.7.1.11_0183.png" alt="Official Tools: Contract Review" />
</Frame>

Step 3: Edit a rule. Click "Edit" in the "Actions" column of the rule list, modify the relevant information in the Edit Rule dialog, and click "Confirm."

<Frame>
  <img src="/images/documentation/ch6_6.7.1.11_0184.png" alt="Official Tools: Contract Review" />
</Frame>

Step 4: Delete a rule. Click "Delete" in the "Actions" column of the rule list, and confirm to delete the rule.
Step 5: Add a tag. Click the "+ Add" button in the tag bar, enter a new tag name, and press Enter to create the tag.

<Frame>
  <img src="/images/documentation/ch6_6.7.1.11_0185.png" alt="Official Tools: Contract Review" />
</Frame>

Step 6: Search for rules. Enter a keyword in the search content field, or select a query date range, then click "Search" to look up rules.

<Frame>
  <img src="/images/documentation/ch6_6.7.1.11_0186.png" alt="Official Tools: Contract Review" />
</Frame>

Step 7: Filter by tag. Click any tag in the tag bar; the rule list will filter to show only rules with that tag.

### Audit Records

Records the execution history of all review tasks, supporting the viewing of review details and retrieval of audit reports. Records can be filtered by criteria and browsed page by page, making the review process easy to trace.

### Interface Description

<Frame>
  <img src="/images/documentation/ch6_6.7.1.13_0187.png" alt="Official Tools: Contract Review" />
</Frame>

\- Audit records list area: displays all review records in a table, including executor, file executed, rule content, review type, review result, status, execution time, and an actions column.
\- Review type indicator: uses differently colored tags to distinguish "Document Review" (orange) from "Document Comparison" (blue).
\- Review result indicator: uses differently colored dots and numbers to indicate the review result, such as "Failed (5/40)," meaning 5 out of 40 issues failed.
\- Status indicator: uses differently colored text to distinguish review statuses, such as "Success" (green) and "Failed" (red).
\- Actions column: includes "View Details" and "Get Report" buttons, used to view review details and generate a review report.
\- Pagination controls: page navigation at the bottom of the page, supporting jumps to a specific page and showing the total number of records.
\- Review detail page: the left side shows a PDF preview of the contract document, and the right side shows the dialogue window with the content review assistant's list of questions and corresponding detailed answers.
\- Get Report dialog: appears when clicking the "Get Report" button, includes a report name field and "Confirm"/"Cancel" buttons.
\- Report results: displays the review report in a table with three columns—Question (A), Answer (B), and Source (C)—recording the answer and basis for each review question in detail.

### Operating Instructions

\- Step 1: View the audit records list. Enter the audit records page to view an overview of all review records.
\- Step 2: View review details. Click "View Details" in the actions column to enter the review detail page, viewing the contract document content on the left and the content review assistant's questions and answers on the right.

<Frame>
  <img src="/images/documentation/ch6_6.7.1.14_0188.png" alt="Official Tools: Contract Review" />
</Frame>

\- Step 3: Get the review report. Click "Get Report" in the actions column, confirm or modify the report name in the popup, and click "Confirm" to generate the report.

<Frame>
  <img src="/images/documentation/ch6_6.7.1.14_0189.png" alt="Official Tools: Contract Review" />
</Frame>

\- Step 4: View the report results. After the report is generated, view the full review report in a table, including the detailed answer and source for each question.
\- Step 5: Browse pages. Use the pagination controls at the bottom to switch between pages and view more review records.

<Frame>
  <img src="/images/documentation/ch6_6.7.1.14_0190.png" alt="Official Tools: Contract Review" />
</Frame>

### Project Management

Manages contract review projects and types, supporting the creation, editing, and deletion of projects. Project types and stages can be defined, enabling classified organization and management of review tasks.

### Interface Description

<Frame>
  <img src="/images/documentation/ch6_6.7.1.16_0191.png" alt="Official Tools: Contract Review" />
</Frame>

\- Project list area: displays all projects in a table, including project name, project type, creation time, and an actions column.
\- Project expand icon: the expand arrow before each project name, used to view sub-projects or details under the project.
\- Actions column: includes "Edit" and "Delete" buttons, used to modify or delete a project.
\- New Project button: the blue "+ New Project" button in the top-right corner of the page, used to open the New Project dialog.
\- View Project Types button: the "View Project Types" button in the top-right corner of the page, used to enter the project type management page.
\- New Project dialog: includes a project name field (required), a project type selection dropdown (required), a project stage selection dropdown (required), and "Confirm" and "Cancel" buttons.
\- Edit Project dialog: structurally similar to the New Project dialog, but pre-filled with the current project's information, supporting modification of the project name, type, and stage.
\- Delete Project confirmation dialog: shows a confirmation prompt "Are you sure you want to delete this record?" with "Confirm" and "Cancel" buttons.

<Frame>
  <img src="/images/documentation/ch6_6.7.1.16_0192.png" alt="Official Tools: Contract Review" />
</Frame>

\- Project type management page: displays all project types in a table, including the project type name and multiple project stage columns (Project Stage 1 through Project Stage 8), plus an actions column.
\- Add Project Type button: the blue "+ Add Project Type" button in the top-right corner of the project type management page.
\- Add Project Type dialog: a form for creating a new project type, including a project type name field and multiple project stage fields.
\- Edit Project Type dialog: a form for modifying an existing project type, pre-filled with the current project type's information.
\- Delete Project Type confirmation dialog: a confirmation prompt for deleting a project type.
\- Pagination controls: page navigation at the bottom of the project list and project type management pages, supporting jumps to a specific page.
