---
title: "Try an Agent"
---

Select and click a published Agent in the "Agent Marketplace" to start using it and enter the Agent's chat page:
Enter your question in the input box at the bottom, or click a quick question, to start a conversation with the Agent;
Use the left-hand sidebar to switch between recently used Agents;
Use the left-hand menu to view conversation history or start a new conversation.
