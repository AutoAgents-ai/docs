---
title: "My Agents Entry"
---

"My Agents" in the left-hand navigation menu of the Agents Platform contains two lists: "Created by Me" and "Shared with Me." Agents can be in one of two states: "Published" or "Unpublished." Published Agents can be found and used directly in the Agent Marketplace. Unpublished Agents can only be viewed and modified by their creator and authorized users.

<Frame>
  <img src="/images/documentation/ch6_6.2.2_0127.png" alt="My Agents" />
</Frame>

From "My Agents," you can click an Agent to open its configuration page and view the sample Agent's configuration details to learn how it was built.
Use the top menu to switch between viewing basic information "Configuration" and "Planning" orchestration;
Use "Publish" in the top-right corner to publish the Agent to the Agent Marketplace so it can be used.
