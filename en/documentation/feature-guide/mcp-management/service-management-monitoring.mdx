### Feature Overview

Provides a centralized view of all connected services, including an overview and tool details, making it easy to monitor and manage service status in one place.

### Entry Point

Log in to the Agents platform and click the "MCP Management" page.

<Frame>
  <img src="/images/documentation/ch6_6.8.2.2_0235.png" alt="Service Management and Monitoring" />
</Frame>

Click any MCP tool.

### Interface Description

### Service Management and Monitoring Interface

MCP overview: view the MCP tool's service name, description, installation method, and MCP service configuration.
MCP tool: view all methods of the MCP tool and their corresponding input parameters.
