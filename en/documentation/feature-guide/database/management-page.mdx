### Interface Description

Tab switching
"Created by Me" tab: Selected by default, showing all database connections created by the current user.
"Shared with Me" tab: Click to switch, showing database connections that other users have shared with the current user.
Database connection list
All database connection assets are displayed as cards, containing the following core information:
Database type identifier (icon + type name, such as MySQL)
Database connection name
Creator information
Connection description (shown on some cards)
"Connect Database" creation card: Located at the front of the list, marked with a "+" icon, used to create a new database connection.
Database card edit, delete, and permission assignment buttons
Hovering over a database card reveals the "..." button, which opens the edit, delete, and permission assignment buttons
