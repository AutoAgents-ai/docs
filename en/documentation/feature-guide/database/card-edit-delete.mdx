The structure of the edit dialog is the same as the "Connect Database" dialog described above, so the operating steps follow the same flow as connection management. The following section focuses on the delete confirmation dialog.

### Interface Description

On the database list page, click the "···" more button in the upper-right corner of the target database card, then click "Delete" in the menu that appears to open the "Reminder" confirmation dialog.

<Frame>
  <img src="/images/documentation/ch6_6.6.5.1_0167.png" alt="Editing and Deleting Database Cards" />
</Frame>

Dialog structure:
Title: "Reminder," clearly indicating the risk of the action.
Risk warning: "This action will permanently delete the data. Continue?" — warning users that deletion cannot be undone.
Action buttons: The "Cancel" button aborts the deletion; the "Confirm" button confirms and executes the deletion, showing a success message once it completes.
Close button: The "×" in the upper-right corner of the dialog closes the dialog and cancels the deletion.

### Operating Procedure

Step 1: Trigger deletion. Click the "···" more button in the upper-right corner of the target database card, then click "Delete" in the dropdown menu to open the delete confirmation dialog.
Step 2: Confirm deletion. Carefully read the risk warning, and after confirming you want to delete the database connection, click "Confirm." The system will permanently delete the database connection and its related configuration, and the card will be removed from the list page accordingly.
Step 3: Cancel deletion (optional). If triggered by mistake, click "Cancel" or the "×" in the upper-right corner to close the dialog and abort the deletion; the database connection remains unchanged.
