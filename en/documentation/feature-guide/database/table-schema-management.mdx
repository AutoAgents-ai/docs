### Table Basic Information Area

Table name and description: Shows the name of the currently selected table, "XX Chapter." "No description yet" is shown by default.
Custom table description input box: Supports entering a custom description for the data table.
Field search box: Supports fuzzy search of the current table's fields by field name or comment.
Field information management table
The table contains 5 core columns for managing data table fields:
Field name: Shows the native database field name (such as chapter_content, chapter_number, etc.); not editable.
Field comment: Shows the native database field comment; displays "-" when there is no comment.
Custom comment: Editable; click "Click to edit..." to enter a custom field description.
Field type: Shows the field's database data type (such as text, int, varchar(255), etc.); not editable.
Enabled: A toggle control; a blue "on" state indicates the field is available for use.
