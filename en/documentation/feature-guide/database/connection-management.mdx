On the database management page, click the "Connect Database" card under the "Created by Me" tab to access the database connection management page.

### Interface Description

Dialog title and close button
"Connect Database" dialog title: Located at the top of the dialog, clearly indicating that its core function is to create a new database connection configuration.
Close button: Located in the upper-right corner of the dialog; clicking it closes the database connection configuration dialog and returns to the previous page.
Database type selection area
Radio button group: Provides multiple database type options, including MySQL, OceanBase, PostgreSQL, SQL Server, Impala, Oracle, and Da Meng, supporting single selection of the target database type.
Type icon and name: Each database type is accompanied by a dedicated icon for quick visual identification.
Configuration input area
Connection name: Required (marked with a red asterisk *), used to enter a custom name for the database connection.
Connection description: Optional, used to add supplementary information about the purpose or use case of the connection.
Host: Required (marked with a red asterisk *), enter the host address of the database service.
Port: Required (marked with a red asterisk *), enter the port number of the database service.
Database name: Required (marked with a red asterisk *), enter the name of the specific database to connect to.
Username: Required (marked with a red asterisk *), enter the account username used to access the database.
Password: Optional, enter the account password used to access the database.
Action button area
Cancel button: Located at the bottom-left of the dialog; clicking it discards the current database connection configuration, closing the dialog and returning to the original page.
Confirm button: Located at the bottom-right of the dialog; clicking it submits the entered database connection configuration and completes the creation of the new database connection.

### Operating Procedure

Select the database type
Step 1: Determine the type. In the "Database Type" radio button group, click the radio button corresponding to the target database type (such as MySQL, PostgreSQL, etc.) to complete the database type selection.
Fill in the database connection configuration
Step 1: Fill in the required fields. In sequence, fill in the required information in the "Connection Name," "Host," "Port," "Database Name," and "Username" fields.
Step 2: Add optional fields (optional). Fill in a description in the "Connection Description" field, and enter the database account password in the "Password" field.
Complete the database connection configuration
Step 1: Submit the configuration. After confirming all configuration items are filled in correctly, click the "Confirm" button at the bottom of the dialog. The system will validate the configuration and complete the creation of the database connection.
Step 2: Cancel the configuration. If you no longer need to create the connection or need to modify the configuration, click the "Cancel" button to close the dialog and discard the current configuration.
Close the dialog
Step: Click the close icon in the upper-right corner of the dialog to close the "Connect Database" dialog directly and return to the database list page.
