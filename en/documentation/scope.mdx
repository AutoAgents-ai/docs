### Intended Audience

This manual applies to platform administrators, business configuration staff, application builders, and general users of the Agents Platform within a customer organization. Different roles complete resource management, capability building, application publishing, and daily usage tasks according to their authorization scope.

| Dimension | Description |
| --- | --- |
| Organizational scope | Headquarters departments, branch offices, project teams, special task forces |
| Business scenarios | Knowledge Q&A, process assistance, intelligent assistants, application packaging, results presentation, etc. |
| Usage goals | Rapid building, continuous optimization, unified governance, improved collaboration efficiency |
| Readership | Customer management staff, builders, and end users |

### Applicable Scenarios

The Agents Platform is suited for scenarios such as knowledge Q&A, process collaboration, business form filling, data queries, application showcasing, operations support, and results publishing — especially for business units that want to complete digital capability building and continuous iteration with a lower barrier to entry and a faster cycle.

### Scope Boundaries

This manual mainly describes the business usage and configuration methods of the platform. It does not replace infrastructure deployment guides, network and security policy documentation, or middleware-specific operations documentation. For content involving deployment, resource requests, port provisioning, database high availability, and disaster recovery, refer to the *Agents Platform Deployment Plan – V2.0* as well.
