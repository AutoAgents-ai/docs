### Platform Positioning

The Agents Platform is positioned as an intelligent building platform for enterprise-oriented, intelligent business development, emphasizing that "business can participate, capabilities can be configured, resources can be governed, and results can be published." The platform supports organically combining Agents, Workflows, knowledge sources, tool capabilities, and page applications, helping business units quickly form runnable, iterable digital applications.

### Core Capability Composition

| Capability Domain | Key Capabilities | Typical Use |
| --- | --- | --- |
| Agent building | Model configuration, workflow orchestration, knowledge enhancement, permission control | Building Q&A assistants, business assistants, process-handling assistants |
| Application packaging | Page generation, component orchestration, visual preview, publishing and access | Packaging intelligent capabilities into business applications ready for direct use |
| Capability reuse | Skill management, tool invocation, MCP resource integration | Accumulating reusable capability assets to support complex-scenario invocation |
| Governance and operations | Organization/user management, role permissions, log auditing, usage statistics | Ensuring the platform runs in a compliant and controlled manner |
| Operations analytics | Data dashboards, invocation details, activity statistics, feedback analysis | Tracking platform usage effectiveness to support continuous optimization |

### Typical Build Path

The typical build path generally follows the process of "basic preparation, capability building, application publishing, business usage, and continuous optimization." The platform first completes basic configuration such as models, organizations, roles, and permissions, then builds Agents or Workflows around business goals, subsequently enhances capabilities through knowledge, tools, and skills, and finally packages the result into a business application delivered through "My Apps."
