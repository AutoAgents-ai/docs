The "Word Document Generation" component is built on the [poi-tl](https://deepoove.com/poi-tl/) template engine, and supports rendering formal Word documents from a Word template combined with JSON data.

## Syntax Reference

poi-tl supports a rich set of template tag syntax, including text replacement, looping tables/paragraphs, image insertion, and conditional rendering. See the official documentation for the complete syntax reference:
