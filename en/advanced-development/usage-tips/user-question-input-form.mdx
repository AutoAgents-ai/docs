---
title: "User Question - Input Form"
---

The "User Question" module supports configuring an input form, letting users submit information via a structured form rather than free-text input alone.

## Referencing Form Data

- `{{yourFormCode}}`: References the form variable input by the user (the key-value data submitted by the form)
- `{{yourFormCode_schema}}`: References the form structure (field definitions, display configuration, etc.)

<Info>
For the field types, display configuration, and submitted data structure of the form, see the `formData` field example in the request body description of the [Agent Chat Streaming API](/en/api-reference/chat-stream).
</Info>
