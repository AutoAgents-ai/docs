---
title: "Agent Chat Non-Streaming (Async) Result Polling API"
---

Used together with the [Agent Chat Non-Streaming API (Async)](/en/api-reference/chat-async) to poll for the asynchronous execution result using `requestId`.

## Request URL

```
{{host}}/openapi/agents/chat/completions/async/polling/v1?agentId={}&requestId={}
```

or

```
{{host}}/openapi/v2/chat/completions/async/polling?agentId={}&requestId={}
```

## Request Method

`GET`

## Request Headers

Refer to the [API Specification](/en/api-reference/overview); supports ✅ Agent Token, ✅ personal credentials.

## Request Parameters

| Parameter | Required | Description |
| --- | --- | --- |
| `agentId` | Yes | Agent ID |
| `requestId` | Yes | Request ID (the `data.requestId` returned by the [async API](/en/api-reference/chat-async)) |

Request example:

```
agentId=4328bb87fdd145e2a25ec53bsada27c95
requestId=2498bb87fdd145e2a25ec53b50b27c95
```

## cURL Example

Replace `{{host}}` with your actual environment address, and `{authKey}`/`{authSecret}` with your credentials (see [API Specification](/en/api-reference/overview)):

```bash
curl -X GET "{{host}}/openapi/agents/chat/completions/async/polling/v1" \
  -H "Authorization: Bearer {authKey}.{authSecret}" \
  -G \
  --data-urlencode "agentId=4328bb87fdd145e2a25ec53bsada27c95" \
  --data-urlencode "requestId=2498bb87fdd145e2a25ec53b50b27c95"
```

## Response Body

| Field | Description |
| --- | --- |
| `code` | Response result code; `1` indicates success, other values indicate failure |
| `msg` | Error message |
| `data.requestId` | Request ID in the background logs; use this ID to locate related logs when troubleshooting |
| `data.output` | Has the same structure as the response body of the [Agent Chat Non-Streaming API (Sync)](/en/api-reference/chat-sync); only has a value when the status is `DONE` |
| `data.state` | Asynchronous task execution status: `0` `1` `2` `3` |

```sql
NOT_EXIST(0, "Does not exist"),
RUNNING(1, "Running"),
DONE(2, "Finished"),
EXCEPTION(3, "Exception occurred")
```
