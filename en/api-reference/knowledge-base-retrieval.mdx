---
title: "Knowledge Base Retrieval"
---

## Request URL

```
{{host}}/openapi/kb/search
```

## Request Method

`POST`

## Request Headers

Refer to the [API Specification](/en/api-reference/overview); supports ❌ Agent Token, ✅ personal API key.

## Request Body Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `kbId` | number | Yes | Knowledge base ID (example value: `123`) |
| `keywords` | string | No | Keywords (example value: `"smart search"`) |
| `vectorSimilarLimit` | number | No | Vector similarity threshold / hybrid similarity (default: `0.15`, example value: `0.2`) |
| `vectorSimilarWeight` | number | No | Vector similarity weight (default: `0.72`, example value: `0.8`) |
| `topK` | number | No | Number of results to retrieve (default: `20`, example value: `30`) |
| `enableRerank` | boolean | No | Reranking switch, `true`/`false`, default: `false` |
| `expandChunks` | boolean | No | Expand context chunks; when enabled, the chunk immediately before and after the matched chunk is also retrieved to improve content completeness, default: `false` |
| `expandNum` | number | No | Number of expanded context chunks (default: `1`, example value: `2`) |
| `rerankModelType` | string | No | Reranking model type (example value: `"bge-reranker-large"`) |
| `rerankSimilarLimit` | number | No | Reranking threshold (default: `0`, example value: `0.5`) |
| `rerankTopK` | number | No | Number of results to retrieve after reranking (default: `10`, example value: `5`) |

<Info>
Fields such as `vectorSimilarWeight`, `enableRerank`, `rerankModelType`, `rerankSimilarLimit`, and `rerankTopK`, which relate to reranking/similarity, have the same meaning as the corresponding fields in [Knowledge Base Advanced Topics - Advanced Query Example](/en/advanced-development/usage-tips/knowledge-base-advanced-query).
</Info>

```json
{
    "vectorSimilarLimit": 0.15,
    "vectorSimilarWeight": 0.72,

    "enableRerank": false,
    "expandChunks": false,

    "rerankSimilarLimit": 0,
    "rerankTopK": 10,
    "keywords": "test",
    "kbId": "1827"
}
```

## Response Body

| Field | Description |
| --- | --- |
| `code` | Response result code; `1` indicates success, any other value indicates failure |
| `msg` | Error message |
| `data[]` | Array of knowledge base retrieval results; see the table below for field descriptions |

### `data[]` Field Description

| Field | Description |
| --- | --- |
| `q` | Chunk content |
| `a` | Answer corresponding to the chunk (only populated for Q&A-type chunks) |
| `position` | Positional information of the chunk within the original document |
| `keywords` | Keywords of the chunk |
| `imgFileKey` | Key of the image file associated with the chunk |
| `layoutType` | Layout type, for example `figure` for an image |
| `userUploadImgFiles` | Image files uploaded by the user |
| `id` | Chunk ID |
| `kbId` | ID of the knowledge base this chunk belongs to |
| `dsId` | ID of the dataset this chunk belongs to |
| `dataId` | Data ID |
| `fileId` | File ID |
| `score` | Overall score |
| `dataKey` | Data key |
| `refNum` | Number of references |
| `dataNum` | Data number |
| `disabled` | Whether disabled |
| `dsInfo` | Information about the dataset this chunk belongs to; see the table below for field descriptions |
| `kbInfo` | Information about the knowledge base this chunk belongs to; see the table below for field descriptions |
| `approvalState` | Approval status |
| `approvalId` | Approval record ID |
| `operateCode` | Operation type code |
| `operateComment` | Operation remarks |
| `approvalComment` | Review comments |
| `approvalParams` | Approval parameters |
| `fusionScore` | Fusion score (an overall score combining the vector score and keyword score) |
| `vectorScore` | Vector similarity score |
| `keywordScore` | Keyword match score |

### `dsInfo` Field Description

| Field | Description |
| --- | --- |
| `id` | Dataset ID |
| `state` | Status |
| `trainingState` | Training status |
| `kbId` | ID of the knowledge base this dataset belongs to |
| `parentId` | Parent ID |
| `fileId` | File ID |
| `name` | Dataset name |
| `extJson` | Extension information (JSON string), including parsing configuration such as language and parser type |
| `createAt` | Creation time |
| `type` | Type: `file` for a file, `folder` for a folder |
| `dataAmount` | Amount of data |
| `parserType` | Parser type |
| `taskStatus` | Task status |
| `progress` | Task progress |
| `taskId` | Task ID |
| `allowDownload` | Whether download is allowed: `1` allowed, `0` not allowed |
| `downloadUrl` | Download URL |
| `allowPreview` | Whether preview is allowed |
| `previewUrl` | Preview URL |
| `uuid` | Unique identifier |
| `approvalId` | Approval record ID |
| `approvalState` | Approval status |
| `approvalCode` | Approval status code |
| `operateCode` | Operation type code |
| `operatorUserName` | Name of the operator |
| `auditorUserNames` | List of reviewer names |
| `creatorUserName` | Name of the creator |
| `operateComment` | Operation remarks |
| `approvalComment` | Review comments |
| `referenceCount` | Number of references |

### `kbInfo` Field Description

| Field | Description |
| --- | --- |
| `id` | Knowledge base ID |
| `parentId` | Parent ID |
| `state` | Status |
| `dataAmount` | Amount of data |
| `name` | Knowledge base name |
| `description` | Knowledge base description |
| `avatarUrl` | Knowledge base avatar URL |
| `vectorModel` | Vector model |
| `type` | Type, for example `kb` |
| `tags` | Tags |
| `ext` | Knowledge base extension configuration; see the table below for field descriptions |
| `virtualDsId` | Virtual dataset ID |
| `dsNum` | Number of datasets |
| `authorName` | Name of the creator |
| `kbType` | Knowledge base type |
| `kbBtnPermission` | Button permissions |
| `approvalMode` | Approval mode |
| `approvalState` | Approval status |

### `kbInfo.ext` Field Description

| Field | Description |
| --- | --- |
| `configWay` | Configuration method, for example `auto` for automatic configuration |
| `chunkSize` | Chunk size |
| `coverageRate` | Coverage rate |
| `similarity` | Similarity threshold |
| `limit` | Limit on the number of results retrieved |
| `agentId` | ID of the associated Agent |
| `language` | Language, for example `Chinese` |
| `parserType` | Parser type |
| `contentEnhances` | Content enhancement options, for example `filename_enhance` for filename enhancement, `image_enhance` for image enhancement |
| `search` | Retrieval configuration |
| `parserModel` | Parsing model |
| `imageDescriptionModel` | Image description model |
| `allowDownloadForNewFile` | Whether new files are allowed to be downloaded |
