The Agents Platform Open API provides capabilities for chat conversations, Agent management, knowledge base and dataset management, file processing, and more, for integration by business systems. This page explains authentication methods, environment addresses, and versioning rules. For specific endpoints, see the directory on the left.

## Obtaining a Token

The platform provides two levels of call credentials. Choose based on your actual needs:

### Obtaining an Agent Token

Go to the Agent editing page and click the relevant button in the top-right corner to obtain a Token dedicated to that Agent.

<Warning>
This Token can only be used to call the chat-related endpoints of Open API for a specific Agent, and its permissions are limited to operating on data belonging to that user.
</Warning>

### Obtaining Personal Credentials

You can obtain personal credentials (authKey / authSecret) from the personal center.

<Warning>
This credential can be used to call all Open API endpoints, but its permissions are limited to operating on data belonging to that user, including the chat endpoints for all Agents under that user's account.
</Warning>

## Authentication Methods

There are three authentication methods: MD5, Bearer Token, and Token. The Token value can be either an Agent Token or personal credentials.

### MD5 Method (Recommended)

Pass the following parameters in the Header:

```http
authKey: your authKey
timestamp: millisecond timestamp; must not be more than 300 seconds from the current time
sign: MD5({authKey}{authSecret}{timestamp})  // the MD5 hash result, using 32-character lowercase
```

**MD5 calculation example:**

Assuming: `authKey=123`, `authSecret=456`, `timestamp=789`

Then: `sign=md5(123456789)`

### Bearer Token Method

Pass the following parameters in the Header:

```http
Authorization: Bearer {authKey}.{authSecret}
```

<Info>Note that there is a space after `Bearer`.</Info>

### Token Method

Pass the following parameters in the Header:

```http
token: {authKey}.{authSecret}
```

Or pass the parameter via URL query params:

```http
{{host}}/api/openapi/agent/chat/stream/v1?token={authKey}.{authSecret}
```
