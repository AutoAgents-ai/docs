---
title: "Get List of Available Models"
---

## Request URL

```
{{host}}/openapi/ai-models/v1/models
```

## Request Method

`GET`

## Request Headers

Refer to the [API Specification](/en/api-reference/overview); supports ❌ Agent Token, ✅ personal API key.

## Request Parameters

No input parameters, no query parameters, and no request body.

## cURL Example

Replace `{{host}}` with your actual environment address, and `{authKey}`/`{authSecret}` with your credentials (see [API Specification](/en/api-reference/overview)):

```bash
curl -X GET "{{host}}/openapi/ai-models/v1/models" \
  -H "Authorization: Bearer {authKey}.{authSecret}"
```

## Response Body

| Field | Description |
| --- | --- |
| `code` | Response result code; `1` indicates success, any other value indicates failure |
| `msg` | Error message |
| `data` | List of available models, an array; see the table below for the fields of each item |

Fields of each model object in `data`:

| Field | Description |
| --- | --- |
| `name` | Display name of the model |
| `model` | Model ID, used for the `model` parameter of the [LLM Chat Completion](/en/api-reference/llm-chat-completion) endpoint |
| `icon` | URL of the model icon |
| `modelVersion` | Model version number |
| `price` | Billing price of the model |
| `quoteMaxToken` | Maximum number of tokens for quoted content |
| `maxTemperature` | Maximum supported sampling temperature |
| `contextMaxToken` | Maximum number of tokens in the context window |
| `completionMaxToken` | Maximum number of tokens generated in a single reply |
| `maxPictureNumber` | Maximum number of images supported (multimodal input) |
| `maxVideoNumber` | Maximum number of videos supported (multimodal input) |
| `supportChat` | Whether chat is supported |
| `supportVision` | Whether vision (image understanding) is supported |
| `supportReasoning` | Whether reasoning/chain-of-thought is supported |
| `extraBody` | Additional request body parameters (varies by model; may be empty) |
