---
title: "Stop Reply Stream"
---

## Request URL

```
{{host}}/openapi/agents/chat/close?agentId={}&conversationId={}
```

or

```
{{host}}/openapi/v2/agents/chat/close?agentId={}&conversationId={}
```

## Request Method

`GET`

## Request Headers

Refer to the [API Specification](/en/api-reference/overview); supports ✅ Agent Token, ✅ personal API key.

## Request Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `agentId` | string | Yes | Agent ID |
| `conversationId` | string | Yes | Conversation ID, corresponding to the `conversationId` field in the chat interface response |

**Request example:**

```
agentId：4328bb87fdd145e2a25ec53bsada27c95
conversationId：2498bb87fdd145e2a25ec53b50b27c95
```

## cURL Example

Replace `{{host}}` with your actual environment address, and `{authKey}`/`{authSecret}` with your credentials (see [API Specification](/en/api-reference/overview)):

```bash
curl -X GET "{{host}}/openapi/agents/chat/close" \
  -H "Authorization: Bearer {authKey}.{authSecret}" \
  -G \
  --data-urlencode "agentId=4328bb87fdd145e2a25ec53bsada27c95" \
  --data-urlencode "conversationId=2498bb87fdd145e2a25ec53b50b27c95"
```

## Response Body

| Field | Description |
| --- | --- |
| `code` | Response result code. `1` indicates success; any other value indicates failure, with details in `msg` |

## Response Body Example

```json
{
  "code": 1,
  "msg": "Operation successful",
  "data": null
}
```
